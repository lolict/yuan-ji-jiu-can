## 1. 编码结构总览

### R-type (寄存器-寄存器)

```
31        25 24   20 19   15 14  12 11    7 6      0
+----------+--------+--------+------+--------+------+
| funct7   | rs2    | rs1    | funct3 | rd    | opcode |
+----------+--------+--------+------+--------+------+
```

### I-type (立即数)

```
31        20 19   15 14  12 11    7 6      0
+----------+--------+------+--------+------+
| imm[11:0]| rs1    | funct3 | rd    | opcode |
+----------+--------+------+--------+------+
```

### S-type (存储)

```
31        25 24   20 19   15 14  12 11    7 6      0
+----------+--------+--------+------+--------+------+
| imm[11:5]| rs2    | rs1    | funct3 | imm[4:0]| opcode|
+----------+--------+--------+------+--------+------+
```

### B-type (分支)

```
31        25 24   20 19   15 14  12 11    7 6      0
+----------+--------+--------+------+--------+------+
|imm[12|10:5] | rs2    | rs1    | funct3 |imm[4:1|11]| opcode|
+----------+--------+--------+------+--------+------+
```

### U-type (高位立即数)

```
31                  12 11    7 6      0
+------------------+--------+------+
| imm[31:12]       | rd    | opcode |
+------------------+--------+------+
```

### J-type (跳转)

```
31                  12 11    7 6      0
+------------------+--------+------+
|imm[20|10:1|11|19:12]| rd    | opcode |
+------------------+--------+------+
```

## 2. 常用指令编码明细

### 2.1 移动

| 指令 | 编码 | 位域 |
|------|------|------|
| `addi x0, x0, 0` (NOP) | `00000013` | `000000000000_00000_000_00000_0010011` |
| `addi x0, x1, 0` (mv x0,x1) | `00008013` | `000000000000_00001_000_00000_0010011` |
| `lui x2, 0x12345` | `12345137` | `0001_0010_0011_0100_0101_00010_0110111` |
| `auipc x0, 0` | `00000017` | pc + imm |

### 2.2 算术 (R-type)

| 指令 | 编码 |
|------|------|
| `add x0, x1, x2` | `00208033` |
| `sub x0, x1, x2` | `40208033` |
| `and x0, x1, x2` | `00208073` (funct3=111) |
| `or x0, x1, x2` | `00208053` (funct3=110) |
| `xor x0, x1, x2` | `00208063` (funct3=100) |
| `sll x0, x1, x2` | `00209033` |
| `srl x0, x1, x2` | `0020B033` |
| `sra x0, x1, x2` | `4020B033` |
| `slt x0, x1, x2` | `0020A033` (有符号<) |
| `sltu x0, x1, x2` | `0020B033` (无符号<) |

### 2.3 立即数

| 指令 | 编码 |
|------|------|
| `addi x0, x1, 42` | `02A00013` |
| `ori x0, x1, 0xFF` | `0FF06013` //
| `andi x0, x1, 0xFF` | `0FF07013` //
| `xori x0, x1, 0xFF` | `0FF04013` //
| `slli x0, x1, 3` | `00309013` |

### 2.4 存储

| 指令 | 编码 |
|------|------|
| `sb x0, 0(x1)` | `00008023` |
| `sh x0, 0(x1)` | `00009023` |
| `sw x0, 0(x1)` | `0000A023` |
| `sd x0, 0(x1)` (64位) | `0000B023` |

### 2.5 加载

| 指令 | 编码 |
|------|------|
| `lb x0, 0(x1)` | `00008003` |
| `lbu x0, 0(x1)` | `0000C003` (无符号) |
| `lh x0, 0(x1)` | `00009003` |
| `lhu x0, 0(x1)` | `0000D003` |
| `lw x0, 8(x1)` | `0080A003` |
| `ld x0, 8(x1)` (64位) | `0080B003` |

### 2.6 分支

| 指令 | 编码 |
|------|------|
| `beq x0, x1, +0x100` | `00100863` |
| `bne x0, x1, +0x100` | `00101863` |
| `blt` | `00104863` (funct3=100) |
| `bge` | `00105863` (funct3=101) |
| `bltu` | `00106863` (funct3=110) |
| `bgeu` | `00107863` (funct3=111) |

### 2.7 跳转

| 指令 | 编码 |
|------|------|
| `jal x0, +0x100` | `0000006f` (无条件) |
| `jal x1, +0x100` | `000000ef` (调用，返回地址存 x1) |
| `jalr x0, 0(x1)` | `00008067` (间接跳转) |
| `jalr x1, 0(x1)` | `000080e7` |

### 2.8 系统调用

```
ecall → 00000073 (12位 imm=0)
参数: a0-a5
调用号: a7
返回: a0
```

### 2.9 原子操作

```
lr.w x0, (x1)         → 0000B02F (funct5=00010, aq=0, rl=0, rs2=0)
sc.w x2, x0, (x1)     → 0010A02F (funct5=00011)
amoswap.w x0, x2, (x1) → 0010902F
amoadd.w x0, x2, (x1)  → 0000A02F
```

## 3. funct3 编码含义表

| funct3 | 含义 (R/S型) | 含义 (I型) | 含义 (分支) |
|--------|------------|----------|-----------|
| 000 | add | addi (sub) | beq |
| 001 | sll | slli | bne |
| 010 | slt | slti | 保留 |
| 011 | sltu | sltui | 保留 |
| 100 | xor | xori | blt |
| 101 | srl/sra | srli/srai | bge |
| 110 | or | ori | bltu |
| 111 | and | andi | bgeu |
