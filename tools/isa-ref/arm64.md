# ARM AArch64 指令编码

> 引用: ARM DDI 0487 (ARM Architecture Reference Manual for A-profile)
> 所有指令 32 位定长，小端

---

## 1. 编码结构总览

ARM 每种指令格式有固定模板，操作码 + 操作数 + 功能位。

### 通用寄存器数据处理 (DP reg)

```
31  29 28  25 24 21 20 16 15 10  9  5 4  0
+---+----+----+----+----+-----+----+---+
| op| 010| 0000| Rm | 000000| Rn | Rd |  DP reg (逻辑/算术)
+---+----+----+----+----+-----+----+---+
```

- op = 0: 逻辑 (and/eor/orr)
- op = 1: 算术 (add/sub)

### 添加立即数 (Add/Sub imm)

```
31 30 29  23 22 21   10  9  5 4  0
+----+----+-----+-------+----+---+
| sf | op | 100010 | imm12 | Rn | Rd |
+----+----+-----+-------+----+---+
```

- sf=1 → 64 位
- shift 位在 22-23

### MOV (wide imm)

```
31 30 29  23 22  5 4  0
+----+----+-----+----+---+
| sf | 10 | 100101 | imm16 | Rd |
+----+----+-----+----+---+
```

- MOVZ (Z): hw=0 写入 16 位，其余位零
- MOVK (K): hw=1 保留其余位 → 写 16 位
- MOVN (N): 反码

## 2. 常用指令编码明细

### 2.1 移动

| 指令 | 编码 | 位域 |
|------|------|------|
| `mov x0, xzr` | `E003804A` | `1 0101010 000 000000 000000 00000` (orr x0, xzr, xzr) |
| `orr x0, xzr, x1` | `AA0003E0` | `1 0101010 000 100001 000000 00000` |
| `movz x0, #0x1234` | `D2824680` | `1 10 100101 0 00100100011010 00000` |

### 2.2 算术

| 指令 | 编码 |
|------|------|
| `add x0, x1, x2` | `8B020020` |
| `sub x0, x1, x2` | `CB020020` |
| `add x0, x1, #255` | `9103FFC0` |
| `adds x0, x1, x2` | `AB020020` |

### 2.3 分支

| 指令 | 编码 |
|------|------|
| `b +0x1000` (相对 26b imm) | `140000xx` |
| `bl +0x1000` | `940000xx` (第 31 位=1) |
| `cbz x0, +0x100` | `B503xxxx` |
| `b.eq +0x100` | `540000xx` (cond=0000) |
| `b.lt +0x100` | `540000xx` (cond=1011) |
| `ret` | `D65F03C0` |

### 2.4 加载/存储 (imm 偏移)

| 指令 | 编码 |
|------|------|
| `ldr x0, [x1, #8]` | `F9400820` |
| `ldr w0, [x1, #8]` | `B9400820` |
| `str x0, [x1, #8]` | `F9000820` |
| `str w0, [x1, #8]` | `B9000820` |
| `ldrb w0, [x1, #1]` | `39400420` |
| `stp x0, x1, [sp, #-16]!` | `A9BF03E0` |

### 2.5 原子操作

| 指令 | 编码 |
|------|------|
| `ldxr x0, [x1]` | `F8400C20` |
| `stxr w2, x0, [x1]` | `F8000C20` |
| `ldaxr x0, [x1]` | `F85FFC20` |
| `stlxr w2, x0, [x1]` | `F81FFC20` |

### 2.6 内存屏障

| 指令 | 编码 |
|------|------|
| `dmb sy` | `D5033F9F` |
| `dsb sy` | `D5033FBF` |
| `isb`   | `D5033FDF` |

### 2.7 系统调用

```
SVC #0 → D4 00 00 01
参数: x0-x5
调用号: x8
返回: x0
```

## 3. 条件码表

| 后缀 | 编码 (31-28) | 含义 |
|------|------|-----|
| eq | 0000 | Z=1 (等于) |
| ne | 0001 | Z=0 |
| cs/hs | 0010 | C=1 (无符号>=) |
| cc/lo | 0011 | C=0 |
| mi | 0100 | N=1 (负) |
| pl | 0101 | N=0 |
| vs | 0110 | V=1 (溢出) |
| vc | 0111 | V=0 |
| hi | 1000 | C=1 && Z=0 (无符号>) |
| ls | 1001 | 反 hi |
| ge | 1010 | N=V |
| lt | 1011 | N!=V |
| gt | 1100 | Z=0 && N=V |
| le | 1110 | Z=1 \|\| N!=V |
| al | 1111 | 无条件 |

## 4. 使用时在手机上的关键约束

- **系统调用走 svc #0**，非 x86 的 `syscall`
- **WFI/WFE** (等待中断/事件) 省电: `D503201F`
- **缓存维护**: `DC CVAU, x0` → `D50B7A80`
- **SIMD 每指令 4 个 float**: `4EA01C00` (fadd v0, v1, v2)
