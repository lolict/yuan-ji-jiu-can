# x86-64 指令编码

> 引用: Intel SDM Vol. 2 / AMD APM Vol. 3
> 变长指令，1-15 字节，小端

---

## 1. 编码结构总览

x86 指令由 4 个可选前缀 + Opcode + ModR/M + SIB + Displacement + Immediate 组成。

```
[PREFIX] [REX] [OPCODE] [ModR/M] [SIB] [DISP] [IMM]
 0-4B     0-1B  1-3B     0-1B     0-1B  0-4B   0-4B
```

### ModR/MSIB 字节

```
7  6  5  4  3  2  1  0
+------+---------+-----+
| Mod  | Reg/Op  | R/M |
+------+---------+-----+
```

- Mod=00: [R/M] (无位移，除 R/M=100 走 SIB)
- Mod=01: [R/M + disp8]
- Mod=10: [R/M + disp32]
- Mod=11: R/M 是寄存器

### REX 前缀 (64 位模式)

```
7  6  5  4  3  2  1  0
+--+--+--+--+-----+----+
| 0100 | W | R | X | B |
+--+--+--+--+-----+----+
```

- W=1 → 64 位操作数
- R=1 → 扩展 Reg 字段
- X=1 → 扩展 SIB Index
- B=1 → 扩展 R/M 或 Base

## 2. 常用指令编码明细

### 2.1 移动

| 指令 | 编码 | 字节数 | 备注 |
|------|------|--------|------|
| `mov rax, rbx` | `48 89 D8` | 3 | REX.W + 89 /r |
| `mov rax, imm64` | `48 B8 xx xx xx xx xx xx xx xx` | 10 | REX.W + B8+q |
| `mov eax, 1` | `B8 01 00 00 00` | 5 | B8+d |
| `mov r8, imm32` | `41 B8 xx xx xx xx` | 6 | REX.B + B8+d |
| `xor eax, eax` | `31 C0` | 2 | 清零优化 |
| `push rax` | `50` | 1 | 50+q |
| `pop rax` | `58` | 1 | 58+q |
| `mov rax, [rbx+8]` | `48 8B 43 08` | 4 | load |
| `mov [rbx+8], rax` | `48 89 43 08` | 4 | store |

### 2.2 算术

| 指令 | 编码 | 字节数 |
|------|------|--------|
| `add rax, rbx` | `48 01 D8` | 3 |
| `sub rax, rbx` | `48 29 D8` | 3 |
| `add eax, 42` | `83 C0 2A` | 3 |
| `add rax, 0x1000` | `48 81 C0 00 10 00 00` | 7 |
| `inc rax` | `48 FF C0` | 3 |
| `dec rax` | `48 FF C8` | 3 |
| `and rax, rbx` | `48 21 D8` | 3 |
| `or rax, rbx` | `48 09 D8` | 3 |
| `xor rax, rbx` | `48 31 D8` | 3 |
| `shl rax, 3` | `48 E1 E0` | 3 |
| `shr rax, 3` | `48 E9 E8` | 3 |

### 2.3 分支

| 指令 | 编码 | 类型 |
|------|------|------|
| `nop` | `90` (1B) / `0F 1F 00` (3B) | 对齐 |
| `jmp rel32` | `E9 xx xx xx xx` | 相对 |
| `jmp rax` | `FF E0` | 间接 |
| `je +0x100` | `0F 84 FC 00 00 00` | near jcc |
| `jne +0x100` | `0F 85 xx xx xx xx` | near jcc |
| `jl +0x100` | `0F 8C xx xx xx xx` | near jcc |
| `call +0x100` | `E8 xx xx xx xx` | near call |
| `call rax` | `FF D0` | indirect |
| `ret` | `C3` | near ret |
| `test rax, rax` | `48 85 C0` | 比较零 |
| `cmp rax, rbx` | `48 39 C3` | 比较 |

### 2.4 系统调用

```
syscall → 0F 05 (2B)
参数: rdi, rsi, rdx, r10, r8, r9
调用号: rax
返回: rax
```

## 3. CPUID 信息

```
cpuid → 0F A2
eax=0: 厂商字符串 (GenuineIntel / AuthenticAMD)
eax=1: 型号/步进/特性
eax=2: 缓存/TLB
eax=7: 扩展特性
```

---

## 4. 主机 (Linux 容器) 上的 x86-64 注意

你的开发容器大概率是 x86-64 (Linux 主机):
- `syscall` 直接进内核，不是 INT 2E
- `__builtin_ia32_*` 对应 SIMD
- io_uring 通过 liburing 调用
