# MIPS32 指令编码

> 引用: MIPS32 Architecture For Programmers Vol. II
> 定长 4 字节，大端 (默认)

---

## 1. 编码结构总览

### R-type (寄存器)

```
31        26 25   21 20   16 15   11 10    6 5      0
+----------+--------+--------+--------+--------+------+
| opcode   | rs     | rt     | rd     | sa     | funct|
+----------+--------+--------+--------+--------+------+
```

### I-type (立即数)

```
31        26 25   21 20   16 15                 0
+----------+--------+--------+----------+
| opcode   | rs     | rt     | immediate|
+----------+--------+--------+----------+
```

### J-type (跳转)

```
31        26 25                            0
+----------+--------------------------------+
| opcode   | target address (26 bit)        |
+----------+--------------------------------+
```

## 2. 常用指令编码明细

### 2.1 移动

| 指令 | 编码 |
|------|------|
| `move $v0, $v1` (ori $v0, $v1, $zero) | `00 22 10 25` (ORI $v0,$v1,0) |
| `li $v0, 1` (ori $v0, $zero, 1) | `34 02 00 01` |
| `lui $v0, 0x1234` | `3C 02 12 34` |
| `lw $v0, 0($v1)` | `8C 42 00 00` |
| `sw $v0, 0($v1)` | `AC 42 00 00` |
| `lb $v0, 0($v1)` | `80 42 00 00` |
| `lbu $v0, 0($v1)` | `90 42 00 00` |

### 2.2 算术

| 指令 | 编码 |
|------|------|
| `addu $v0, $v1, $a0` | `00 22 10 21` (funct=100001) |
| `subu $v0, $v1, $a0` | `00 22 10 23` |
| `and $v0, $v1, $a0` | `00 22 10 24` |
| `or $v0, $v1, $a0` | `00 22 10 25` |
| `xor $v0, $v1, $a0` | `00 22 10 26` |
| `nor $v0, $v1, $a0` | `00 22 10 27` |
| `slt $v0, $v1, $a0` | `00 22 10 2A` |
| `sltu $v0, $v1, $a0` | `00 22 10 2B` |
| `addi $v0, $v1, 42` | `20 42 00 2A` |
| `addiu $v0, $v1, 42` | `24 42 00 2A` |

### 2.3 移位

| 指令 | 编码 |
|------|------|
| `sll $v0, $v1, 3` | `00 02 10 C0` (rt=v1, rd=v0, sa=3) |
| `srl $v0, $v1, 3` | `00 02 10 C2` |
| `sra $v0, $v1, 3` | `00 02 10 C3` |
| `sllv $v0, $v1, $at` | `00 21 10 04` |

### 2.4 分支

| 指令 | 编码 |
|------|------|
| `beq $v0, $v1, +0x100` | `10 44 00 40` (offset=+0x100/4=+0x40) |
| `bne $v0, $v1, +0x100` | `14 44 00 40` |
| `bgtz $v0, +0x100` | `1C 40 00 40` |
| `blez $v0, +0x100` | `18 40 00 40` |
| `bgez $v0, +0x100` | `04 41 00 40` (rt=1→bgez, 0→bltz) |
| `bgezal $v0, +0x100` | `04 51 00 40` (rt=10001) |

### 2.5 跳转

| 指令 | 编码 |
|------|------|
| `j target` | `08 00 00 xx` (target / 4) |
| `jal target` | `0C 00 00 xx` |
| `jr $ra` | `03 E0 00 08` (funct=001000) |
| `jalr $t9` | `03 20 F8 09` ($ra=t9, funct=001001) |

### 2.6 原子操作

```
ll $v0, 0($v1)   → C0 42 00 00 (Load Linked)
sc $v0, 0($v1)   → E0 42 00 00 (Store Conditional)
sync             → 00 00 00 0F
```

### 2.7 比较/陷阱

```
slt $at, $v0, $v1   → 00 44 08 2A
slti $v0, $v1, 0x100 → 28 42 01 00
```

### 2.8 系统调用

```
syscall → 00 00 00 0C
参数: $a0-$a3
调用号: $v0
返回: $v0
```

### 2.9 浮点 (MIPS FPU)

```
add.s $f0, $f1, $f2  → 04 42 00 01 (COP1)
lwc1 $f0, 0($v1)     → C4 42 00 00
```
