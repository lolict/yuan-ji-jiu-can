# 表格编程·全局静态翻译器 (table-trans)

把外来机器码（wasm / ELF32 / ELF64 / ARM64 / ARM32 / 汇编文本）静态翻译编入**我们的地址空间**：满全法容器符号 × 机器码进制（254+2 槽位，满 254 折叠进位）。

## 真源与授权

| 来源 | 内容 |
|------|------|
| `encoding/opcode_registry.md` §0.1 | 容器族符号（合/退/损/积/分/入/出/召/审/差/复/迁/阴/阳/裁/判/折） |
| `docs/MACRO_ISA_MACRO_MACHINE_CODE.md` | 容器四类型（加法/螺旋/镜像/折叠）+ 256=254+2 进制 + 折叠进位 |
| `tools/lazyform/lazyform.esv:57`、`tools/cmdenv-rs/rules/cmd.chain:72` | 口诀表仅清点，串联用加法 |
| `SYMBOL_AUTHORITY.md` §3.5 | 仅允许加减编址 |

## 用法

```sh
make            # 编 tabtrans + gen_fixture
make test       # 验收：wasm 真样例×4 + ELF32/ELF64 + 汇编呼唤
./tabtrans wasm ../../cangjie-wasm/build/fact.wasm
./tabtrans elf  tests/out/arm64.elf
./tabtrans elf  tests/out/arm32.elf
./tabtrans asm  tests/out/demo.asm
```

## 地址空间编法

每条外来指令 → 一个容器，逐行输出：

```
#0001 L0 槽001 格1行1列 迁 螺旋 wasm:66 4100
```

- `#NNNN` 串联序号：加法递增（前一序号 + 1）
- `L层 槽NNN`：机器码进制槽位，满 **254** 折叠进位 layer+1（254/255 两槽留给锚点）
- `格i行j列`：乘法口诀清点格（9x9=81），**积=加法累加**（行内每格 = 前格 + 行号），仅清点计数，不参与串联
- 符号+类型：满全法容器族名 + 容器四类型
- 尾列：原域:偏移 原始字节

未译指令显形计数，静默丢弃被禁止。

## 真源表 table.chain

唯一翻译依据，可注释、可增补（`.chain` 格式，`gttx://tab|符号|功能域|容器类型|外域|编码|备注|来源`）。当前 55 行：wasm 55 操作码行 + arm64/arm32 掩码行。更特异掩码排前（载入自动排序），首个命中生效。

**来源列是强制的（第四道闸）**：每行必须写出处。授权引用写 `opcode_registry.md§0.1(符号)`、`MACRO_ISA§3`、`ARM A64手册`、`ARM A32手册`、`wasm规范`；凡 Agent 的推断必须以「我推断:」开头并注明待裁决项（当前待裁决：新符号「迁」、rem→「损」、drop 归「折/揭」、折叠容器承载 wasm 块结构）。没有来源列的行，载入即拒、报原行——未经用户裁决的推断永远带标记，摘标记即违规。

## 四道驳回闸（默认拒绝，白名单放行）

| 闸 | 时机 | 行为 |
|----|------|------|
| 1 符号未授权 | 汇编模式翻译时 | 符号不在真源表 → 报错退出 |
| 2 行间重叠歧义 | 载入表时 | 部分重叠直接拒绝载入、报行号 |
| 3 未译显形 | 翻译时 | 未命中指令计数输出，静默丢弃被禁止 |
| 4 来源列缺失 | 载入表时 | 无来源行拒绝载入、报原行 |

## 为什么掩码不是概率

掩码只是「哪些位是操作码、哪些位是操作数」的压缩声明；按位与匹配是一次确定运算。三类真实风险全部在载入期/清点期消掉：

1. **表序依赖** → 载入时按掩码位数排序，更特异的行永远排前（qsort + 载入检查）
2. **行间重叠** → 载入时成对检查：部分重叠直接拒绝载入并报行号；只有严格特异的嵌套放行
3. **覆盖未知** → `./tabtrans verify <wasm|arm32|arm64>` 逐行枚举全部自由位组合，精确清点每个符号能命中的字数

当前清点结果（确定数，无采样）：

| 外域 | 覆盖字数 | 占 2^32 | 歧义 |
|------|---------|---------|------|
| arm32 | 152,043,521 | 3.5400% | 0 |
| arm64 | 327,352,321 | 7.6215% | 0 |
| wasm | 55 / 256 操作码 | — | 0（精确匹配无掩码） |

未译指令永远显形计数（未译=N），静默丢弃被禁止。扩表只增覆盖，已有的字永不漂移：掩码行一旦载入通过歧义检查，它命中的每个字都唯一归属一个符号。

不用掩码的两条备选路线（M1 备用）：**字段语法表**（声明位域，掩码由表派生并自检）与**全字枚举真源**（对齐 `mqf-isa/src/cross_isa/state_enumerator.rs` 的二进制容器代数，逐字直查，运行期零匹配）。

## 边界（M0）

- wasm：线性扫解码段（代码段），跳过其余段；处理 LEB128 立即数 / memarg / br_table / blocktype
- ARM：定长 4 字节线性扫，掩码匹配操作码域；操作数解析与控制流跟随留 M1
- ELF：按 program header 取 PT_LOAD+X 段；节头路线与动态段留 M1
- 汇编文本：符号直呼（授权符号）+ `@符号` 地址呼唤
