# 满全法 · 拼音进制闭环设计

## 五维地址空间的完整公式

```
48(声母) × 60(声调) × 66(韵母) × 42(颜色容器) × 100(微位置) = 798,336,000 ≈ 8亿地址
```

### 维度释义

| 维度 | 进制 | 来源 | 含义 |
|------|------|------|------|
| 声母 | 48 | shengmu48.nim | 24声母 × 2(大小写)，奇偶=阳/阴极性 |
| 声调 | 60 | tone60.nim | 5声 × 6韵 × 2(大小写) |
| 韵母 | 66 | yunmu66.nim | 29复韵母 × 2(大小写) + 8单韵母由CLOCK覆盖 |
| 颜色容器 | 42 | color_custom.c | 6系 × 7阶，六边形蜂窝6-bit |
| 微位置 | 100 | 容器内微网格 | 10行 × 10列 = 容器内100个精细坐标(源自4字格×25细分) |

> 用户原话："48*60*66*42*100怎么还有一百没有加上"  
> 答案：此前渲染器只用了前四维(声母×韵母×声调×颜色容器=2,784有效音节→42色)  
> 缺失的第五维"100" = 每个容器内的精细微位置(10×10子网格)。  
> 加上后地址从 7,983,360 跃升到 798,336,000，扩展约100倍。

## 第五维的意义：为什么需要 100？

- 2,784 个有效音节映射到 42 色 → 每色约 66 个音节(拥挤，同色无法区分)
- 加入 ×100 微位置 → 4,200 微格/色 → 2,784 音节仅占 66% 微格，留有余量
- 微位置使**同色音节可按其声母/韵母/声调的数值散列到不同微格**
- 视觉层：同色但不同位置 → 细粒度可区分

## 音节→微格推导公式

```python
def syllable_micro(si, yi, ti, yunmu_name):
    """音节 → 容器色(42) + 微位置(100)"""
    # Step 1: 声母极性
    polarity = "阳" if si % 2 == 0 else "阴"  # 奇=阳(主动),偶=阴(接受)

    # Step 2: 音色哈希
    ci = (si * 17 + yi * 7 + ti * 3) % 42

    # Step 3: 微位置散列(避免同色音节堆叠)
    h = si * 100 + yi * 30 + ti * 7 + sum(ord(c) for c in yunmu_name) % 100
    row = h // 10        # 微行 0-9
    col = h % 10         # 微列 0-9
    micro = row * 10 + col  # 0-99

    return ci, micro, polarity, row, col
```

## 二音节地址(基础层,已有/已知)

二音节 = 声母₁+韵母₁+调₁ → (色₁, 微₁)  
这是基础函数 `f(s₁,y₁,t₁) → (c₁,m₁)`

## 三/四音节地址(推导层,新增)

### 设计原则

**推导 vs 组合:**  
用户明确："不要组合,我们要的是推导,推导的是全新的一个容器的范畴"  
即: **三音节 ≠ 音节₁ + 音节₂ + 音节₃** 的拼接地址  
而是: `f₃( f(s₁,y₁,t₁), f(s₂,y₂,t₂), f(s₃,y₃,t₃) ) → 全新地址`

### 推导函数设计

**核心机制:** 用已有的2音节符号作为推导材料,通过相位变换/极性变换,推导出**不属于2音节空间的全新地址**。

**"全新"的定义:**  
推导出的地址不具有"包含旧符号"的特性。它是容器的范畴扩展、符号的范畴扩展——一个新的几何位置、新的符号形态。

### 推导规则(替换方式)

```
替换方式(非增量增量):
- 2音节基础: 48×66×60×42×100 = ~8亿地址(基础层)
- 3音节推导: 从中选 2音节作为"相位锚" + 1新音节作为"偏移相位"
- 4音节推导: 从中选 2音节作为"相位锚" + 2新音节作为"偏移相位对"

"最小化发音数量"原则:
- 始终保持 2 个发音作为锚点(替换基础)
- 不扩展到第3/4个独立发音
- 而是: 用第3/4个发音的数值, 对锚点做相位/极性/数值变换
```

### 公式

```python
def derive_3syllable(s1, y1, t1, s2, y2, t2, s3, y3, t3):
    """三音节推导: 用s1y2t1作锚, s2y2t2+s3y3t3做相位偏移"""
    # 锚点地址(已有)
    c1, m1 = f(s1, y1, t1)   # 基础2音节

    # 相位偏移量
    offset = ((s2 + s3) * 17 + (y2 + y3) * 7 + (t2 + t3) * 3) % 100

    # 微位置替换(在锚点色系内偏移)
    new_micro = (m1 + offset) % 100
    new_color = (c1 + (offset // 10)) % 42

    return new_color, new_micro  # 全新地址

def derive_4syllable(s1,y1,t1, s2,y2,t2, s3,y3,t3, s4,y4,t4):
    """四音节推导: 双偏移叠加"""
    c1, m1 = f(s1, y1, t1)
    offset = ((s2+s3+s4)*17 + (y2+y3+y4)*7 + (t2+t3+t4)*3) % 100
    new_micro = (m1 + offset) % 100
    new_color = (c1 + (offset // 10)) % 42
    return new_color, new_micro
```

### 数字和发音一体化

```
数字 = 声母编号 × 韵母编号 × 声调编号 + 音名数值 → 色 + 微位置
发音 = 物理读音(si+yi+ti)
身份 = 色名 + 符号 + 微格坐标

→ 数字和发音是同一身份的两种表达
→ 从数值可推出发音, 从发音可推出数值
```

### 统计确定性

```
- 所有2,784基础音节: 100% 一一对应到微格(无歧义)
- 三/四音节推导: 通过确定性公式, 相同输入→相同输出(可统计基础)
- 替换方式保证了不膨胀符号集(始终保持2锚点)

"不完全是为了解决统计的问题,所以在解决发音明确性的地址选址效率过程中,
 保障可统计性这两个范畴"
```

## 颜色体验: 42色够吗?

**42色是下限, 不是均值:**

- 6系 × 7阶 = 42色, 每色覆盖6个色阶
- 每色 × 100微格 = 4,200微格
- 2,784有效音节仅占 66.4% → 空间充足
- 加入三/四音节推导地址后, 目标 ~10,000 有效地址:
  仍占 238% → 需第二层(64容器×8层=576容器, 576×4,200=2,419,200叶子节点)
  10,000 / 2.4M = 0.4% 填充率 → 绝不拥挤

**不会因"颜色多"而稀释体验:**  
42色是系统色(颜色身份), 微位置才是精细层(几何身份)。视觉上是一个带微坐标的色块。

## 几何变换: 新旧符号如何合作?

### 替换方式(最终决策)

```
旧符号(2音节基础) ↔ 新符号(3/4音节推导)
合作方式: 以 2音节地址 为"相位锚"
          3/4音节通过数值偏移推导出新微位置
          
几何含义: 不创造全新几何形状(避免膨胀)
          而是在同一(色,微)空间内做"相位偏移"
```

### 为什么这样最优?

1. **确定性:** 发音→地址是纯函数(数值推导)
2. **统计确定性:** 2,784基础唯一, 推导公式可复现
3. **最小化:** 不引入额外符号, 不膨胀容器数量
4. **体验:** 同色系内微位置偏移 → 视觉连续(相似发音相邻微格)
5. **闭环:** 2音节→3音节→4音节 都是同一推导公式的嵌套
