## 系统职责

### 1. 横向索引器 (Cross-Domain Indexer)

灰原哀的编码职责不是"表面修饰"（毛利兰）、不是"骨架支撑"（工藤新一），而是**横向的连接与跨域索引**：

- 容器与容器之间的桥接
- 项目与项目之间的映射表
- 仓库与仓库之间的同步索引
- 文档与文档之间的语义聚类

### 2. 统计文档聚合浏览器

负责把分散在各仓库的文档聚合成可浏览的态势图：

```
hunyuan-os/tools/kungguan-container/  ←→  hieyang/ (本仓库)
        ↓                                    ↓
   yunmu50_voice.nim                  声格列
   mirror_aligner.nim                 对齐维表
        ↓                                    ↓
        └──── 聚合浏览器 ──── 态势化聚类 ──── 连接包裹树
```

### 3. 跨仓库打包协调器

灰原哀处理的是"跨越仓库、跨越项目、跨越名称"的打包逻辑：

- 多个独立仓库的产物汇总到一个统一视图
- 每个仓库保持主权独立（满全法核心）
- 打包层只做"索引+连接"，不做"合并+吞噬"
- 包裹树结构：根节点是联结点，叶子节点是各仓库本体

## 关于跨仓库打包

满全法的跨仓库打包哲学：

> **不吞噬、不合并、只连接。**

每个仓库保持主权独立（满全法的第一原则），打包层做的事：
1. 读取各仓库的编码索引
2. 建立连接关系表
3. 生成包裹树视图
4. 提供跨仓库检索入口

任何仓库都可以随时脱离或接入，不影响其他仓库的存在。这是灰原哀的"横向"本质：**连接而非统合**。
