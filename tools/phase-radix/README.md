# mhz — 满全法颜色进制

可编译、可解释、可打包的颜色进制工具。

## 架构

```
┌─────────────────────────────────────────┐
│  Python 薄壳 (mhz.py)                   │
│  命令行接口 · 用户交互                    │
├─────────────────────────────────────────┤
│  _native.py  — ctypes 绑定              │
├─────────────────────────────────────────┤
│  libcolor.so  — C 核心 (17KB)           │
│  ┌─────────────┬──────────┬───────────┐ │
│  │ 类型纪律     │ 衍射引擎  │ 编织平衡   │ │
│  │ 7类×3层     │ 6维衍射   │ 力均衡     │ │
│  ├─────────────┴──────────┴───────────┤ │
│  │ 审判五关: 层级→类型→锚→审美→编织    │ │
│  └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

## 安装

```bash
cd tools/phase-radix
pip install -e .
```

## 使用

```bash
# 审判一对符号
mhz trial a á        # → REJECT (跨层级)
mhz trial a A        # → PASS (通过)
mhz trial b p        # → PASS (通过)

# 衍射分析
mhz diffract a       # 基韵锚 · 出力/失衡
mhz diffract zh      # 声母 · 出力/失衡

# 配对衍射
mhz pair a A         # 类型匹配 · 审美分

# 注册新符号
mhz register x shengmu L1

# 运行演示
mhz demo

# 系统状态
mhz status
```

## 核心概念

- **类型纪律**: 7类符号 (基韵锚/声调韵/复韵母/符号/溢出/声母/修饰)
- **层级栈**: L1基元 / L2修饰 / L3装配 (跨层绝对拒绝)
- **审判五关**: 层级→类型→锚→审美→编织 (任一关失败=拒绝)
- **衍射分析**: 出力/受力/失衡度 (单符号属性)
- **编织平衡**: 配对力均衡 (双符号关系)
