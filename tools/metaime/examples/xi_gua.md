# 示例：xi gua（西瓜）

这是一个完整的端到端示例，展示从音节程序到编译执行的全过程。

## 输入程序

```
ma xi gua
```

## 语义解释

- ma (m+a): 遍历 — 三个容器并排，峰谷交替
- xi (x+i): 交叉 — 两线交叉，找交集
- gu (g+u): 螺旋 — 同时产生向内和向外螺旋

## 几何力场计算

| 音节 | 声母力 | 韵母方向 | 声调能量 | 合力 |
|------|--------|----------|----------|------|
| ma   | 11     | 内→外    | 1.0      | 11.0 |
| xi   | 9      | 内→外    | 1.0      | 9.0  |
| gu   | 14     | 内↔外    | 1.0      | 14.0 |

## 执行过程

```
初始状态: ma=11.0, xi=9.0, gu=14.0
操作序列: 遍历 → 交叉 → 螺旋
力场演化: 30.45 → 28.22 → ... → 16.99 (收敛)
```

## 编译

```bash
cd tools/metaime
python3 glyph_cc.py "ma xi gua" --emit xi_gua.c
cc -o xi_gua xi_gua.c -lm
./xi_gua
```
