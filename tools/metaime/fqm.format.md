# FQM 文件格式规范 · 自己的符号定义

## 核心原则
- 不使用任何外部语言的语法（无Python/无C/无Nim）
- 只用我们自己的符号：袋(容器)、引(引用)、容(内容)、址(地址)、链(链接)
- 每行一个声明，格式：`主体.关系=值`

## 语法

```
# 注释以 # 开头

# 1. 定义容器
袋.<容器名>.容=<符号1>,<符号2>,...

# 2. 定义容器属性
袋.<容器名>.进制=<数字>
袋.<容器名>.极性=<0或1>

# 3. 定义跨容器引用
袋.<容器A>.引.<容器B>=<符号A>→<符号B>

# 4. 定义符号的近义词
近.<标准符号>=<变体1>,<变体2>,...

# 5. 定义全局偏移
偏=<十六进制数>
```

## 示例

```
# 声母容器定义
袋.声母.容=b,p,m,f,d,t,n,l,g,k,h,j,q,x,zh,ch,sh,r,z,c,s,y,w
袋.声母.进制=23
袋.声母.极性=1

# 韵母容器定义
袋.韵母.容=a,o,e,i,u,v,ai,ei,ui,ao,ou,iu,ie,ve,er,an,en,in,un,vn,ang,eng,ing,ong
袋.韵母.进制=24
袋.韵母.极性=0

# 跨容器链接：声母→韵母
袋.声母.引.韵母=b→a,p→o,m→e

# 近义词
近.分=份,纷,芬
近.家=嘉,佳,加

# 全局偏移
偏=0x00
```

## 文件扩展名
- `.fqm` — 容器定义文件
- `.fql` — 链接关系文件
- `.fqn` — 近义词表文件
