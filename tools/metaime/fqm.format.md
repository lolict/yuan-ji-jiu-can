# FQM 文件格式规范 · 本体论量化

## 核心原则
- 不使用代数地址（无 0x00、无 base+offset）
- 位置 = 域.身份（如 声母.首、韵母.次）
- 符号的"地址"是它的本体论路径，不是数字
- 链接是本质与本质的连接，不是地址映射

## 语法

```
# 注释以 # 开头

# 1. 定义容器
袋.<容器名>.容=<符号1>,<符号2>,...

# 2. 定义容器属性
袋.<容器名>.进制=<数字>
袋.<容器名>.极性=<0或1>

# 3. 定义跨容器链接（本质连接）
袋.<容器A>.引.<容器B>=<符号A>→<符号B>

# 4. 定义符号的近义词
近.<标准符号>=<变体1>,<变体2>,...

# 5. 定义全局偏移（可选，用于运行时相位）
偏=<十六进制数>
```

## 示例

```
# 声母容器定义
袋.声母.容=b,p,m,f,d,t,n,l,g,k,h,j,q,x,zh,ch,sh,r,z,c,s,y,w
袋.声母.进制=23
袋.声母.极性=1

# 韵母容器定义
袋.韵母.容=a,o,e,i,u,v,ai,ei,ui,ao,ou,iu,ie,ve,er,an,en,in,un,vn,ang,eng,ing,ong
袋.韵母.进制=24
袋.韵母.极性=0

# 跨容器链接：声母→韵母（本质连接）
袋.声母.引.韵母=b→a,p→o,m→e,f→i,d→u,t→v

# 近义词
近.分=份,纷,芬
近.家=嘉,佳,加

# 全局偏移
偏=0x00
```

## 本体论路径

加载后，每个符号获得一个本体论路径：

```
声母.b → 声母.首
声母.p → 声母.次
韵母.a → 韵母.首
韵母.o → 韵母.次
```

链接解析为：

```
声母.首 → 韵母.首
声母.次 → 韵母.次
```

**没有数字地址，只有本质身份。**

## 文件扩展名
- `.fqm` — 容器定义文件
- `.fql` — 链接关系文件
- `.fqn` — 近义词表文件
