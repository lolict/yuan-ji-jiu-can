> 版本: v0.1.0-glyph
> 日期: 2026-08-28
> 根基: 声母形状几何关系范畴论

---

## 一、语言概述

### 1.1 核心理念

**字母的字形 = 操作的语义。**

每个拉丁字母的小写形式是一个几何图形。这个图形描述了一个力学系统：
- 直线 = 张力（直接传递力）
- 曲线 = 扭力（旋转传递力）
- 交叉 = 分支（力的一分为二）
- 弯折 = 反射（力的方向改变）
- 封闭 = 容器（内部空间）
- 开口 = 通道（内外交换）
- 螺旋 = 内外共存（同时向内和向外）
- 点 = 标记（精确定位）

### 1.2 与现有语言的根本区别

| 特性 | 传统语言（冯诺依曼） | 本语言（字形几何） |
|------|----------------------|-------------------|
| 执行模型 | 顺序执行指令 | 力场相互作用 |
| 状态表示 | 内存地址+值 | 几何配置（容器+向量+势能） |
| 运算基础 | 算术逻辑运算 | 几何变换（装入/取出/链接/裁定） |
| 控制流 | 条件跳转/循环 | 力场自然演化到平衡 |
| 数据结构 | 数组/对象/结构 | 容器（袋）及其几何关系 |
| 函数调用 | 栈帧+返回地址 | 力场配置切换 |
| 类型系统 | 静态/动态类型 | 几何兼容性（形状匹配） |

### 1.3 数学根基

- **范畴论**: 对象=容器，态射=几何变换，函子=跨容器映射
- **几何动力学**: 力=几何形状的内能，势能=位置的能量状态
- **加法统摄**: 所有运算基于加法（禁用乘除），保持线性叠加

## 二、字母表与操作语义

### 2.1 声母（23个）= 容器类型

每个声母定义一种容器形状，以及在该容器上可执行的操作。

| 声母 | 字形 | 容器形状 | 操作语义 | 操作符 |
|------|------|----------|----------|--------|
| b | 竖+右碗 | 球形容器（碗坐底） | 装入（从上方放入） | `装` |
| p | 竖+下碗 | 球形容器（碗悬挂） | 取出（从下方抽出） | `取` |
| m | 三峰 | 三容器并排 | 遍历（依次经过） | `遍` |
| f | 十字+弯 | 三向支撑 | 接触摩擦 | `摩` |
| d | 左碗+竖 | 球形容器（开口向左） | 定位（到达目标） | `达` |
| t | 横+竖钩 | 钩形容器 | 锚定（固定位置） | `锚` |
| n | 两峰 | 框架容器 | 比较（成对） | `较` |
| l | 单竖 | 线形容器 | 连接（两点一线） | `连` |
| g | 圆+弯钩 | 螺旋容器 | 螺旋（内外共存） | `旋` |
| k | 两斜+竖 | 支架容器 | 支撑（从一点向外） | `撑` |
| h | 右弯+竖 | 椅子形容器 | 承载（托住上方） | `承` |
| j | 竖弯+点 | 钩形容器+标记 | 捕获（勾住标记） | `捕` |
| q | 竖弯+尾 | 弯尾容器 | 追踪（沿尾寻找） | `追` |
| x | 两斜交叉 | 交叉容器 | 比较（交集判断） | `交` |
| zh | 反Z | 折线容器 | 折叠（改变方向） | `折` |
| ch | 反C+竖 | 环抱容器 | 包裹（环抱内容） | `包` |
| sh | S+竖 | 蛇形+支撑 | 流动（沿曲线传递） | `流` |

| s | S形 | 蛇形容器 | 传递（沿曲线滑动） | `传` |
| y | 两斜下 | 分叉容器 | 分裂（一分为二） | `裂` |
| w | 双谷 | 合并容器 | 合并（二合为一） | `合` |

### 2.3 声调（4个）= 能量级

每个声调定义一个势能级，影响操作的幅度。

| 声调 | 调值 | 势能 | 幅度系数 |
|------|------|------|----------|
| 一声 | 55 | 高势能恒定 | 1.0（标准） |
| 二声 | 35 | 势能上升 | 1.2（加大） |
| 三声 | 214 | 势能降升 | 0.8（先减后加） |
| 四声 | 51 | 势能下降 | 1.5（加速） |

## 三、语法规则

### 3.1 基本单元

程序的基本单元是**音节（Syllable）**，由三部分组成：

```
音节 = 声母 + 韵母 + 声调
```

示例：
- `ma` = m(三峰容器) + a(辐射向量) + 一声(标准幅度)
- `pa` = p(悬挂容器) + a(辐射向量) + 一声(标准幅度)
- `fa` = f(支撑容器) + a(辐射向量) + 一声(标准幅度)

### 3.2 表达式

表达式由音节通过**几何组合规则**连接而成。

#### 3.2.1 水平组合（并置）

```
A B = A + B
```

两个音节并排放置 = 两个力场并列存在。

示例：
```
ma pa = 三峰容器 + 悬挂容器
```

语义：两个容器并排，各自独立运作。

#### 3.2.2 垂直组合（嵌套）

```
A
B
```

两个音节上下放置 = 一个容器套入另一个容器。

示例：
```
ma
pa
```

语义：三峰容器内部套有悬挂容器。

#### 3.2.3 交叉组合（链接）

```
A → B
```

两个音节用箭头连接 = 从A到B的力传递。

示例：
```
ma → pa
```

语义：三峰容器的力传递给悬挂容器。

#### 3.2.4 弯折组合（反射）

```
A ↩ B
```

两个音节用弯折箭头连接 = A的力被B反射回去。

示例：
```
ma ↩ pa
```

语义：三峰容器的力被悬挂容器反射。

### 3.3 语句

语句是表达式的有序序列，描述一个完整的操作过程。

```
语句 = 表达式 {; 表达式}
```

示例：
```
ma → pa; fa → da
```

语义：先让三峰容器的力传递给悬挂容器，再让支撑容器的力传递给定位容器。

### 3.4 程序

程序是语句的有序序列，描述一个完整的力场演化过程。

```
程序 = 语句 {换行 语句}
```

## 四、语义规则

### 4.1 操作执行

每个音节的执行 = 根据其声母（容器类型）+ 韵母（向量方向）+ 声调（能量级）执行对应的几何操作。

#### 4.1.1 装入操作（b类）

```
ba = b(球形容器) + a(辐射向量) + 一声(标准)
```

执行：
1. 创建一个球形容器
2. 从上方开口处放入内容
3. 内容在容器内向外辐射
4. 幅度为标准（系数1.0）

#### 4.1.2 取出操作（p类）

```
pa = p(悬挂容器) + a(辐射向量) + 一声(标准)
```

执行：
1. 创建一个悬挂容器
2. 从下方开口处抽出内容
3. 内容在容器内向外辐射
4. 幅度为标准（系数1.0）

#### 4.1.3 遍历操作（m类）

```
ma = m(三峰容器) + a(辐射向量) + 一声(标准)
```

执行：
1. 创建三个并排容器
2. 依次经过每个容器
3. 每个容器内的内容向外辐射
4. 幅度为标准（系数1.0）

### 4.2 力场相互作用

当两个音节组合时，它们的力场会发生相互作用。

#### 4.2.1 力场强度计算

每个音节的力场强度 = 其声母所有几何基元的力之和。

```
力(声母) = Σ 力(几何基元)
```

几何基元力值：
- 直线（张力）= 2
- 曲线（扭力）= 3
- 交叉（分支）= 4
- 弯折（反射）= 2
- 封闭（容器）= 5
- 开口（通道）= 1
- 螺旋（内外共存）= 6
- 点（标记）= 1

#### 4.2.2 相互作用力

两个音节组合的相互作用力 = 两个音节力场强度之和（加法统摄）。

```
力(A B) = 力(A) + 力(B)
```

#### 4.2.3 兼容性判断

两个音节可以组合的条件：它们的"被利用部位"相同。

```
兼容(A, B) ⟺ zone_used(A) = zone_used(B)
```

### 4.3 执行模型

#### 4.3.1 力场演化

程序的执行 = 力场从初始状态到平衡态的演化过程。

```
初始状态: 所有音节处于各自的力场配置
演化规则: 相邻音节的力场相互作用，产生新的力场配置
终止条件: 所有力场达到平衡（无净力差）
```

#### 4.3.2 能量守恒

在整个演化过程中，总能量守恒。

```
Σ 势能(所有音节) + Σ 动能(所有相互作用) = 常数
```

## 五、类型系统

### 5.1 几何类型

每个值有一个几何类型，由它的容器形状决定。

| 类型 | 形状 | 示例 |
|------|------|------|
| 球型 | 封闭曲面 | b, p, d, g, o |
| 线型 | 直线 | l, i, t |
| 峰型 | 曲线起伏 | m, n, s, w |
| 叉型 | 交叉线 | x, f, k, z |
| 螺旋型 | 卷曲 | g, q, zh, ch, sh, r |
| 框架型 | 支撑结构 | h, n, k |

### 5.2 类型兼容

两个值可以组合，当且仅当它们的几何类型兼容。

```
兼容(球型, 球型) = true
兼容(线型, 线型) = true
兼容(球型, 线型) = false（除非有转换规则）
兼容(峰型, 峰型) = true
兼容(叉型, 叉型) = true
兼容(螺旋型, 螺旋型) = true
```

### 5.3 类型转换

不兼容的类型可以通过**几何变换**转换。

```
球型 → 线型: 压扁（施加压力）
线型 → 球型: 弯曲（施加扭力）
峰型 → 线型: 拉伸（施加拉力）
线型 → 峰型: 压缩（施加压力）
```

## 六、标准库

### 6.1 容器操作

| 操作 | 语法 | 语义 |
|------|------|------|
| 创建容器 | `b a` | 创建一个球形容器 |
| 装入内容 | `b a → X` | 将X装入球形容器 |
| 取出内容 | `p a ← X` | 从球形容器取出X |
| 遍历容器 | `m a → [X Y Z]` | 依次经过X, Y, Z |
| 比较容器 | `n a ↔ [X Y]` | 比较X和Y |
| 裁定容器 | `f a ⟶ X` | 对X进行裁定 |

### 6.2 链接操作

| 操作 | 语法 | 语义 |
|------|------|------|
| 建立链接 | `l a → X` | 从当前容器连接到X |
| 追踪链接 | `q a → X` | 沿尾部追踪到X |
| 分支链接 | `r a → [X Y]` | 从当前容器分支到X和Y |
| 合并链接 | `w a ← [X Y]` | 将X和Y合并到当前容器 |

### 6.3 变换操作

| 操作 | 语法 | 语义 |
|------|------|------|
| 折叠变换 | `zh a → X` | 将X折叠改变方向 |

| 分裂变换 | `y a → [X Y]` | 将X分裂为X和Y |
| 合并变换 | `w a ← [X Y]` | 将X和Y合并 |

## 七、示例程序

### 7.1 简单装入

```
ba
```

创建一个球形容器，装入内容，内容向外辐射。

### 7.2 装入后取出

```
ba; pa
```

先装入，再取出。两个操作顺序执行。

### 7.3 遍历三个容器

```
ma → [ba pa da]
```

遍历三个容器：球型、悬挂、定位。

### 7.4 比较后裁定

```
na ↔ [ba pa]; fa ⟶ result
```

先比较球型和悬挂容器，然后对比较结果进行裁定。

### 7.5 分支处理

```
ra → [ba; pa; ma]
```

从一个容器分支到三个不同的处理路径。

### 7.6 完整程序示例

```
# 创建一个球形容器
ba

# 装入内容
ba → content

# 遍历三个容器
ma → [ba pa da]

# 比较前两个
na ↔ [ba pa]

# 裁定比较结果
fa ⟶ judgment

# 根据裁定分支
ra → [ba; pa]

# 合并结果
wa ← [ba pa]
```

## 八、实现指南

### 8.1 解析器

1. 将输入字符串分解为音节序列
2. 对每个音节，查找其声母、韵母、声调
3. 构建抽象语法树（AST），其中节点是音节，边是几何组合关系

### 8.2 类型检查器

1. 对每个音节，确定其几何类型
2. 检查相邻音节的类型兼容性
3. 对不兼容的类型，尝试应用类型转换规则

### 8.3 执行引擎

1. 初始化所有音节的力场配置
2. 循环执行：
   a. 计算相邻音节的相互作用力
   b. 根据合力更新每个音节的状态
   c. 检查是否达到平衡
3. 输出最终状态

### 8.4 编译器（可选）

1. 将AST转换为中间表示（IR）
2. 优化：合并相邻的兼容操作
3. 目标代码生成：
   - 编译到C：将几何操作映射为结构体操作
   - 编译到WASM：将力场配置映射为线性内存布局
   - 编译到GPU：将力场演化映射为并行计算

## 九、与现有系统的关系

### 9.1 与FQM的关系

本语言是FQM（满全法容器操作协议）的**语法层**。FQM定义了容器操作的语义，本语言定义了如何书写这些操作。

### 9.2 与鼓膜自举的关系

鼓膜自举是语言的**运行时**。它负责：
1. 初始化力场环境
2. 加载程序
3. 执行力场演化
4. 输出结果

### 9.3 与字形几何模块的关系

字形几何模块（glyph.zig/glyph.nim）是语言的**字母表**。它定义了每个字母的几何属性和操作语义。
