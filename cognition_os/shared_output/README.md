# 共享接力目录 · 多代理协作

## 规则
1. 每个子代理完成任务后 → 把产出写入此目录
2. 新子代理启动 → 先读取此目录中的现有产出
3. 所有符号必须来自 symbol_index.nim · 禁止自创
4. 违反规则的产出 → 标记为"废弃" · 不进入接力链

## 文件命名
- `agent_[序号]_[任务描述].json`
- 例: `agent_001_yunmu_shengmu_train.json`

## 接力链
```
agent_001 → 产出写入 → agent_002 读取 → 继续 → ...
```

## 检查清单
- [ ] 符号是否来自 symbol_index.nim?
- [ ] 是否使用了白名单外字符?
- [ ] 是否遵守基元冻结?
- [ ] 是否与已有产出冲突?
