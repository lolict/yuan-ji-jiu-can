# 田字格坐标偏置记号 · 设计规格

## 问题

在田字格容器内"造字"（把汉字笔画/结构拆开到格位里），需要一套记号法来描述：
- 笔画从哪个格位出发
- 向哪个方向偏置
- 偏置多少量级

## 用户提供的记号法

### 基本偏置类型

| 记号 | 含义 |
|------|------|
| `+1` | 正向偏移 1 级（右/上） |
| `-1` | 负向偏移 1 级（左/下） |
| `±1` | 正负双向偏移 1 级（左右/上下都可能） |
| `±2` | 正负双向偏移 2 级 |
| `1±` | 轴向 1 偏移（双重含义：量级 1 + 方向 ±） |
| `2± 3±` | 多个独立偏置，同时存在 |
| `1- 2- 3-` | 三个连续负向偏移步骤 |
| `4±` | 轴向 4 偏移（通常指声母组内偏移） |

### 偏置量级协议

`1±, 2±, 3±, 4±` 对应不同的迁移层：
- `1±`：格内微调（笔画位置偏移）
- `2±`：格间迁移（从一个格到相邻格）
- `3±`：跨行迁移（从一个声母行到另一个）
- `4±`：跨族迁移（从声母组到不同韵母组）

### 复合记号

| 记号 | 含义 |
|------|------|
| `1±.±2` | 正向量级1 + 正负双向量级2 的组合 |
| `1±.±3` | + 量级3 |
| `1±.±4` | + 量级4 |
| `±1.-2` | 正负量级1 + 负向量级2 |
| `±1.-3` | + 负向量级3 |
| `±1.-4` | + 负向量级4 |
| `±2.±3` | 正负量级2 + 正负量级3 |
| `±2.±4` | + 量级4 |
| `-1.2+` | 负向量级1 + 正向量级2 |

### 例子解读

```
1±.±2 = 格内微调 ± 格间双向迁移（可在相邻格左右摆动）
±1.-2 = 第一级全方向探索 → 第二级向左/下定位
±2.±3 = 格间摆动 ± 跨行调整
```

## 四格偏置体系与田字格四格的对应

田字格本身四格对应四种基础偏置：

| 格位轴 | 偏置类型 | 含义 |
|--------|----------|------|
| 左上（声母格） | ±X | 声母组内偏移 |
| 右上（韵母格） | ±Y | 韵母组内偏移 |
| 左下（声调格） | ±Z | 声调组内偏移 |
| 右下（微位格） | ±W | 微位置调整 |

## 与现有编程体系的对接

现有实现：`base = s*3960 + t*66 + y` = 三轴正交地址

记号法偏置 → 地址偏移：

| 记号 | 等效操作 |
|------|----------|
| `+1` | 地址 +1（右移一个微调） |
| `-1` | 地址 -1（左移） |
| `±1` | 摆动探索：±1 之间往返 |
| `±2` | 格间迁移：±66（韵母跨1） |
| `±3` | 跨行：±3960（声母跨1） |
| `1±.±2` | 微调 + 格间探索：±1 + ±66 |
| `±1.-3` | 第一轴探索 + 跨行定位：±1 ± 3960 |
| `-1.2+` | 微调向左1 + 韵母跨2：-1 + 132 |

## 可执行性判断

✅ **这套记号法完全可执行**，因为：
1. 每级偏置对应一个数值偏移（±1, ±66, ±3960）
2. 复合记号是多个独立偏移的笛卡尔积
3. 方向与量级分离，可以独立加到地址公式上
4. 四格记号法天然映射到现有的声母/韵母/声调/微位四轴

⚠️ 需要完善记号法的部分：
1. `1±` 和 `±1` 的区别——看起来是同一回事，但用户意图可能是"正向1" vs "正负1"
2. `±2.±3` 顺序——是"先探索后定位"还是"同时叠加"？需要语义明确
