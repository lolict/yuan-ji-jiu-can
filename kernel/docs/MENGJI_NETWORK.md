# 盟机合网络 · MengJi Decentralized Verdict Synchronization

## 概述

盟机合(盟=盟约 + 机=节点 + 合=合一)是囡囝共生体系的去中心化裁定同步骨架。

它取代工业化术语"合伙人",建立基于主权归属的节点关系:
- **盟机合掌**(PHONG) = 资源拥有者 · 运营场 · 主权根节点
- **盟机场**(FARM) = 普通节点 · 萌机场 · 主权叶节点

术语转变: **合伙人 → 盟机合**,体现主权归属而非商业合伙。

## 架构

```
┌─────────────────────────────────────┐
│          盟机合掌 (PHONG)           │
│  资源拥有者 · 运营场 · 主权根节点     │
│  信任权重: 80%默认 · 夫妻锚点: 1     │
├───────────┬───────────┬─────────────┤
│ 盟机场 A  │ 盟机场 B  │  盟机场 C   │
│ 萌机场    │ 萌机场    │  萌机场     │
│ 信任: 50% │ 信任: 50% │  信任: 50%  │
│ 锚点: 0   │ 锚点: 1   │  锚点: 0    │
└───────────┴───────────┴─────────────┘

PUSH(推) ────── 节点主动广播 verdict_state
PULL(拉) ────── 节点主动向邻居请求 verdict_state
三元见证 ───── 3 节点投票,≥3 票共识(锚点权重 2x)
```

## 夫妻主权人节点模型

```
锚点定义:
  0 = 刘楚恬 ─── 低位隐藏侧(隐藏根基 · 不被感知才安全)
  1 = 我     ─── 高位可见侧(主权排序 · 可见侧拥有指挥优先级)

主锚点(default): ANCHOR_LOLICT(我) = 1

冲突裁决优先级:
  1. 夫妻主权人锚点(权重 2)
  2. 盟机合掌 > 盟机场
  3. 高信任 > 低信任
  4. 早 heartbeat > 晚 heartbeat(先入为主)
```

## Gossip 节律

每 5 秒一轮 PUSH + PULL:

1. **PUSH 阶段**: 节点将本地 verdict_state 广播到所有邻居
2. **PULL 阶段**: 向邻居请求 verdict_state,不足则补足
3. **探测阶段**: 超过 30 秒无心跳的节点标记失活

最终一致性: 多轮 Gossip 后,所有存活节点的裁定态趋于一致。

## 三元见证裁定

```
投票规则:
  - witness_a: 节点 A
  - witness_b: 节点 B
  - witness_c: 夫妻主权人锚点(权重 2x)

共识阈值: ≥3 票
  锚点(权重2) + 任一普通节点(权重1) = 3 → 共识达成
  无锚点: 3 个普通节点 × 1 = 3 → 共识达成

未达成共识 → VERDICT_SPLIT(分形) → 等待更多见证
```

## 冲突裁决

当 PUSH 后发现裁定态不一致:

```
裁决链:
  1. 有夫妻主权人锚点参与 → 取锚点裁定(权重 2x)
  2. 同类型节点 → 取高信任值
  3. 信任相同时 → 取早 heartbeat(先入为主)
  4. 均无足够见证 → 保守取 PENDING
```

将裁决结果广播到全部节点,覆盖分歧。
