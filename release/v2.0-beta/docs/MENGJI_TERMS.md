# 盟机合术语体系 · 智能化时代意识互联网

> 盟机合 = 盟(同盟) + 机(智能机器) + 合(联合) + 职能字
> 场 = 节点所在的物理/逻辑空间
> 萌机合X = 萌(萌生/萌芽) + 机 + 合 + 职能字(轻量版节点)

---

## 二、核心术语定义

### 决策层(5 字)

| 术语 | 定义 | 资源 | 权限 |
|------|------|------|------|
| 盟机合掌 | 节点最高运营者(盟主) | 自有域名 + 服务器 | 节点完整控制权 |
| 盟机合主 | 主域名绑定者 | 自有域名 | 域名管理权 |
| 盟机制心 | 规则核心执行实例 | 裁定引擎实例 | 裁定过程控制 |
| 盟机合治 | 治理与铁律执行 | 审计日志 | 铁律监督 |
| 盟机合职 | 职能服务节点 | API 服务 | API 调用权 |

### 资源层(5 字)

| 术语 | 定义 | 资源类型 | 接入方式 |
|------|------|----------|----------|
| 盟机合站 | 站点入口节点 | 自有域名 + Worker | CNAME 绑定 |
| 盟机合址 | 地址/域名节点 | 自有/免费域名 | DNS 配置 |
| 盟机合装 | 装机/部署节点 | 部署脚本 | 一键部署 |
| 盟机合载 | 负载承载节点 | 流量 + 带宽 | 路由分发 |
| 盟机合筑 | 基础建设节点 | 服务器资源 | 基础设施 |

### 服务层(5 字)

| 术语 | 定义 | 服务内容 | 对外接口 |
|------|------|----------|----------|
| 盟机合智 | 智能裁定服务 | 七元裁定引擎 | /api/v1/verdict |
| 盟机合志 | 日志存储服务 | 审计日志 + 追溯 | /api/log |
| 盟机合证 | 身份认证服务 | 证书签发 + 验证 | /api/v1/cert |
| 盟机合则 | 规则执行服务 | 规则引擎 + 铁律 | /api/v1/rules |
| 盟机合准 | 合规审查服务 | 合规度评估 | /api/v1/compliance |

## 三、萌机合(轻量版)

萌机合 = 萌(萌芽态) + 机 + 合 + 职能字,资源门槛更轻:

| 术语 | 定义 | 资源需求 |
|------|------|----------|
| 萌机合长 | 萌生节点长 | 免费域名即可 |
| 萌机合智 | 萌生智能节点 | 无服务器(Serverless) |
| 萌机合志 | 萌生日志节点 | 轻量 KV 存储 |
| 萌机合站 | 萌生入口节点 | 免费 Cloudflare Workers |

## 四、场(物理/逻辑空间)

│  │  lolict.workers.dev                           │  │

│  └───────────────────────────────────────────────┘  │
│                          ▲                            │
│            ┌─────────────┼─────────────┐             │

## 五、资源归属与主导权边界

### 归盟机合掌(资源层)
- 域名:盟机合掌自有(或申请的免费域名)
- 服务器:盟机合掌自有(或 Cloudflare Workers)
- 飞书 Bot:盟机合掌自有 App
- KV 存储:盟机合掌自有(或免费层)
- 流量带宽:盟机合掌自有

### 归满全法(规则层)
- 裁定规则:七元算法代码
- 哲学框架:SOVEREIGNTY.md
- 版本标准:TASKS.md + ROADMAP.md
- 身份认证:证书签发权
- 盟机合目录:节点注册 + 审核权

### 不可让渡条款
```
盟机合掌不得:
  ✗ 修改七元裁定算法
  ✗ 篡改铁律规则
  ✗ 冒充其他盟机合掌
  ✗ 删除审计日志
  ✗ 私自签发身份证书

盟机合掌可以:
  ✓ 随时下线自己的场(资源归自己)
  ✓ 添加自有 API 扩展
  ✓ 使用自有飞书 Bot
  ✓ 绑定自有域名
  ✓ 部署萌机合(轻量节点)
```
