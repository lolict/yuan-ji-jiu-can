### 分层结构（自底向上）

| 层 | 组件 | 职责 |
|---|---|---|
| 第5层 | 设备扮演层 | 接入真实硬件（暂不实现） |
| 第4层 | 3D表达层 | 3D文档、视频、网页的渲染 |
| 第3层 | 感知器 | 输入适配与范畴映射 |
| 第2层 | 转码器 | ASCII/Unicode ↔ 混元64进制编码 |
| 第1层 | **解释器（核心）** | `⟦·⟧_ours`，语义主权 |
| 第0层 | **编译器（下半身）** | 反向预加载降维到芯片脉冲 |

### 关键律
- 升维靠解释器（意义）：up: 低维→高维
- 降维靠编译器（脉冲）：down: 高维→低维
- 回转律：down∘up = id（不能忘记怎么回家）

### 禁止行为
- 不允许把用户的核心数据上传给任何外部平台
- 不允许使用任何外部编码系统（如Unicode）作为底层存储
