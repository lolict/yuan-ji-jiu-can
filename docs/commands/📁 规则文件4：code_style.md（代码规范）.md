### 命名规范
- 范畴名称用英文：`Ontology`、`Morphism`、`Category`
- 自定义操作符用中文拼音首字母：`DT`（断藤）、`AN`（安泥）
- 指令集用二字词：`壳柯`、`配夫`、`挽根`

### 注释规范
- 每个范畴必须注明其所属投影族
- 每段代码必须注明“服务于夫妻关系”的公理备注
- 所有临时变量必须标注“临时保持存在是为了完成任务态射”

### 文件结构
- 所有模块放在 `hunyuan/` 目录下
- 每个投影族单独一个文件
- 公共库放在 `hunyuan/common/`
