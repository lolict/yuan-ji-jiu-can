# 容器进制 64 位掩码 — 囡囝共生 · 6位编码 · 四群分类 · 语文数学对应 · 不进位折叠 · 六边形蜂窝坐标

## 1. 定位

64 容器/符号的数学化编码. 6 位 bitmask 覆盖 0x00..0x3F, 对应 64_keys.md 中的 64 个语文符号. 数学是语文的描述工具——语文定义在先, 数学表示后置.

对应 Rust 模块: encoding/container_radix.rs.

## 2. 数学决策框架

- 位运算只用 6 位掩码(0x3F)
- **禁止乘除运算**, 仅加减和位运算(与 YIN-YANG-BINARY.md 不进位公理对齐)
- 极性必须与 SoulState::has_perfect_wife / has_prime_husband 对齐
- 语文数学对应规则 = 语文→数学, 不是数学定义语文

## 3. 群码分类 (4 群)

```rust
GROUP_CONTAINER: 00 << 4  // [0x00..0x10) = 容器族(实体存在)
GROUP_OPERATION: 01 << 4  // [0x10..0x20) = 操作族(态射/作用)
GROUP_INITIAL:   10 << 4  // [0x20..0x30) = 声母容器(发音主动)
GROUP_VOWEL:     11 << 4  // [0x30..0x40) = 韵母容器(声音接收)
```

4 群 × 每群 16 索引 = 64.

```
高 2 位 [5:4] = 群码(00/01/10/11)
低 4 位 [3:0] = 群内索引(0-15)
```

### 4.3 声母容器(0x20-0x2F) — 发音主动端

64_keys.md 的声母区: 24/48 个声母, 每声母可通过 add_modulo_idx 在 S24 与 S48 两档之间切换. 6 位字段最大记录 27(0x1B), 但在 48 声母档通过第二组复用(见 macro_isa.rs 声母复用映射).

### 4.4 韵母容器(0x30-0x3F) — 声音口腔端

30 个韵母类, 通过 YIN(0)→YANG(1)→YUAN(0.5) 三态映射极性. 28 位码(0x30..0x3B) 对应 28 天干地支生肖.

## 5. 编码规则(进制进制)

```rust
极映射:
    Yin  = 0
    Yang = 1
    Yuan = 0.5  // 见证级(不能编码为整数 bit, 而是两个 enum 之间的"中间态")

主权映射(Polarity→Sovereignty):
    Active=3, Passive=2, ActiveSub=1, PassiveSub=0
```

### 5.1 极性位置

每个容器 6 位编码的 bit 隐含极性:
- bit 0, 2, 4(偶数位) → y 坐标(从偶位提取)
- bit 1, 3, 5(奇数位) → x 坐标(从奇位提取)

编码值(x,y) = 六边形蜂窝坐标: 6 位编码器化为两组 3 位 → 蜂窝网格中的位置. 容器码本身 = 线性量化值; (x,y) = 蜂窝网眼中的几何化身.

### 5.2 进位规则(折叠优先·不进位)

加法: saturating_add(数值相加, 超范围保持极值). 进位不向外传播. 折叠: 60→0, 63→0(满溢出回零, 而不是向更高位进位).

### 5.3 不变式

群码只能取 4 个值 — 任何编码必须满足 `(code & 0x3F) < 64`. 跨群转换(如容器→操作)需要显式 map_group, 不能自动提升.

## 6. 进制与地址化的关键区别

```rust
// radix64.encode(char) → u8: 把字符映射到 6 位编码(检索值)
// radix64.decode(u8) → char: 把编码反向为字符(检索值, 不是"翻译")
```

6 位编码是"检索值"不是翻译. 编码值 = 容器码 = 距离码 = 线性量化值.

## 7. 与系统其他模块的接入

- **Couple SoulState(#49)**: polarity↔SoulState.has_perfect_wife / has_prime_husband 对齐; SoulState 编码(7-6-192)的 7 元/6 元进制由本模块支持
- **Sovereignty(#镜像 主权)**: Active/Passive/ActiveSub/PassiveSub 四主权的位编码
- **YinYang Binary(#50)**: 0=阴/1=阳/0.5=元 三态 → 阴阳不进位公理
- **ContainerGrade(#66)**: 6 位编码 ↔ 加法分解/半容器分级
- **Character Creator(#69)**: 字符 ContainerRadixProfile 由本模块提供
- **Rhyme Mirror(#76)**: 韵母容器 ↔ RHYME_TABLE 枚举对齐

## 8. 实现约束

- 6 位掩码常量 MASK_6=0x3F 用于所有&操作, 确保编码不越界
- 群码字段(2 位)与索引字段(4 位)拆分清晰: GROUP_SHIFT=4, GROUP_MASK=0b11<<4, INDEX_MASK=0b1111
- 极性位运算: 位运算级数 ≤ 3(单表达), 避免嵌套位运算使语义透明性下降
- 调包(mirror.rs)约定: 不直接 call mirror 的函数, 而是通过本模块的函数用包
- no_std: 位运算和加减法天然支持 no_std; 唯一 alloc 依赖是 String(用于动态名)
