## 五、编码使用规则

### 5.1 音节编码格式

```
[声母编码] + [韵母编码] + [声调编码] = 一个完整音节
```

例：编码"ɓɛà"= 重型起音 + 明亮韵 + 快速下降调

### 5.2 编码长度

| 场景 | 编码数 | 示例 |
|------|--------|------|
| 纯声母 | 1 | ZD001 |
| 纯韵母 | 1 | ZD022 |
| 声+韵 | 2 | ZD001+ZD022 |
| 完整音节 | 3 | ZD001+ZD022+ZD037 |

### 5.3 与拉丁字母的零混淆

本编码表所有符号与 aoeiuv 拉丁本体**视觉差异显著**，不存在"看起来像拉丁字母"的问题。任何给定的零维码编码，不会被误认为拼音。
