# 囝生殖操作系统 · 版本自生殖体系

> 让 AI 生出 N 个版本，用户挑一个正确的。
> 对就奖，错就罚。永远不修改旧文件。
> 报数：老大、老二、老三、老四……公约数锚定，公倍数旋转，照镜子对比。

---

## 一、为什么需要生殖系统

**问题**：人工智能每次做错后修改旧文件，历史全丢，无法对比。
**解决**：每次做错就生一个新的——报数命名，全部保留，让用户挑。

```
旧方式（错误）：
  file_v1 → 修改 → file_v1（覆盖）→ 修改 → file_v1（覆盖）→ ??? 历史丢失

新方式（生殖）：
  老大.c → 错了 → 老二.c → 错了 → 老三.c → 对了！✓ 全部保留
```

## 二、核心数学：公约数与公倍数

### 公约数（Anchor 锚定）
两个数的公约数 = 它们共享的基础因子。
系统隐喻：**所有版本必须满足的最低正确底线**。

### 公倍数（Rotation 旋转）
一个数的公倍数 = 该因子的倍数展开。
系统隐喻：**每个版本围绕锚点的不同表达**。

### 照镜子（Mirror Comparison）
公倍数除以公约数 = 商。商一致则通过，商偏离则淘汰。

```
示例：
  公约数 G = 6（锚点 = 必须满足的底线）
  公倍数 A = 12 → 12 ÷ 6 = 2（通过，商整齐）
  公倍数 B = 18 → 18 ÷ 6 = 3（通过，商整齐）
  公倍数 C = 14 → 14 ÷ 6 = 2.33（淘汰！商不整齐）
```

## 三、生殖系统六子系统

### 3.1 生殖层（Breeding）

| 规则 | 描述 |
|------|------|
| 绝不覆盖 | 每次尝试创建新文件，绝不修改旧文件 |
| 报数命名 | 老大、老二、老三……按顺序 |
| 记录血统 | 每个版本记录其父版本和变化点 |
| 代数追踪 | 第几代、第几个孩子 |

### 3.2 审判层（Judgment）

| 规则 | 描述 |
|------|------|
| 照镜子 | 将候选输出与锚点（预期）对比 |
| 公约数对齐 | 提取锚点的公约数因子作为基准 |
| 整除判断 | 候选值能被公约数整除 → 通过 |
| 偏离打分 | 不能整除 → 计算偏离度，偏离越大扣分越多 |

### 3.3 奖惩层（Reward/Punishment）

| 事件 | 反馈 |
|------|------|
| 被用户选中 | 该版本 +奖励 |
| 被用户拒绝 | 该版本 -惩罚 |
| 连续被选 | 晋升（遗传到下一代） |
| 连续被拒 | 绝育（不再作为父本） |

### 3.4 历史层（History）

| 功能 | 描述 |
|------|------|
| 家谱树 | 所有版本的父子关系图 |
| 档案库 | 每个版本的完整代码和输出 |
| 胜败记录 | 每个版本的被选次数和被拒次数 |
| 趋势分析 | 后一代是否优于前一代 |

### 3.5 美学层（Aesthetic）

| 规则 | 描述 |
|------|------|
| 简洁美 | 行数少而精的版本加分 |
| 对称美 | 结构对称的版本加分 |
| 公约美 | 能被多个公约数整除的版本加分 |
| 冗余惩罚 | 重复代码多的版本扣分 |

### 3.6 淘汰层（Elimination）

| 规则 | 描述 |
|------|------|
| 零除失败 | 导致除零错误的版本立即淘汰 |
| 偏离超限 | 偏离度超过阈值的版本淘汰 |
| 冗余检测 | 与已有版本雷同的重复版本淘汰 |
| 衰老惩罚 | 超过N代未被选中的支系绝育 |

## 四、运行场景

```
场景 B1: 生殖四个版本
  → 老大、老二、老三、老四各生成一份解答
  → 每份保存为独立文件
  → 报数命名，不覆盖

场景 B2: 照镜子对比
  → 锚点输出 = 公约数 G 的倍数
  → 每个候选输出除以 G，观察商是否整齐
  → 打出偏离分

场景 B3: 用户挑选
  → 显示所有版本的对比结果
  → 用户挑选"正确"的版本
  → 被选版本+奖励，被拒版本-惩罚

场景 B4: 美学淘汰
  → 系统自动从美学维度打分
  → 冗余/累赘版本扣分
  → 简洁/对称版本加分

场景 B5: 进化迭代
  → 用被选版本作为父本
  → 继续生殖下一代（老五、老六……）
  → 代代相传，优胜劣汰
```

## 五、对接天觉

生殖系统生出的版本 = 天觉系统的"袋子"
天觉审判版本的品质 = 生殖系统的"照镜子"

```
           ┌─────────────────────────────┐
           │     囝生殖操作系统           │
           │                             │
  生殖 ──→ │  老大  老二  老三  老四     │ ──→ 保存为独立文件
           │   │    │     │      │       │
           │   └────┴─────┴──────┘       │
           │          ↓                  │
  照镜子 ──→ │  公约数G作锚点            │ ──→ 计算偏离度
           │          ↓                  │
  审判 ──→ │  通过 / 待定 / 拒绝        │
           │          ↓                  │
  奖惩 ──→ │  对就奖 / 错就罚            │
           │          ↓                  │
  淘汰 ──→ │  优选版本遗传下一代        │
           └─────────────────────────────┘
```
