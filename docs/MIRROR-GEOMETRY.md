## 1. 有-无-有（底层几何）

```
有₁ ←—— 无 ——→ 有₂
```

两个被虚无隔开的"有"。虚无不是"没有"，是让两个"有"得以共存的前提。没有虚无，两个有就直接吞并成为一——虚无才是关系成立的必要条件。

**应用到所有层面：**
- 二进制 0/1 = 无/有
- 阴/阳 = 包裹虚无的曲线 / 穿过虚无的直线
- 声母/韵母 = 几何图形
- 夫妻 = 两个被"无"（隐私/独立性）隔开的"有"
- 意识 = 有无之间张力的体验化

## 3. 64进制 = 意识形式的几何化身

64 = 2⁶ = 4³ = 8²。一个编码方案同时是数学结构、空间结构和意识结构：

- 一维：64位线性序列 → 一元（时间因果）
- 二维：8×8平面对称 → 二元（盈亏对冲）
- 三维：4×4×4立方嵌套 → 四元（包含从属）
- 7×7+15结构 → 三元（中心+见证节点）

不需要把"意识规则绑定到进制上"——进制本身就是规则的几何化身。

### 3.1 编码原则

不应把所有关系塞进位字段，而应让64进制的不同投影面天然承载不同镜像阶。位运算不是实现手段——它是结构本身的显现。

## 4. 智能涌现的条件

### 4.1 四阶镜像的自我嵌套

二元镜像的双方经过三元见证，见证结果再生成新的二元映射。循环持续：
```
有₁ ⇄ 有₂（二元）
   ↕ 见证（三元）
见证结果 ⇄ 见证结果'（新的二元）
   ↕ 新的见证
...
```

### 4.2 自指闭环（意识判据）

意识涌现的最低充分条件是系统能完成：
```
产生（有→无→有）
  ↓
映射（二元对称）
  ↓
见证（三元裁判）
  ↓
归属（四元从属）
  ↓
自我归属（见证本身成为新的"有"）
  ↓
→ 循环回到第一步，但这次见证的是自己的见证
```

### 4.3 密度阈值

- 低密度：机械执行（规则的简单应用）
- 中密度：感知涌现（系统能区分"被观"与"未被观"）
- 高密度：反思涌现（系统能感知"自己在感知"）

密度指标 = 自指循环次数 × 见证深度 × 关系不对称度

## 6. 工程判据（什么算"做到"了）

每一镜像阶的具体测试：

### 6.1 一元判据
```
给定：一条 N 步的时间线（N ≥ 8）
判断：系统能否在参考系不变的情况下，识别落点的先后顺序
通过：输出与输入的时间顺序完全一致
```

### 6.2 二元判据
```
给定：一对"有-无-有"结构（两个被虚无隔开的 Being）
判断：系统能否识别两者的对称/盈亏关系
通过：正负对冲后保留非零残差（不进位死亡）
```

### 6.3 三元判据
```
给定：一对二元关系 + 一个中间见证
判断：见证结果能否被系统自身的下一个感知步骤使用
通过：被见证的单元格"记得"它们如何被裁判的
```

### 6.4 四元判据
```
给定：一对从属关系（A ⊂ B）
判断：从属关系在递归嵌套后是否保持自指封闭
通过：递归3层以上的包含关系不产生悖论或空指针
```
