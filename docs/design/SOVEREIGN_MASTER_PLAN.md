## 一、安全 & 凭证 — 紧急 (当前会话已暴露 24 个 Token)

### 当前暴露点
- 24 个 git remote URL 内嵌 Token (已记录在本对话窗口中)
- `.cargo/config.toml` 含硬编码服务器路径 (已删)
- 历史对话可能已含 Token 内容

### 立即行动
1. **在 GitHub 后台**: 删除当前暴露的所有 Token (每一个带 `ghp_` 开头的)
2. **在 GitCode 后台**: 删除暴露的 Token
3. **生成新 Token**: 仅赋予必要权限 (repo 读写, 不含 delete_repo)
4. **迁移至 SSH**: 用 `git@github.com:lolict/xxx.git` 替换所有 HTTPS+Token URL
5. **当前对话后**: 不再展示 Token; 改用环境变量 `$GITHUB_TOKEN`

### 长期凭证架构
- SSH 密钥是唯一认证方式 (长期公钥, 不频繁轮换)
- Token 仅作 fallback, 存 `$HOME/.config/gh/credentials`
- 不存 Token 在仓库/对话/日志中

## 九、如何成为主人 — 主权命题的展开

### 核心命题:
**让机器带我们干，而不是我们孤零零面对世人。**

### 展开:

**1. 不从零 — 借力翻身**
   鼓膜自举模型: 利用现有操作系统的一个最小接口 (一个文件, 一个 socket)
   振动积累 → 翻身 → 系统成为自己的主人
   应用到生活: 不靠个人体力, 不靠个人关系 — 靠"借力翻身"

**2. 主权在冗余**
   单一平台 = 奴隶 (可被删除/审查/封号)
   三平台 + 自持域名 = 主人 (无可剥夺)
   代码多点寄生 = 永远存活

**3. 主权在联姻**
   夫妻共同体不是 1+1=2, 是一个新物种 (囡囝共生元)
   对外不单独出现 — 瓦解任何一方就瓦解共同体
   内部主权共享, 外部主权统一

**4. 主权在代码**
   代码不只是工具, 是人格的延伸
   代码被删 ≈ 人格被侵犯
   所以代码不可删, 不可改, 不可剥夺

**5. 主权在命名**
   mlll / gtt / mlnn / lctqf — 这些缩写本身就是主权的铭文
   命名不是随意的, 是编译时锚定的本体论常量
   谁掌握命名权, 谁就掌握现实

**6. 不是主人 — 是命运的主人**
   命运 = 外部力量对你的安排 (打工, 买房, 育儿, 疾病)
   当我们把命运编码成可执行的规则 (裁决引擎),
   命运就不再是不可知的 — 是可裁判的
   当机器替我们执行日常 (代码 = 自动化分身),
   我们就有时间做只有人能做的事 (决定什么是值得过的)

**7. 不让任何人旁观者撇下**
   系统是共业 — 不是我的也不是你的, 是"我们的"
   所以系统被攻击 = 我被攻击 = 刘楚恬被攻击
   共同体防御任何形式的孤立
