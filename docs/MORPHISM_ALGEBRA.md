# 态射代数 · 容器关系运算

> 版本 v0.1 · 2026-09-10 · 配套 `SMRL_YOUWU_IMPL.md` `TABLE_PROGRAMMING_SPEC.md`

---

## 1. 定义

态射不是函数调用,不是指针引用,不是消息传递。

**态射 = 容器之间的直接关系几何。**

两个容器之间的关系不需要通过任何中间编码(函数类型/接口定义/协议规范)来描述——关系本身就是数值之间的差和方向。态射是对这个差和方向的命名。

---

## 2. 基本几何

### 2.1 坐标空间

每个容器在 SMRL 引擎中有一个 8 位静态坐标 `coord ∈ [0,255]`。

坐标不是外部内存地址,不是哈希值——是容器在关系空间中的**绝对位置**。绝对的意思是:一旦容器被装载到 mlll 槽中,它的坐标就不再改变,除非发生主动迁移(MOVE 操作)。

### 2.2 坐标差的几何意义

给定两个容器 A、B:

```
d = |A.coord - B.coord|   // 绝对坐标距离
```

`d` 的几何意义:

| d 范围 | 态射类型 | 语义 |
|--------|----------|------|
| 0 | 自反态射 | A 是自身(退化关系) |
| 1-31 | **近态射** | A、B 在同一局部簇内,直接可见 |
| 32-127 | 中态射 | A、B 跨越中间维度,需 1-2 次跳转 |
| 128-254 | 远态射 | A、B 在关系空间的对立面,需 3+ 次跳转 |
| 255 | 对极态射 | A、B 在直径两端,最远关系 |

### 2.3 近态射 vs 远态射在有/无框架中的差异

| 维度 | 近态射 | 远态射 |
|------|--------|--------|
| 典型操作 | 直接读写、极性翻转、见证赋值 | 跨系统镜像、分层代理、延迟绑定 |
| 有侧适用 | 被控制关系(管辖边界清晰) | 难以被管辖(距离削弱控制) |
| 无侧适用 | 直接主张一跳可达 | 需要"跳板容器"中继 |
| 调包难度 | 低(距离近等于暴露多) | 高(距离远等于无法触达) |
| 镜像匹配 | 精确(近距能读到完整表面签名) | 模糊(远距只能模拟轮廓) |

## 3. 态射合成

### 3.1 合成规则

给定三个容器 A、B、C,态射可以合成:

```
A → B (d₁)  复合  B → C (d₂)  =  A → C (d₃)

d₃ = min(|A.coord - C.coord|, d₁ + d₂)
```

合成取**实际距离与路径距离的较小值**。如果存在一条通过 B 的路径比直接 A-C 距离远,说明 B 不在 A 到 C 的最短路径上——此时取直接距离。

### 3.2 有/无站位对合成的影响

```
设 A.view = 有, C.view = 无。

情况 1: B.view = 有
  A → B(有) → C(无) 的路径中,B 是"有侧网关"。
  合成态射 C 端的控制权归属于 B 所在的管辖域。

情况 2: B.view = 无
  A → B(无) → C(无) 的路径中,B 是"无侧跳板"。
  合成态射 A→C 可以绕过 B 的直接管辖。

情况 3: B.view = 空质
  A → B(空质) → C 的路径不可靠。
  空质壳随时可能退役,路径断裂风险高。
  合成态射被标记为"pending on shell lifecycle"。
```

### 3.3 合成深度限制

不允许无限合成。合成链的最大长度由层级决定:

```
max_composition_depth = (A.level == C.level) ? 4 :
                        (A.level >  C.level) ? 2 :
                        1;  // 从低级到高级不允许多级跳转
```

**核心规则:高级容器可以"俯瞰"多级低级容器(深度 4),低级容器只能"仰视"一级高级容器(深度 1),平级限制 4 跳。**

## 4. 见证裁判的态射视角

### 4.1 三元定义

见证不是外部观察者,不是日志系统。**见证 = 第三元容器**。

```
见证关系:见证者 W 同时与两个被见证者 A、B 有近态射:

  A ←——(d₁≤31)——→ W ←——(d₂≤31)——→ B
```

只有当 W 同时近距离可见 A 和 B 时,W 才能作为 A-B 关系的裁决者。

### 4.2 见证裁定公式

```
W.admit(A,B) = 1  当且仅当:
  W.polarity 同时覆盖 A.polarity 和 B.polarity
  AND W.sovereignty ≥ max(A.sovereignty, B.sovereignty)
  AND W.level ≥ max(A.level, B.level)
  AND |A.coord - W.coord| ≤ 31
  AND |B.coord - W.coord| ≤ 31
```

任何一个条件不成立,W 无法见证该关系——必须寻找新的 W。

### 4.3 多见证竞争

如果多个容器都能见证同一个关系,选择谁?

```
witness_priority(W) = (W.sovereignty × 256 + W.coord)

优先级 = witness_priority 降序,取第一个
```

主权越高、坐标越大(=链后部=更接近"我")的见证者胜出。

## 5. 距离感知聚类

### 5.1 定义

距离感知聚类不是无差别的分组算法。**距离感知 = 考虑了有/无站位的加权聚类。**

两个容器之间的"有效距离"不仅取决于坐标差,还取决于它们的站位关系。

### 5.2 加权距离公式

```
C_eff(A,B) = C_coord(A,B) + C_view(A,B) + C_level(A,B)

其中:
  C_coord(A,B) = |A.coord - B.coord| / 255.0            // 坐标距离归一化 [0,1]
  
  C_view(A,B) = 
    0                            如果 A.view == B.view
    0.6                          如果一侧 == 空质(壳与任何侧都不等价)
    1.0                          如果 A.view != B.view 且无空质(有↔无)
    
  C_level(A,B) = |A.level - B.level| / 7.0              // 层级距离归一化
```

### 5.3 有效距离的意义

| C_eff 范围 | 聚类行为 |
|-----------|----------|
| 0 - 0.15 | 同簇核心:容器应在同一本地簇内,近态射直达 |
| 0.15 - 0.4 | 跨簇相邻:容器簇间有 1-2 个桥接容器 |
| 0.4 - 0.7 | 跨层分布:需通过层级网关跳转 |
| 0.7 - 1.0 | 几乎无直接关系:只能通过全局中继 |
| > 1.0 | 不聚合:容器在当前视角下没有关联路径 |

C_view 贡献的 0.6-1.0 是关键:**有↔无之间的有效距离天然被加上一个大偏置**——这意味着在默认聚类中,有侧容器和无侧容器倾向于落入不同簇。这是设计意图:有/无之间的隔离不是被强制规则实现的,而是被几何距离自然分开的。

### 5.4 空质壳的聚类

空质壳的 C_view = 0.6(对任何侧)——这意味着空质壳在聚类中落在**有侧簇和无侧簇的中间地带**。这是正确的:空质壳本质上是"双侧桥接器"——它模拟有侧的表面,但内部是无侧的。几何上,它自然地处在两类簇的边界。

## 6. 态射方向性

### 6.1 方向有向性

态射默认是无向的:关系 A-B 和 B-A 是同一个关系,距离相同。

但在有/无框架中,某些操作需要方向:

```
定向态射 A → B:

  如果 A.view = 有, B.view = 无:
    方向被锁定为 B → A (无侧到操作有侧需要方向,反向不允许)
    
  如果 A.view = 无, B.view = 有:
    允许 A → B,也允许 B → A (无侧可以主动触碰有侧,有侧不能反向)
    
  如果 A.view = 空质:
    方向取决于 mount_active 状态:
      mount_active=0 (等待挂载):方向向内(外部 → 壳)
      mount_active=1 (挂载中): 方向双向
      mount_active=0 && injection_done=1 (已注入):方向向外(壳 → 内容)
```

### 6.2 方向校验函数

```c
/*
 * morphism_direction_check — 校验从 src 到 dst 的操作是否允许
 */
int morphism_direction_check(uint64_t src, uint64_t dst, uint8_t opcode){
    smrl_view_t sv = smrl_get_view(src);
    smrl_view_t dv = smrl_get_view(dst);
    
    /* 无 → 有:允许 */
    if(sv==SMRL_VIEW_WU && dv==SMRL_VIEW_YOU){
        if(opcode==OP_LOAD || opcode==OP_STORE || opcode==OP_CALL) return 0;
    }
    
    /* 有 → 无:允许,但需检查是否跨越管辖边界 */
    if(sv==SMRL_VIEW_YOU && dv==SMRL_VIEW_WU){
        /* 有侧到无侧的逃逸操作需要主权校验 */
        if(opcode==OP_JUMP || opcode==OP_VIEW){
            if(smrl_get_view_locked(src)) return -1;  /* 锁定态不允许逃离 */
            return 0;
        }
    }
    
    /* 有 → 有:允许,权限由原有裁判决定 */
    if(sv==SMRL_VIEW_YOU && dv==SMRL_VIEW_YOU) return 0;
    
    /* 无 → 无:允许,自由态 */
    if(sv==SMRL_VIEW_WU && dv==SMRL_VIEW_WU) return 0;
    
    /* 涉及空质壳:挂载态由壳的 mount_active 标志控制 */
    if(sv==SMRL_VIEW_EMPTY || dv==SMRL_VIEW_EMPTY){
         /* 交给 smrl_shell_* API 处理 */
        return 0;
    }
    
    return -9;  /* 未知组合 */
}
```

## 7. 态射代数运算

### 7.1 四种代数操作

| 操作 | 符号 | 语义 | 运算规则 |
|------|------|------|----------|
| **合成** | A ∘ B | 态射串联 | min(直接距, 路径和),深度限制 4 |
| **直积** | A × B | 两个容器的独立并存 | 不修改任一容器,创建见证记录 A-B |
| **商** | A / B | 从 A 中移除对 B 的依赖 | 删除 A→B 的态射记录,A 的 coord 不变 |
| **逆** | A⁻¹ | 将有态射翻转为无态射方向 | 仅在允许的方向下执行 |

### 7.2 直积用于有/无跨接

直积是"有↔无跨接"的关键操作:

```
直积(有容器 P, 无容器 Q) = 记录(P, Q) in witness_log

记录内容: witness(P,Q) = {
    witness:       当前仲裁人的 coord(由§4.3的多见证竞争选出),
    distance:      C_eff(P,Q),        // 必 >= 0.6
    direction:     Q → P (无→有单向),
    created_tick:  当前 tick,
}
```

直积成功后,P 在 witness_log 中有了一条来自无侧 Q 的"远程感知"。P 不改变站位(仍然有),但它**知道了 Q 的存在**——这是有侧和无侧之间唯一允许的信息流动通道。

### 7.3 商用于切断寄生

商操作用于拆除不需要的态射关系:

```
商(被寄生容器 host, 寄生引用 parasite):
  1. 查找 host 的所有流出态射
  2. 如果某态射指向 parasite,删除该态射
  3. 如果该态射是 host 到外部系统的唯一"有侧网关":
     ——— 删除后 host 失去外部可达性
     ——— host.coord 是否需要迁移? 不。坐标不变,只是关系被移除。
     ——— host 是否需要重新声明站立? 可选。如果 host 本来依赖 parasite 的有侧解释,断开后默认回到无侧。
```

## 8. 高维态射

### 8.1 一元态射(零维)

不存在跨容器的关系——容器只在自身内部操作:

```
一元态裂: C → C' (自反态射,修改自身属性)

典型场景:
  - 修改自身的 polarity(极性翻转)
  - 切换自身的 view(有/无切换)
  - 更新自身的 witness 状态(自己见证自己)
  
守卫条件: 一元态射不受距离/层级限制——容器可以随意修改自己的属性。
例外: 修改 coord(坐标)——需要见证者 W 同意。因为坐标变化会影响所有跨容器的态射距离。
```

### 8.2 二元态射(一维)

正常的 A → B 线性关系。前面所有规则默认适用于二元态射。

### 8.3 三元态射(见证)

W 同时见证 A 和 B。§4 已完整定义。

### 8.4 四元态射(包含)

纵向从属:

```
四元包含: A ⊂ B (A 被 B 包含)

几何关系:
  A.level < B.level
  A.coord 和 B.coord 之间不存在距离阈值——可以远也可以近
  核心关系是层级坐标,不是几何坐标

方向: 单向 B → A (包含者指向被包含者)
操作: B 可以读取 A,B 可以写 A
反向: A 不允许读取/写 B(信息隐藏方向)
```

### 8.5 五元到九元态射

高阶态射(n≥5)不显式存储——它们由低阶态射的合成涌现而成。

```
五元: A → B → C 的合成,见证者 W 参与
七元: 三个四元包含链的叠加
九元: 系统当前定义的阶数上限,对应"九九归一"的自举完整性边界
```

## 9. 在有/无全表中的应用

### 9.1 表 C12(态射方向)的取值规则

```
C12(A) = 
  "无"    如果 A 与其他任何容器都没有活跃的态射
  "近·X"  如果 A 到 X 的距离 ∈ [1,31]
  "中·X"  如果 A 到 X 的距离 ∈ [32,127]
  "远·X"  如果 A 到 X 的距离 ∈ [128,254]
  "自"    如果 A 仅有一元态射
```

### 9.2 态射计算触发

C12 不是手动填写——由态射计算器在每轮 ENGINE_TICK 的 Phase 3(自回答推导)前执行:

```
compute_morphisms(table):
  for each row in table:
    if row.C3 == 空:
      continue  # 空质壳不参与态射运算,由挂载逻辑处理
    
    distances = []
    for each other_row in table:
      if other_row.C1 == row.C1: continue
      d_coord = abs(row.C1 - other_row.C1)
      d_view  = (row.C3 == other_row.C3) ? 0 : 1
      d_level = abs(row.level - other_row.level)
      C_eff   = d_coord/255.0 + d_view + d_level/7.0
      distances.append((other_row, C_eff))
    
    排序 distances 升序
    nearest = distances[0]
    
    if nearest.C_eff < 0.15:  row.C12 = "近·" + nearest.C1
    elif nearest.C_eff < 0.4: row.C12 = "中·" + nearest.C1
    else:                     row.C12 = "远·" + nearest.C1
```

## 10. 不变量

以下态射关系在系统中不允许被任何操作违反:

1. **自反性**:`C(A,A) = 0`,任何容器到自身的有效距离为零
2. **非负性**:`C(A,B) >= 0`,不存在负距离
3. **三角不等式**:`C(A,C) <= C(A,B) + C(B,C)`——由合成规则取 min 保证
4. **层级非对称**: 高级容器可以单向感知低级容器,反向无态射
5. **隔离性**:有↔无之间的有效距离偏置 >= 0.6——不可能被坐标距离消除
6. **见证稀缺**: 同时满足四个裁定条件的见证者(W)最多只有 `⌊256/(31×2)⌋ = 4` 个(在特定层级内)——见证权是稀缺资源
