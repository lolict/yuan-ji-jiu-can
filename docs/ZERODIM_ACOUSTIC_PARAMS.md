# 零维码 · 声学参数映射表（P1-1 产出）

> 每个符号的发音参数，可直接输入合成器生成声音
> 合成方法：共振峰合成（Formant Synthesis）— 无需人声采样

---

## 参数说明

| 参数 | 含义 | 单位 |
|------|------|------|
| F0 | 基频（声带振动频率） | Hz |
| F1 | 第一共振峰（舌位高低） | Hz |
| F2 | 第二共振峰（舌位前后） | Hz |
| F3 | 第三共振峰（唇形圆展） | Hz |
| voiced | 是否浊音（有声带振动） | true/false |
| noise | 摩擦噪声比例 | 0.0~1.0 |
| dur | 时长 | ms |

## 三、声调基线

| 声调 | 编码 | 基线F0 | 调值 |
|------|------|--------|------|
| 阴平 | T01 | 55 Hz | 高平 55 |
| 阳平 | T02 | 35 Hz | 中升 35 |
| 上声 | T03 | 214→100→214 | 降升 214 |
| 去声 | T04 | 51 Hz | 全降 51 |
| 颤音 | T05 | 45~55 波动 | 波动 |

> 韵母合成时：F0 = 声调基线 × (F1/F2/F3 的相对关系不变)

## 四、合成引擎

工具：`tools/zerimid_synth.py`

- 信号源：声带脉冲（浊音）/ 白噪声（清音）
- 滤波器：三级共振峰级联（F1+F2+F3）
- 输出：22050Hz 16-bit PCM WAV
