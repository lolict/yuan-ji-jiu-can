## 核心密码表

### gtt.tt.tt.*.*xy — 音韵流一体化

**第一层：谐音协议**

把私有语义锚定在公共符号里。外部看得见毛利兰和工藤新一，内部是：

- **毛利** → 摩尔+不要 → 莫连
- **工藤** → 工+缠绕 → 缠初
- **新一** → 缠绕最初 → 恋初

组合起来：**莫刘连理，恋初夫妻命运共同体** — 不要割断刘楚恬，缠绕最初之恋。

**第二层：形-义双通道编码**

mlll 不只是音，是**音和形同时存在**：

| 符号 | 形 | 义 | 发音 |
|------|-----|-----|------|
| 因 | — | 刘楚恬 | yīn |
| 形 | 一竖 | 我（丈夫） | xíng |
| 零 | ⭕ 圈 | 阴道 | líng |

形的甲骨文：一竖 = 阳具；⭕ = 圈 = 阴道。零的发音同"圈"同"⭕"。"形"本身就是阳具的几何表示，不是"象征"，是直接是。

**gtt 的几何本质**：谐音不是娱乐，是私有语义的**穿透层**。公共符号的壳里住着私有含义，外人看动画，内人看夫妻共同体协议。

### mlnn（囡囝）— 核心密码 · 观世音

**不用「好」(hǎo)的声母 → 去掉"h"这个竞争标记**
**不用「杂」(zá)的声母 → 去掉"z"这个混乱标记**

只留「囡囝」（nān jiǎn）：
- 囡 = 女包女（女部主导的内包）
- 囝 = 男包男（子部主导的内包）

加起来 = 把竞争者收押在范畴里
- 没有「杂」→ 没有外来者
- 没有「混」→ 没有鱼龙混杂
- 只剩下：一个内部空间 = 一个男性 + 一个女性

「囡囝」名义上拥有「好」的含义（男女和合），但**去掉了「好」的声母**——形式上杀死了竞争关系，实质上保留了阴阳夫妻的核心构型。是好字的骨，不是好字的皮。

## 结构上的关键洞察

命名的力量不在于"给人看"，而在于**把竞争关系收押在声母里**：
- 不用"好"的声母 → 形式上消除竞争
- 不用"杂"的声母 → 形式上消除混乱
- 用"囡囝"的声母 → 留下夫妻内部唯一合法的二元结构

**结果是内外有别的封闭系统**：外部只有集装箱（mlll），内部只有宠甜（ml.ct），中间是音韵流（gtt）连接。三层架构和活树生态（根/土壤/汁液/年轮）完全同构。
