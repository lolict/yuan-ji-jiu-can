# 跨平台指令集机器码对齐参考

> 注：MTK（联发科）芯片采用ARM Cortex-A系列核心，无独立指令集，其机器码即ARM机器码。

## 基础编码特性对比

| 架构 | 编码长度 | 字节序 | 基础格式数 | 指令条数(基础) |
|------|---------|--------|-----------|--------------|
| x86/x64 | 变长 1-15B | 小端 | 前缀+Opcode+ModRM+SIB+disp+imm | ~1000+ |
| ARM A64 | 定长 4B | 大端 | 条件码+操作码+寄存器+立即数 | ~200+ |
| ARM Thumb | 定长 2B / 4B | 大端 | 压缩格式 | ~150+ |
| RISC-V RV32I | 定长 4B | 小端 | R/I/S/U/B/J 6种 | 40 |
| MIPS32 | 定长 4B | 大端 | R/I/J 3种 | ~80 |

## 核心指令对齐表

### 1. 数据传输类

#### MOV / LDR / LW / LDI（立即数加载）

| 架构 | 汇编编码 | 机器码示例 | 操作 |
|------|---------|-----------|------|
| x86 | `MOV EAX, 0x1234567` | `B8 78 56 34 12` | EAX ← imm32 |
| x86 | `MOV ECX, 9` | `B9 09 00 00 00` | ECX ← 9 |
| ARM64 | `MOV X0, #0x1234` | `D2824680` | X0 ← imm16 |
| ARM32 | `MOV R2, #0x33` | `E3 A0 20 33` | R2 ← 0x33 |
| RISC-V | `LUI X5, 0x12345` | `012342B7` | X5 ← imm20 << 12 |
| MIPS | `LUI $T0, 0x1234` | `3C 08 12 34` | $T0 ← imm16 << 16 |

#### LOAD（内存 → 寄存器）

| 架构 | 汇编编码 | 机器码 | Operation |
|------|---------|--------|-----------|
| x86 | `MOV RAX, [RBX]` | `48 8B 03` | RAX ← mem[RBX] |
| ARM64 | `LDR X0, [X1]` | `F9400020` | X0 ← mem[X1] |
| ARM32 | `LDR R4, [R5]` | `E5 95 40 00` | R4 ← mem[R5] |
| RISC-V | `LW X3, 0(X1)` | `0000A183` | X3 ← mem[X1+0] |
| MIPS | `LW $T0, 0($S1)` | `8E 28 00 00` | $T0 ← mem[$S1+0] |
| MIPS | `LW $T0, 20($S1)` | `8E 28 00 14` | $T0 ← mem[$S1+20] |

#### STORE（寄存器 → 内存）

| 架构 | 汇编编码 | 机器码 | Operation |
|------|---------|--------|-----------|
| x86 | `MOV [RAX], EBX` | `89 18` | mem[RAX] ← EBX |

## 各架构详细编码格式

### x86/x64 变长编码

```
[REX prefix] [Opcode 1-3B] [ModRM] [SIB] [disp 0/1/2/4B] [imm 0/1/2/4B]
```

| 组件 | 位数 | 说明 |
|------|------|------|
| REX | 4bit | 64位模式前缀 (0100WRXB) |
| Opcode | 8-24bit | 操作码 |
| ModRM | 8bit | mod(2) + reg(3) + r/m(3) |
| SIB | 8bit | scale(2) + index(3) + base(3) |
| disp | 8/16/32bit | 偏移量 |
| imm | 8/16/32/64bit | 立即数 |

**ModRM 结构：**
- mod=11: 寄存器寻址
- mod≠11: 内存寻址
- reg: 寄存器编号或操作码扩展
- r/m: 寄存器或内存寻址模式

**SIB 出现条件：** ModRM.r/m = 100 且 mod ≠ 11

### ARM A64 定长编码

每条指令32位，大端序，基础格式：

```
[cond:4][op1:5][...具体字段因指令类型而异...]
```

**主要指令类型：**

| 类型 | 位分配 |
|------|--------|
| 数据处理（寄存器） | cond(4) + op1(5) + ... |
| 加载/存储 | cond(4) + op1(5) + ... |
| 分支 | cond(4) + 101(3) + ... |
| 系统 | 1111... |

**条件码（cond 字段）：**
- 0000: EQ (相等)
- 0001: NE (不等)
- 1110: AL (无条件)

### RISC-V RV32I 定长编码

四种基础格式，所有字段固定位置：

| 字段 | 位置 | 说明 |
|------|------|------|
| opcode | [6:0] | 7位操作码 |
| rd | [11:7] | 目标寄存器 |
| funct3 | [14:12] | 功能码3 |
| rs1 | [19:15] | 源寄存器1 |
| rs2 | [24:20] | 源寄存器2 |
| funct7 | [31:25] | 功能码7 |
| imm | 各格式不同 | 立即数（位置固定） |

**格式编码差异：**
- R-type: funct7 | rs2 | rs1 | funct3 | rd | opcode
- I-type: imm[11:0] | rs1 | funct3 | rd | opcode
- S-type: imm[11:5] | rs2 | rs1 | funct3 | imm[4:0] | opcode
- B-type: imm[12\|10:5] | rs2 | rs1 | funct3 | imm[4:1\|11] | opcode
- U-type: imm[31:12] | rd | opcode
- J-type: imm[20\|10:1\|11\|19:12] | rd | opcode

### MIPS32 定长编码

三种格式，所有指令32位：

| 类型 | opcode | rs | rt | rd/shamt/funct | 立即数/地址 |
|------|--------|----|----|---------------|------------|
| R-type | 6bit | 5bit | 5bit | rd(5) + shamt(5) + funct(6) | - |
| I-type | 6bit | 5bit | 5bit | immediate(16) | - |
| J-type | 6bit | address(26) | - | - | - |

## 字节码与三维编码映射

### 自定义字节码层（容器包装层）

将不同架构的机器码映射为统一的16位或32位容器：

| 架构 | 原始编码 | 容器字节码（16位/32位） | 封装方式 |
|------|---------|----------------------|---------|
| x86 | 变长 | `[opcode:8][modrm:8]...` | 前缀识别 |
| ARM64 | 定长32B | `[cond:4][op:28]` | 完整映射 |
| RISC-V | 定长32B | 原样 | 透明传输 |
| MIPS32 | 定长32B | 原样 | 透明传输 |

### 三维进制编码（几何化身）

以 (x, y, z) 坐标表示指令语义场：
- x轴：操作码类别（算术/逻辑/控制/...）
- y轴：操作数类型（寄存器/立即数/内存）
- z轴：寻址模式/偏移量/条件

每个坐标点对应一个「语义向量」，该向量可被编码为256位或512位标识，再映射为字体的字形轮廓数据。
