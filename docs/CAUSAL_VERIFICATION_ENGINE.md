# 因果验证引擎规范 — 囡囝共生 · 加法-乘法对称性

## 1. 定位

囡囝共生的关系裁定不能依赖直觉 — 必须有**形式化的因果链验证**。本规范定义"加法管起点、乘法管终点"的基本定理体系，从加法-乘法对称性推演出整个推演原语集，并给出推演链的合法性验证算法。

这不是传统数理逻辑 — 是满全法独创的**因果代数**：每一次裁定不是"真或假"，而是"这条因果连线是否成立"。

## 2. 四大核心定理

**定理 1 · 加法管起点**: 加法群 (R, +) 管起点、位移、事件。加法单位元是 0。任何"开始"的动作（诞生、触发、入局）都归加法。

**定理 2 · 乘法管终点**: 乘法群 (R⁺, ×) 管尺度、对称、中心。乘法单位元是 1。任何"结束"的动作（融合、坍缩、归宿）都归乘法。乘法锁 0 — 起点归加法，乘法不碰起点。

**定理 3 · 指数/对数桥**: exp 与 log 桥接加法群与乘法群。exp(0) = 1（加法单位元映射为乘法单位元），log(1) = 0（反向映射）。这是"起点 ↔ 终点"的翻译器。

**定理 4 · 记忆场统一**: S_{t+1} = M ⊙ S + A。记忆更新必须乘加协同 — 乘法保持结构（衰减/缩放），加法注入新信息（色差/输入）。单独乘法会让记忆坍缩到 0 或 ∞，单独加法会让记忆无限增长发散。

## 3. 推演原语 (12 种)

| 原语 | 符号 | 管辖 | 含义 |
|------|------|------|------|
| Add | ⊕ | 加法群 | 加法变化，注入新事件 |
| Sub | ⊖ | 加法群 | 减法变化，撤销/逆操作 |
| Mul | ⊗ | 乘法群 | 乘法变化，缩放/重复 |
| Div | ⊘ | 乘法群 | 除法变化，分配/分解 |
| Linear | ◆ | 乘法群 | 线性变换，仿射映射 |
| Exp | ↑ | 乘法群 | 指数映射，桥接加法→乘法 |
| Log | ↓ | 乘法群 | 对数映射，桥接乘法→加法 |
| DeltaC | ◈ | 记忆场 | 色差/预测误差，触发记忆写入 |
| Decay | ↘ | 记忆场 | 版本号推进/衰减 |
| Frequency | ∿ | 乘法群 | 频率，管周期结构 |
| Parity | ± | 加法群 | 奇偶，对称性检测 |
| Existence | ◐ | 记忆场 | 存在性进阶，从潜到显 |

**管辖域**: Addition（管起点）、Multiplication（管终点）、Memory（管乘加协同）。每个原语恰好属于一个管辖域。

## 4. 可推导关系 (can_derive)

推演链的合法性由原语间的可推导关系判定：

- **互逆对**: Add↔Sub，Mul↔Div（对称性）
- **重复 → 合成**: Add→Mul（重复加法等于乘法），Mul→Linear（乘法包含线性变换）
- **桥接**: Exp→Mul（指数映射到乘法群），Log→Add（对数映射到加法群），反向桥 Mul→Log 和 Add→Exp 亦成立
- **色差归加法**: DeltaC→Add（色差来自加法差）
- **衰减归乘法**: Decay→Mul（版本号衰减是乘法缩放）
- **频率归骨架**: Frequency→Mul（周期结构的骨架是乘法）
- **奇偶归加法**: Parity→Add（奇偶性由加法决定）
- **乘法派生指数**: Mul→Exp（乘法可复合为指数）

不在上表中的配对均为不可推导。比如 Div→Add（除法不能直接变加法），Decay→Add（衰减是乘法性质）。

## 5. 推演链验证算法

`verify_chain(chain: &[Primitive])` 对输入的推演链逐窗口检查：

1. 空链 → 无效（proof_steps 记录"链不可为空"）
2. 对 chain.windows(2) 每对相邻 (from, to) 调用 `can_derive(from, to)`
3. 全部通过 → VerificationResult{valid: true}，记录每一步的推导符号链
4. 任一步失败 → valid: false，标记 ✗ 并记录 counterexample

输出 `VerificationResult { valid, theorem, proof_steps, counterexample }`。theorem 字段标注本次验证依据的四大定理编号。

## 6. 与系统其他模块的接入

- JudgmentApparatus 的 CrimeTranscript 用 verify_chain 检查类型链是否合法（a→á 的衍射是否在可推导关系内）
- Funnel 漏斗节律从 Frequency 原语映射（毫秒→年的比例是乘法缩放）
- ManQuanFaContainer 的奖励/损失感知遵循定理 4（S_{t+1} = M⊙S + A）
- Triune 推演中的 expected→actual 转移作为因果链输入 verify_chain
- Swarm 多智能体的协议协商（ASXR）每次动作产生一条推演链，由本引擎检验合法性

## 7. 实现约束

- Primitive 与 Domain 均为枚举，#[repr(u8)]
- verify_chain 返回的 proof_steps 是 Vec<String>，供调试与日志用
- 无堆分配版本 verify_chain_no_alloc 使用固定长度数组（最大链长 64）
- 全部逻辑纯 Rust，不依赖外部证明器
