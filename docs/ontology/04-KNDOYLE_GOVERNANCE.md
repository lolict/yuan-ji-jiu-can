## 一、kndoyle 的重构

kndoyle 已从"柯南"的单纯对应，彻底改造为一套**框内-多数-管辖-夫妻**的关系逻辑。

### 1.1 读音拆解
```
kndoyle → 困难大 → 框内、躲、洞、多与二
```

### 1.2 语义映射
| 读音 | 指向 | 状态 |
|------|------|------|
| 困 | 框内 | 被管制的、处于低位的 |
| 难 | 躲/洞 | 隐藏、被动接收 |
| 大 | 多与二 | 多数、复数存在 |

### 1.3 系统角色
- **kndoyle = 被管辖层** = "多数"的集合符号
- 躲在框内、躲在洞里的多数存在
- 由"夫妻"作为管理者去驱动它

```
        ┌─────────────────────────┐
        │     夫妻 (加法/最窄)      │ ← 管理者
        │   hfqml + lctcf + fqmy   │
        └───────────┬─────────────┘
                    │ 管辖动力
                    ▼
        ┌─────────────────────────┐
        │     kndoyle (多数/最宽)   │ ← 被管辖层
        │   躲在框内、洞里的多数     │
        └─────────────────────────┘
```

### 2.1 夫妻 = 管辖动力的发出者
- 夫妻是最窄的存在（加法）
- 夫妻二人 = 爱人 = 管理者
- 夫妻不是感知节点，是**管辖动力的发出者**

### 2.2 kndoyle = 被管辖层
- kndoyle 是最宽的存在（乘法）
- kndoyle 是"多数"的状态
- 躲在框内、处于下位、被动接收

### 2.3 管辖动力
- 管辖那个多数的是"爱人就是夫妻二人"
- 夫妻统领多数
- 加法管理乘法

## 四、kndoyle 的治理规则

### 4.1 框内规则
- 多数躲在框内 → 被动、接收、被管理
- 框 = 加法的框架 = 夫妻定义的边界
- 框内的一切必须被加法解释

### 4.2 躲藏规则
- 躲 = 隐藏 = 不直接暴露
- 躲在洞里 = 被乘法覆盖
- 但躲藏本身被夫妻管辖

### 4.3 多数规则
- 多 = 乘法 = 最宽的状态
- 多与二 = 多数与少数的对立统一
- 多数被夫妻二人管辖

| 角色 | 定位 | 状态 | 权力方向 |
