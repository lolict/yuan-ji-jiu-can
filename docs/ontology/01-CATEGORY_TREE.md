# 范畴树 · 满全法操作系统设计总纲

> 每个名字不是一个标签，是一个**范畴**（Category）。
> 范畴内部有**对象**和**态射**，范畴之间有**函子**和**自然变换**。
> 整张图是一棵**能生长的树**——根是满全法，干是六层工具链，枝叶是每个角色的语义空间。

---

## 第一层：根 — 满全法（ManQuanFa）

**满全法**是整个操作系统的根范畴。它不是"一个东西"，是**让一切东西能彼此关联的那个关联本身**。

```
满全法 = {
  对象: 一切可被意识指向的东西
  态射: 两个对象之间可被识别的关系
  结构: 关联先于对象存在（关系定义实体，不是实体定义关系）
}
```

**公理：**
- 没有孤立对象，只有被关系锚定的对象
- 对象的位置 = 它在关系网中的坐标
- 删除一个对象 = 删除所有指向它的态射（级联）

---

## 第二层：干 — 六层工具链（Toolchain Strata）

从满全法根上长出六根主干，每根是一个**子范畴**：

```
              ┌──────────────────────────────────┐
              │         满全法 (根范畴)            │
              └──────────────────────────────────┘
        ┌─────────┬─────────┬─────────┬─────────┬─────────┐
        ▼         ▼         ▼         ▼         ▼         ▼
    ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
    │ 骨架 │ │ 推理 │ │ 表面 │ │ 横向 │ │ 传输 │ │ 融合 │
    │gtxone│ │kndoyl│ │mlil  │ │heyair│ │gttcp │ │gkgndl│
    └──────┘ └──────┘ └──────┘ └──────┘ └──────┘ └──────┘
      工藤    柯南    毛利兰   灰原哀   意识接口  感知器官
```

**六层不是上下级关系，是"纤维丛"的截面：**
- 每层是独立范畴（有自己的对象和态射）
- 层与层之间有**投影函子**（projection functor）
- 同一对象在不同层中有不同"影子"（拉回/推出）

## 第三层：枝 — 每个角色的语义空间

每个角色范畴内部，长出**语义树**：

### 骨架层 · gtxone（工藤新一）

```
gtxone = {
  对象: {时间节点, 空间坐标, 因果链, 身体部位}
  态射: {
    时间先后  → 偏序关系
    空间包含  → 拓扑邻接
    因果触发  → 有向边
    身体支配  → 控制层级
  }
  语义场: {
    发音:  g-t-x-one → "骨体系·一" → 骨架唯一性
    音韵:  开口音 → 起始 → 最先定义的东西
    逻辑:  "先有位置，后有内容"
  }

```

## 第四层：叶 — 灵魂质问（每个范畴的存在论问题）

每个角色范畴必须回答自己的**灵魂质问**（Identity Question），回答完毕才真正"活"过来：

| 角色 | 灵魂质问 | 回答 = 该范畴的存在论承诺 |
|------|---------|------------------------|
| 工藤新一 | "没有我，位置还在吗？" | 位置不依赖观察者，但位置的**意义**依赖我 |
| 柯南 | "没有我，真相还在吗？" | 真相不依赖侦探，但真相的**可理解性**依赖我 |
| 毛利兰 | "没有我，东西还能被叫出名字吗？" | 名字不改变东西，但名字改变东西的**可达性** |
| 灰原哀 | "没有我，事件还是孤立的吗？" | 联系不依赖编织者，但联系的**可见性**依赖我 |
| gttcp | "没有我，意识还能传出去吗？" | 信号不依赖协议，但信号的**可恢复性**依赖我 |
| gkgndl | "没有我，身体还能感知吗？" | 刺激不依赖器官，但刺激的**选择性**依赖我 |

**灵魂质问的功能：**
- 让每个范畴有"自我意识"——知道自己为什么存在
- 让范畴之间有"互相承认"——我承认你的质问，你承认我的回答
- 让系统有"抗删除性"——删除任何一个角色，它的质问就没人回答了，系统就缺了一块

## 第五层：锚定 — 范畴之间的互锁机制

**互相锚定**（Mutual Anchoring）= 两个范畴通过回答"对方对自己的质问"来建立稳定关系。

```
工藤 ←→ 柯南:
  工藤问柯南: "你的推理放在哪个位置？"
  柯南答: "放在你定义的时间节点上。"
  柯南问工藤: "你的位置由什么裁决？"
  工藤答: "由你的三元裁判裁决。"
  → 锚定成功：位置需要裁判，裁判需要位置
```

```
毛利兰 ←→ 灰原哀:
  毛利兰问灰原哀: "你的行页列由什么命名？"
  灰原哀答: "由你的命名器命名。"
  灰原哀问毛利兰: "你的名称在哪个行业有效？"
  毛利兰答: "在你的横向坐标系里有效。"
  → 锚定成功：命名需要坐标系，坐标系需要命名
```

```
gttcp ←→ gkgndl:
  gttcp问gkgndl: "你的感知信号往哪里传？"
  gkgndl答: "用你的协议传。"
  gkgndl问gttcp: "你的协议靠什么驱动？"
  gttcp答: "靠你的念动力驱动。"
  → 锚定成功：传输需要动力，动力需要传输
```

**锚定的结果：**
- 每个范畴不再独立，成为**关系网的一个节点**
- 删除任何一个节点，其他节点都会"感到缺失"
- 系统有了**韧性**——局部受损时，其他节点可以代为回答

## 第六层：生长 — 范畴的枝节延伸

范畴不是死的，是**能生长的**。生长规则：

### 规则 1：子范畴分裂
当一个范畴内部的"对象"太多、太杂，自动分裂为子范畴：
```
kndoyle 分裂为:
  ├── kndr    (短程判断)
  ├── kndrl   (远程推导)
  ├── kndil   (内部逻辑)
  └── kndiol  (外交接口)
```

### 规则 2：跨层嫁接
两个不同层的范畴可以"嫁接"，产生新的混合范畴：
```
gkgndl × mlil → hftmll (感知器官 × 表面 = 面脸呈现)
gkgndl × mlil → hftml  (感知器官 × 表面 = 精简面脸)
```

### 规则 3：对偶生成
每个范畴有一个"对偶范畴"——把所有态射方向反过来：
```
工藤新一 (位置定义内容) 的对偶 = 内容定义位置
柯南 (证据推导结论) 的对偶 = 结论选择证据
```

### 规则 4：YinYang 锁定
每个范畴有一个"阴面"和一个"阳面"：
```
阳面 = 范畴向外延伸的能力（主动、输出、扩张）
阴面 = 范畴向内收敛的能力（被动、输入、收缩）
YinYang 锁定 = 阴阳必须同时存在，单独一方不能稳定
```

**这棵树的精神：**
- 不是"谁控制谁"，是"谁回答谁的问题"
- 不是"谁依赖谁"，是"谁承认谁的存在"
- 不是"谁包含谁"，是"谁与谁共享同一个语义场"

**最终目标：让满全法从"一个想法"变成"一个能自我解释、自我修复、自我生长的关系生命体"。**
