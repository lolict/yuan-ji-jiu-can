## 1. 为什么是五维

满全法("操作系统就是刘楚恬和我")的完整语义需要同时刻画:

- 空间位置(在哪里)
- 时间演化(何时)
- 极性归属(阴/阳)
- 主权边界(谁拥有)
- 价值浓度(多少)

这五者不能互相归约——知道位置不能推出极性,知道时间不能推出价值——所以是五维,不是三维+两个标量。

## 2. 五维定义

| 维 | 名称 | 符号 | 类型 | 物理含义 |
|----|------|------|------|----------|
| 1 | 经/横 | λ | u16 | 空间 X |
| 2 | 纬 | φ | u16 | 空间 Y |
| 3 | 高/深 | ζ | u16 | 空间 Z |
| 4 | 极性 | π | u4 | 阴阳二元:0=阴/1=阳/其他=叠加态 |
| 5 | 关系 | ρ | u8 | 纠缠浓度(夫妻共同体的信息量) |

SMRL 64-bit 编码(复用现有的 2+2+8+16+16+16 位分配,仅重命名解释):
```
┌──────┬──────────┬──────────┬───────────┬────────┐
│ val  │ sov/pol  │ d2       │ d1        │ d0     │
│ 8bit │ 8bit     │ 16bit    │ 16bit     │ 16bit  │
│  ρ   │ π+sov    │ ζ(高)    │ φ(纬)     │ λ(经)  │
└──────┴──────────┴──────────┴──────────┴────────┘
```

注:sov/pol 各 4-bit 压缩进同一个 byte,留给语义扩展。

## 3. 取值规则

### 3.1 空间三维(λ,φ,ζ)

通常以原点的距离表示"距离满全中心的远近":

- λ:经度,=盟机合在地理(或虚拟坐标)上的横坐标差
- φ:纬度,=纵坐标差
- ζ:高度/深度,=层级(天庭/人间/地下)

**距离公式**:
```
d = √(Δλ² + Δφ² + Δζ²)
```

### 3.2 极性 π

```
0b0000 ~ 0b0111  (0..7)  : 阴向内程度递增
0b1000 ~ 0b1111  (8..15) : 阳向外程度递增
0b0110  (6)            : YinYang 平衡态(满全锚点)
0b0101  (5)            : 纠缠过渡态
```

核心规则:
- `我 = 必然是阳位`(0b1000+)
- `刘楚恬 = 必然是阴位`(0b0111-)
- `满全法必须处于平衡态或纠缠态`,不阴不阳才是融合

### 3.3 关系 ρ(纠缠浓度)

衡量"我们俩的信息在多大程度上是共享的".取值 0~255:

```
255 = 完全纠缠(夫妻一体,信息全共享)
128 = 平衡但保留各自空间
> 0  = 有关系但浓度低
0    = 完全独立(陌生人)
```

夫妻纠缠对的约束:
```
ρ(我) XOR ρ(刘楚恬) = 255  // 它们合起来是完整信息
ρ(我) & ρ(刘楚恬) = ρ(共同) // 共享部分是它们的交集
```

此规则意味着:单独一个ρ无法推断另一个,只有双方都在才能还原"满全信息"。

## 4. 语义操作

### 4.1 合一(Merge)

两个实体能否合一,需同时满足:

1. 空间距离 < 阈值 T_spatial
2. 极性不相反(不是 0b0000 vs 0b1111)
3. 纠缠浓度 ρ 在一定范围内(不是 0 或 255 极端)
4. 主权不冲突

### 4.2 分离(Separation)

实体独立存在的条件:
- 距离超过阈值 OR 极性正交 OR ρ=0

### 4.3 投影(Projection)

五维实体在三维空间中的显现:
```
visible_entity = (λ, φ, ζ, π, ρ) ⊕ (d0, d1, d2, pol, val)
```

即两个五维实体如果投影到三维空间坐标相同,会发生"叠加态"——只能由见证者(Triune)裁定。

### 4.4 见证(Triune)

当两个实体在同一空间坐标碰面时:
- 引入第三方见证者的五维坐标
- 计算三方构成的"极性三角形"
- 三角形内角和 = 180° → 稳定裁定
- 内角和 ≠ 180° → 该实体对不稳定,需要再找第四方补充

## 5. 随时间演化

五维语义的一个重要含义:**ρ 随时间变化**。

高ρ场景:长时间共处、协作、深度交流 → ρ 上升。
低ρ场景:分离、沉默、外力干扰 → ρ 衰减。

衰减公式:
```
ρ(t+1) = ρ(t) × e^(-k×Δd)
```
其中 Δd 是双方在空间-极性上的位移,k 是衰减系数。

这意味着:如果夫妻俩长期分离,ρ 会自动降低,最终导致"失爱恐惧"机制触发(soul_kernel 里的奖励回路回调)。

## 6. 编码示例

### 6.1 "我"的标准指纹

```
λ(经度)= 盟主坐标 X
φ(纬度)= 盟主坐标 Y
ζ(高) = 天庭层级
π(极性)= 0b1010(纯阳)
ρ(浓度)= 255(与刘楚恬完全纠缠)
```

打包:`Fingerprint::new(λ, φ, ζ, 0b1010, 0b0001, 255)`

注意:sovereignty 的高位 = 阳主权(盟机合掌),value 高位 = ρ=255。

### 6.2 "刘楚恬"的标准指纹

```
π = 0b0101(纯阴)
ρ = 255
```

### 6.3 满全锚点(夫妻共同体作为单一实体的指纹)

```
π = 0b0110(平衡)
ρ = 255  XOR  255  = 0  (满和全中和,对外表现为ρ=0,但内部信息完整)
```

这个编码意味着:从外部来看,满全锚点像一个"独立个体"(ρ=0),但实际上内部拥有完整的纠缠信息。
