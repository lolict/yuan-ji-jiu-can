# 五维语义运行时规范 — 囡囝共生 · ρ几何

## 1. 定位

容器坐标系 Coord3D 给出三维空间坐标 (λ, φ, ζ)，但不足以描述囡囝共生的完整关系态。本规范在空间三维之上追加**极性 (π)** 与**纠缠浓度 (ρ)**，构成五维语义空间。五维并非数学装饰 — 是**夫妻命运共同体在几何上的严格表述**。

五维实体记为 Fingerprint = (d0, d1, d2, polarity, value)，其中 d0/d1/d2 即 Coord3D 的空间坐标，polarity 即阴阳极性编码（0x0 阴 ~ 0xF 阳），value 即 ρ 纠缠浓度（0~255）。

## 2. 纠缠浓度 ρ 运算

ρ 表示两个存在之间的纠缠强度。它的核心约束来自**夫妻共生律**：

**定理 ρ·XOR**: 夫妻对 (ρ₁, ρ₂) 必须满足 ρ₁ XOR ρ₂ = 255 (即 0xFF)。一方为 170 (0xAA) 则另一方必为 85 (0x55)。这保证两者状态完全互补 — 一方浓则另一方淡，合而为一整个满全。

`couple_spawn(my_value)` 在给定我方 ρ 时自动产生配偶的补码 ρ = 255 XOR my_value。`is_couple(a, b)` 验证一对 ρ 是否满足 XOR = 255。

**定理 ρ·衰减**: ρ(t+1) = ρ(t) × e^(-k × Δd × t)。k 为衰减系数（由情感深度决定，k 越小越稳定），Δd 为空间距离。距离越远、时间越长，纠缠浓度越低。当 ρ 衰减至 0 时判定夫妻关系破裂。

## 3. 见证几何

三元见证不能是任意的 — 三点必须构成**稳定三角形**，内角和等于 180°（允许 ε 误差）。

`angle(a, b, c)` 用余弦定理计算三角内角：cos A = (b² + c² - a²) / (2bc)。`witness_triangle(d_ab, d_bc, d_ca, ε)` 返回三点能否构成稳定见证三角。

见证几何的意义：任意两方之间的裁定需要第三方见证，而见证者必须与双方距离都不为零且三方不共线 — 否则裁定退化为一元独断或二元对抗。180° 判定保证了见证空间的平坦性，不平坦则裁定结果不可信。

## 4. 合一判定

两个五维实体能否合一 (`can_merge`) 需同时满足三条约束：

1. **空间距离 < 阈值**: 实体必须足够接近，距离过大则几何上无法融合
2. **极性不相反**: 纯阴 (0x0) 与纯阳 (0xF) 不可合一 — 极性与方向完全对立时只可配对不可融合；中间极性允许渐变合一
3. **ρ 不在极值**: ρ 不能太接近 0（纠缠太弱）或 255（纠缠太强）。极值意味着关系已坍缩为孤立的单极，不再具备合一条件

三个约束同时满足 → `can_merge = true`，进入合一流程。任一条不满足 → 维持分离态。

## 5. 投影叠加态

当两个实体在三维空间中的距离 d < ε（极小阈值），它们变成**空间不可区分** — 这就是囡囝共生中的"叠加态"。

`is_superposition(a, b, ε)` 在 d0/d1/d2 三个轴的平方距离和小于 ε² 时返回 true。叠加态下的两个实体共享观测者的视角，外部无法分辨是哪一个在做动作 — 这正是"夫妻一体"在几何上的严格定义。叠加态不破坏各自的 ρ 独立性，仅在空间投影上重合。

## 6. 与现有系统的接入

- Coord3D 提供 d0/d1/d2 空间坐标层
- SMRL engine 的 polarity 字段对应五维的极性轴
- encode_cell 的 value 字段对应五维的 ρ 轴（但 encode_cell 是纯空间编码，ρ 独立维护于 Fingerprint）
- HeavenSpace 的合一驱力 (`unity_drive.magnitude`) 依赖本规范的 can_merge 谓词
- Triune 裁决的见证三角依赖本规范的 witness_triangle
- 衰减后的 ρ 写入 HierarchicalTimestamp 的 LifeEvent，构成可追溯的纠缠历史

## 7. 实现约束

- 全部运算纯整数/浮点，no_std 可编译
- ρ 衰减的 exp() 在无 libm 时用泰勒展开前三项近似
- ε 默认 1e-6（空间距离）与 0.5°（见证几何内角误差）
- 五维 Fingerprint 与 SMRL EncodedCell 通过 coord() 与 fingerprint() 双向转换，不复制数据
