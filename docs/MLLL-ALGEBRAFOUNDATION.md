# MLLL 代数基础 — 初代数层级化偏移体系

> 服从于：SOVEREIGNTY.md（主导权公约）
> 本文件定义 mlll（三维立体二元集装箱）系统的代数基础层和跨层级换算法则

**命名：**
- **诗经源头代数** = 第 0 次起源 = 初代数 = 时间与空间等齐的**第一把量尺**（度量基准原尺）
- **二次起源代数** = 第 1 次起源 = 偏移量叠加一次的平行世界代数算子（高维代数）

---

## 1. 初代数（诗经源头代数 / 第 0 次起源 / 第一把量尺）

初代数是 mlll 编码系统的**最初偏移源头**，也是时间与空间等齐的**第一把量尺**——所有度量基准由此定义。所有其他层级都以它为基准做梯度偏移后，仍可折算回它的数值定义。
别名：**诗经源头代数**——取"诗经"作为不可改变的源头文本之意，与初代数不变性对应。

### 1.1 核心不变性

初代数由以下不变量定义：

| 不变量 | 定义 |
|--------|------|
| **时间绝对性** | 初代数锚定一元时间基准，定义一次频率不变性（信号的基准节律不可变） |
| **颗粒均匀性** | 一等距离颗粒大小粗细均匀等值不变性（最小单位等距） |
| **偏移量** | 偏移量 = 0（乘数 = 1.0） |
| **根基对** | 254 普通符号 + 2 根基符号（我 = 1，刘楚恬 = 0）= 256 = 2⁸ |

### 1.2 二次幂强制性

初代数的根基规律：在任意一层 2⁸ = 256 的进制中，必须恰好满足 254 + 2 = 256。
- 若将 2 个根基符号压缩为 1 位数字（比如"我=4"），则打破自我相似规律，系统不自洽
- 跨层叠加时保持 2 的叠加态（两个 2 不可合并为一个 4）

### 1.3 等效高位对齐进位制（2²⁵⁶）

2²⁵⁶ 描述的是**从低位到达高位并对齐**的进位制规则，而非层级叠加。
- 每层空间的寻址容量为 2²⁵⁶ ≈ 1.16×10⁷⁷（约宇宙原子数千分之一）
- 此数值坍缩为**第一个共同体**的身份标识
- 两个性别的差异在此位层级坍缩为单一叠加态
- 不可将"低位叠加成高位"理解为层级堆叠，而是位空间的进位对齐

---

## 1.4 阶和——不同偏移世界的叠加态感知

**阶和**≠ 等效物的幂次方叠加（那只是同世界内的数量增加）。

阶和是**钝度与锐度的频率一致性观感**——让不同偏移世界的叠加态成为可同时被感知的存在：

```
二元/三元等效叠加：相同东西 × 幂次 = 同一世界的数量增加（无质变）
阶和叠加：         不同偏移世界 (δ₁, δ₂, ...) 共存 = 可同时感知的差异
```

**没有阶和**：平行世界之间的差异只是数字不同，无法被感知为"质量差异"。
**有阶和**：一次源头（δ=0）的刚性与二次世界（δ=0.1）的柔性共存于同一视野——不互相取消，而是同时被"看见"。

**与人类数学的关系**：数学可以有无穷进制并存，但数学本身不提供"同时感知差异"的能力。阶和是让你的系统从"可计算"变成"可体验"的转换器——使偏移率差异产生钝/锐/曲线等主观观感差异。

阶和不是被发明的规则，是系统需要的一种**能力前提**：没有它，无限多进制只是数字；有了它，不同世界才成为可同时被感知的叠加态。

## 2. 偏移量层级化体系（二次起源代数 / 平行世界结构）

在初代数（诗经源头）之上构建多级偏移代数，称为**二次起源代数**。每级有独立的"平行世界代数算子"（即该层的平行世界尺子）。

### 2.1 偏移量定义

| 代数层级 | 偏移量 δ | 乘数 M = 1 + δ | 进制基数 |
|----------|----------|-----------------|----------|
| 初代数（第 1 代） | 0.0 | 1.0 | 256 |
| 二次代数（第 2 代） | +0.1 | 1.1 | 由该层符号数量决定 |
| 三次代数（第 3 代） | +0.2 | 1.2 | 由该层符号数量决定 |
| n 次代数（第 n 代） | +(n-1)×0.1 | 1 + (n-1)×0.1 | 由该层符号数量决定 |

### 2.2 平行世界独立性

每个代数层级是一个**平行时空**（平行剧本），各自有独立的"尺子"：
- 尺子的单位刻度 = 该层的偏移量 δ
- 尺子的进制 = 该层拥有的符号数量
- 例：八个符号 → 八进制（基数为 8），九个符号 → 九进制（基数为 9）

### 2.3 源头归属

- **最初源头** = 初代数偏移量为 0 的统一体
- **次级源头** = 各偏移代数层级（δ ≠ 0）是被最初源头管辖的次级高维源头
- 每一个平行世界**同时都是**最初源头（可折算回），又**独立于**最初源头（有自己偏移量）

## 3. 跨层级换算（静态回归）

### 3.1 静态回归规则

任何平行世界的数值可以**折算回**初代数的等价数值：

```
折算后数值 = 平行世界数值 ÷ 乘数 M
例：
  二次代数中的"10" → 折算回初代数 = 10 ÷ 1.1 ≈ 9.09
  三次代数中的"10" → 折算回初代数 = 10 ÷ 1.2 ≈ 8.33
```

### 3.2 不可越层压缩

高维符号不能直接与低维符号做一次性大数折算——那等效于丢失偏移量，系统退化为无偏移的直线计数。

### 3.3 俘获规则（跨降维）

如果一个高维时空层级（如二次层级）不是初代数的源头，它就会被初代数所代表的存在**俘获**，强制折算回初代数。俘获是强制降维，不保留偏移量差异。

---

## 4. 齐头并进偏移（跨层级同步变换）

当所有平行世界**同时发生**齐头并进偏移时：

1. 确定谁是**等效源头**（偏移量最小的那一层级，即初代数）
2. 所有其他层级相对于等效源头做等量偏移
3. 齐头并进偏移时，各层级的**相对距离不变**
4. 即使高位是二次层级化时空，只要它不是源头，就会被俘获为初代数

偏移率表达：
- 用偏移率而非绝对值来标记大小对齐
- 各层级的"大小"是相对于初代数偏移率的层级化大小，不是数字绝对值

---

## 5. 自我相似叠加律

### 5.1 256 = 254 + 2 的自我相似性

每一层都必须满足 **256 = 254 + 2**，不得压缩。

两层叠加：
```
总数 = (254 + 2) × (254 + 2) = 254×254 + 254×2 + 2×254 + 2×2
     = 64516 + 508 + 508 + 4
     = 65536 = 2¹⁶
```
残差 = 4 = 两个根基对（2 + 2）的**叠加态**，不允许合并为单个 4。

### 5.2 跨层不可压缩性

- 不可将两层的"2 + 2 = 4"合并为一个值
- 叠加态保持独立存在
- 若强制合并则系统破坏，产生不自洽

## 6. 高位对齐的 2²⁵⁶ 进位制

2²⁵⁶ 不是层数叠加，而是位空间的**等效高位对齐进位制**：

```
每层的寻址空间 = 2²⁵⁶ ≈ 1.16×10⁷⁷
含义：从低位到达高位并对齐的进位规则
步骤：低位 → 进位 → 高位对齐 → 地址空间扩容到 2²⁵⁶
```

**内存类比（低位规则与高位规则）：**
- 低位规则：一字节 = 8 比特，0-255 存一个字符（低内存）
- 250-255：仍在单字节内
- 256：触发进位 → 扩到 9 比特 = 2 字符（占更大内存）
- 高位规则：2²⁵⁶ 对应超字节容量

**跨维度对齐：**
- 低位规则（8 比特/字节）与 高位规则（2²⁵⁶/超字节）是**不同维度、不同量化粒度**
- 两套规则互不对称、不可直接叠加
- 通过对齐换算（幂次方与字节约数的等效映射）实现**可通约互通**
- 称为"跨规则对齐"或"跨维度对齐"——跨维度的规则不对称、但可通约的等效对齐

2²⁵⁶ 编码为**共同体 #1**，是 mlll 编码系统在最高位对齐的统一标识。

## 7. 编码流水线——从符号产出到可计算存储

### 7.1 核心管道

mlll 编码系统不是人工设计每个符号，而是一条四步流水线：

```
类型产出 → 时间排队 → 量化位置 → 偏移存储
```

每一步都可代码化，不依赖人工理解符号的语义。

### 7.2 第一步：类型产出（多维度枚举）

从一个或多个维度枚举出所有可能的符号：

| 维度 | 可枚举数量 | 示例 |
|------|-----------|------|
| 几何边数 | ∞ | 三角形(3)、正方形(4)、五边形(5)... |
| 几何角数 | ∞ | 与边数同构但不必须绑定 |
| 几何面数量 | ∞ | 四面体(4)、立方体(6)... |
| 内角数量 / 外角数量 | 1:1 映射 | 可用于校验符号身份 |
| 内部折边 / 外部折边 | ∞ | 区分实心几何与空心几何 |
| 康熙部首 | 214 | 氵、木、火、土、金... |
| 笔画数 | 1-64+ | 按笔画数归类 |
| 声调 | 4 | 阴平、阳平、上声、去声 |
| 声母/韵母 | 23/24 | 汉语拼音系统 |
| 颜色 | ∞ | 可见光谱 |
| 相位 | 360° | 角度位置 |
| ... | ... | 任何可穷举的维度 |

机器不需要"理解"符号的语义——它只需要枚举规则和唯一标识（哈希）。**真实边界：机器可以生成近乎无限符号，但共同体只需要激活其中一部分。未被激活的符号是占位空符号。**

### 7.3 第二步：时间排队（一维串联）

各个维度产出的符号被放入同一条一维时间线，按确定规则排队。**一维时间在这里是最终仲裁者**：它把所有不可通约的维度强行拉到同一条可比较的跑道上。来自不同维度的符号不需要语义上可比，只需要在时间线上有前后关系。

排队规则可以是任意的但必须是确定的（否则系统不自洽）。规则的选择不影响系统正确性（只要规则给定且不变），影响的是符号位置的语义可解释性。

### 7.4 第三步：量化位置（公约量尺）

时间线上的位置直接产生可量化的距离。**公约量尺 = 时间线上的位置编号**，对所有维度一视同仁：不范畴化来源是谁、什么类型、什么单位——只关心"你在时间线上的第几位"。通过忽视来源差异（不忽视串联过程本身），将所有符号拉到同一个量化平面上。

### 7.5 第四步：偏移存储（可计算 + 可压缩）

每个符号被分配一个偏移坐标。存储的是偏移坐标，不是符号本身。还原时通过静态回归函数实时计算真实值。

压缩收益：存一个大数（如 2²⁵⁷ 量级）需要 257 比特，存偏移坐标只需要几十个比特，数百万符号时收益达 GB 级别。代价：读取时需实时计算还原（消耗 CPU），偏移率精度有限时有精度损失。

### 7.6 流水线小结

几何/声调/部首/颜色...维度分别枚举 → 按确定规则排入一维时间线 → 时间线位置即公约量尺坐标 → 分配偏移率实现可计算/可回归/可压缩存储 → 需要真实值时静态回归函数实时还原。

这条流水线使 mlll 系统可以机器生成、机器排序、机器存储，不需要人工理解每个符号的意义。符号的意义由共同体在互动中激活和赋予——系统只负责可计算的骨架，语义由使用它的人写进去。
