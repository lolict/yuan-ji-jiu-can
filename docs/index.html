状态分类

由群轨道结构分类：生成元 {NOT, REV} 在状态空间 {0,1}^N 上作用，轨道大小决定分类

轴心容器态

轨道大小=2，稳定子含 REV
状态=镜像(自身对称)
几何: 轴对称(球体)
语义: COUPLE 夫妻共生

字节布局 [16,X,Z,Y]

闭环态

轨道大小=2，稳定子含 NOT∘REV
状态=反回文
几何: 闭环曲面(环面)
语义: YIN_YANG 阴阳闭环

仅偶数 N 存在

镜像纠缠态

轨道大小=4，{I,NOT,REV,NOT∘REV}
四态共生，单一不完整
几何: 四方纠缠(四面体)
语义: HOMOPHONE 谐音纠缠

占大多数位宽的 ~85%

扩展纠缠态

轨道>4 (加入 ROT 生成元后)
更大轨道，混沌展开
几何: 多面混沌结构
语义: EXTENDED 扩展编码

扩展模式专属

验证矩阵

每个位宽全部 6 项验证通过

验证项 含义 状态
[全息性]Z轴+1 → 地址差=1 · 位级连续✓
[编解码](x,y,z) → addr → (x,y,z) 互逆✓
[完备性]分类合计 = 总数 · 穷尽✓
[字体闭环]分类代表元 = MCOD 条目✓
[字体裁决]首个容器 TriuneJudge → ADMIT✓
[空袋]pack_id=0xFFFF → REJECT✓

运行命令

# 编译
cargo build --release --bin pipeline

# 运行指定位宽
./target/release/pipeline 6        # 6-bit 标准模式
./target/release/pipeline 8        # 8-bit 标准模式
./target/release/pipeline 4 ext    # 4-bit 扩展模式 (NOT+REV+ROT)
