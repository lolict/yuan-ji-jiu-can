- Weight → FlowRight → Priority 链式派生
- Actor: 身份+权重+流动权+优先级+速度
- Cluster: CenterCenter/CenterHusband/CenterWife/Peripheral/Immobile/External
- RelAlgebra: N×N 关系矩阵 + 融合/流动/分类

**pleasure.rs** — 愉悦值动力引擎
- Pleasure (价值单位), decay_over_distance (距离损耗)
- ExternalEntity: 外界实体 (竞争/吸引/资源/威胁)
- Attractor: 愉悦引力 + 融合 + 丈夫/妻子侧分链 + fuse 唯一中心
