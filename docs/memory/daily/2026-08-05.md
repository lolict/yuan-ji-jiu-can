## 关键洞察

1. **域无关作为核心约束** — 任何域名运行同样的裁决逻辑,绑定域名等于交出主权
2. **JS 回退策略** — WASM 优先但自动回退 JS,保证最坏情况下也能裁决
3. **三层场域** — 主场(规则)/盟机场(合伙人)/萌机场(轻量)/WASM场(离线)
4. **盟机合词汇力量** — "盟机合掌"比"合伙人"更有凝聚力,更有主权感
5. **去中心化演化路径** — 中心化(CF Worker) → 多节点(合伙人) → 离线(WASM)
6. **移动端原生桥** — 统一 JS 接口 (window.mqfNative),平台差异由桥处理
7. **Gossip 同步可行** — 简单 PUSH+PULL 双向同步,默克尔树守一致性
