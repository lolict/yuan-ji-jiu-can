### 理论沉淀: 多语言分工

| 语言 | 满全法位置 | 适合原因 |
|------|-----------|---------|
| **Rust** | 内核核心计算器(已用) | 状态机、不变量、并发未来 |
| **Zig**  | 寄生壳层 / WASM 编译链 | 交叉编译、comptime、无隐藏 |
| **Nim**  | 编译器前端 / 胶合层 | 宏系统、快速、多后端 |
| **V**    | 暂不上场 | 生态弱、安全目标冲突 |
