## 关键教训
- 用户红线: "用龙猫大模型免费来写" = 绝不装积分包
- JNZ/JZ/RET 的被测试寄存器必须编码到 rs1 字段 (Verilog JNZ 逻辑用 f0_0=rf[s0_0] 作为被测试值)
- STORE 编码不对称: data → rs2, addr_base → rs1 (由 decode_regs 映射)
- IF 状态机需要单独 latch fetch_idle; DE 需要 FD_valid 消费信号
- 同一 clock 多 always 块不可多驱动同一 reg
- Verilog 跨 lane 前递需要检查全部 4 个 producer 端口 × 4 个 consumer 源
