# .3d.cbc.mll 文件格式规范

## 概述

`.3d.cbc.mll` 是 UniCore v2.0 专属私有文件格式，用于存储：
- 自定义进制数据
- 字符集映射
- 三维空间阵列配置
- 节点因果时间数据
- 集装箱内存状态
- 插件指令扩展

## 文件结构

### 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│                    文件头 (Header)                          │
│  魔数 + 版本号 + 标志位 + 数据偏移 + 校验和                  │
├─────────────────────────────────────────────────────────────┤
│                    数据段 (Segments)                        │
│  ┌─────────────────┐                                       │
│  │ 段1: 进制配置    │                                       │
│  ├─────────────────┤                                       │
│  │ 段2: 字符集映射  │                                       │
│  ├─────────────────┤                                       │
│  │ 段3: 集装箱数据  │                                       │
│  ├─────────────────┤                                       │
│  │ 段4: 空间阵列    │                                       │
│  ├─────────────────┤                                       │
│  │ 段5: 时间节点    │                                       │
│  ├─────────────────┤                                       │
│  │ 段6: 插件配置    │                                       │
│  └─────────────────┘                                       │
├─────────────────────────────────────────────────────────────┤
│                    文件尾 (Footer)                          │
│  段表偏移 + 校验和 + 私有标记                               │
└─────────────────────────────────────────────────────────────┘
```

### 文件头结构 (16字节)

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 4 | Magic | 私有魔数: `0x3D 0x43 0x42 0x43` (.3dCBC) |
| 0x04 | 2 | Version | 版本号: 0x0200 (v2.0) |
| 0x06 | 2 | Flags | 标志位 |
| 0x08 | 4 | DataOffset | 数据段起始偏移 |
| 0x0C | 4 | Checksum | 头校验和 |

#### Flags 标志位 (2字节)

| 位 | 含义 |
|----|------|
| Bit 0 | 压缩标志 |
| Bit 1 | 加密标志 |
| Bit 2 | 自定义字符集 |
| Bit 3 | 三维阵列数据 |
| Bit 4 | 时间节点数据 |
| Bit 5-15 | 保留 |

### 数据段结构

每个段由段头(8字节) + 段数据组成：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 2 | SegmentType | 段类型 |
| 0x02 | 2 | Flags | 段标志 |
| 0x04 | 4 | Length | 段数据长度 |
| 0x08 | N | Data | 段数据 |

#### 段类型定义

| 类型码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | RADIX | 进制配置 |
| 0x02 | CHARSET | 字符集映射 |
| 0x03 | CONTAINER | 集装箱数据 |
| 0x04 | SPATIAL | 空间阵列 |
| 0x05 | TIMENODE | 时间节点 |
| 0x06 | PLUGIN | 插件配置 |
| 0xFF | END | 结束标记 |

## 段详细结构

### 1. 进制配置段 (RADIX)

存储自定义进制定义：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 1 | RadixCount | 进制数量 |
| 0x01 | N*6 | RadixEntries | 进制条目数组 |

#### 进制条目结构 (6字节)

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 1 | RadixID | 进制ID |
| 0x01 | 2 | BaseValue | 进制基数 |
| 0x03 | 2 | RangeMin | 最小值 |
| 0x05 | 1 | Flags | 标志位 |

### 2. 字符集映射段 (CHARSET)

存储自定义字符集映射：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 2 | MappingCount | 映射数量 |
| 0x02 | N*4 | MappingEntries | 映射条目数组 |

#### 映射条目结构 (4字节)

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 1 | SourceChar | 源字符(ASCII) |
| 0x01 | 2 | CustomValue | 自定义值 |
| 0x03 | 1 | ContainerID | 绑定集装箱ID |

### 3. 集装箱数据段 (CONTAINER)

存储256个集装箱状态：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 256 | Values | 集装箱值数组 |
| 0x100 | 1024 | Positions | 位置数据(4字节/集装箱) |
| 0x500 | 256 | Flags | 标记数据 |

### 4. 空间阵列段 (SPATIAL)

存储三维阵列配置：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 1 | ArrayType | 阵列类型 |
| 0x01 | 1 | Dimension | 维度(3=三维) |
| 0x02 | 4 | OriginX | 原点X |
| 0x06 | 4 | OriginY | 原点Y |
| 0x0A | 4 | OriginZ | 原点Z |
| 0x0E | 2 | ElementCount | 元素数量 |
| 0x10 | N*12 | Elements | 元素数组 |

#### 阵列类型

| 类型码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | MATRIX | 矩阵阵列 |
| 0x02 | CONE | 锥阵 |
| 0x03 | SPHERE | 球阵 |
| 0x04 | HEX | 蜂窝阵 |
| 0x05 | WAVE | 波浪阵 |

### 5. 时间节点段 (TIMENODE)

存储节点因果时间数据：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 2 | NodeCount | 节点数量 |
| 0x02 | N*12 | NodeEntries | 节点数组 |

#### 节点条目结构 (12字节)

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 4 | NodeID | 节点ID |
| 0x04 | 1 | EventType | 事件类型 |
| 0x05 | 4 | CauseID | 因果节点ID(0xFFFFFFFF=无) |
| 0x09 | 2 | TimeOffset | 时间偏移 |
| 0x0B | 1 | Flags | 标志位 |

### 6. 插件配置段 (PLUGIN)

存储可插拔插件配置：

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 2 | PluginCount | 插件数量 |
| 0x02 | N*20 | PluginEntries | 插件数组 |

#### 插件条目结构 (20字节)

| 偏移 | 长度 | 内容 | 说明 |
|------|------|------|------|
| 0x00 | 1 | PluginID | 插件ID |
| 0x01 | 16 | Name | 插件名称 |
| 0x11 | 2 | Version | 版本号 |
| 0x13 | 1 | Status | 状态 |

## 私有魔数说明

文件头魔数 `0x3D 0x43 0x42 0x43`：
- 0x3D = '=' (3D的ASCII表示)
- 0x43 = 'C' (CBC)
- 0x42 = 'B'
- 0x43 = 'C'

组合为 `.3dCBC`，标识专属三维+CBC体系。

---

## 校验和算法

采用简单异或校验：

```
checksum = 0
for each byte in data:
    checksum ^= byte
```

---

## 文件识别规则

1. 文件头魔数匹配 `0x3D 0x43 0x42 0x43`
2. 版本号 >= 0x0200
3. 数据偏移有效

---

## 防抄袭设计

1. **私有魔数**：市面无匹配格式，无法直接解析
2. **自定义段结构**：无公开文档，难以逆向
3. **二进制存储**：非明文，增加拆解难度
4. **专属标记**：尾部私有标记验证合法性
