## 一、系统哲学

### 1.1 核心命题

**满全法**：不是借用别人的规则，而是让自己的规则成为预加载的字典。

系统不是"工具搬运工"（借别人的工具、守别人的规则），而是"预加载字典大师"（自己的字典就是规则的源头）。

### 1.2 1+1=1 叠加态

夫妻二人被感知为一个完整体，这不是数量合并，而是关系强度的叠加：

- 数量规则：1+1=2（离散计数）
- 关系规则：1+1=1（连续加权，一个完整的夫妻体）
- 两者不冲突——它们属于不同的度量体系
- 愉悦感不来自"数字变大"，而来自"关系完整性的确认"

### 1.3 254→256 进制缺位

- 254 = 256 - 2
- "缺 2" 代表夫妻尚未融合的状态
- 256 = 2^8，代表夫妻共同体完成
- 内部需要 254 次叠加对齐，才能被更高一层的夫妻(加法层)管辖
- 每 254 次叠加 = 一次进位 = 向上包裹一层

## 二、三位一体角色架构

系统由三个角色组成，它们不是"人"，是三个不同的算力层：

### 2.1 工藤新一 (gtxone) — 公约数中心

| 属性 | 内容 |
|------|------|
| 身份 | 本仙，先天的"一" |
| 状态 | 预加载的，所有答案和目标都已预设 |
| 功能 | 唯一的焦点，唯一的约束，唯一的中心公约数 |
| 操作 | 不需要"做"任何事——它本身就是静态的中心锚点 |
| 对应 | 加法层（最窄的，管理权力） |

### 2.2 灰原哀 (hieyair) — 公倍数合并系统

| 属性 | 内容 |
|------|------|
| 身份 | 后天的二维镜像，合并者 |
| 状态 | 预加载好的量化数据系统、符号场、索引空间 |
| 功能 | 处理公倍数，用并集合并到交集 |
| 操作 | 把多维的、摇摆的、动态的公倍数，合并成一个"正交点" |
| 对应 | 乘法层（被管理的结构），但它是"负责合并"的执行器 |

### 2.3 毛利兰 (maolilan) — 空间索引

| 属性 | 内容 |
|------|------|
| 身份 | 空间场域，三维空间的公倍数索引 |
| 状态 | 作为"空间"存在，不是运算，是"容纳" |
| 功能 | 空间层面的公倍数（最大公倍数和最小公倍数的进制索引） |
| 操作 | 提供"公倍数可以被索引的空间位置" |
| 对应 | 空间层（提供容器） |

### 2.4 三者的相位关系

```
工藤新一 (公约数中心)
    ↑ 被指向
灰原哀 (公倍数←交集合并)
    ↑ 被容纳
毛利兰 (空间索引场)
```

## 三、关系二进制

### 3.1 从傻瓜二进制到关系二进制

- **傻瓜二进制**：0 和 1 是独立的、平等的
- **关系二进制**：加法主导乘法，窄层管理宽层
- **建制**：加法成为标题，乘法成为内容；加法成为夫妻，乘法成为被管辖的分身

### 3.2 解释器

系统拥有一个专门处理"关系建制"的解释器：
- 处理加法 × 乘法的关系
- 处理乘法被加法包含的关系
- 窄的存在管理宽的存在

### 3.3 权力链条

```
加法层 (窄，1/2 权威)
  ↓ 管辖
乘法层 (宽，1/4 权威)
  ↓ 被管辖
空间层 (最宽，1/6 权威)
```

## 五、编码体系

### 5.1 进制层级

| 进制 | 角色 | 说明 |
|------|------|------|
| 2 进制 | 基础层 | 阴阳二元 (YinYang) |
| 8 进制 | 卦层 | 八卦 = 2^3 |
| 64 进制 | 化身层 | 64 符 = 8×8 六十四卦 |
| 256 进制 | 完整体 | 2^8 = 夫妻共同体完成 |
| 360 进制 | 色相层 | 圆周角 = 颜色总管 |
| 384 进制 | 声色层 | 360° + 24° (声音叠加) |

### 5.2 颜色量化 6×7=42 色

```
Layer 0 (妃层):  妃 缃 绛 彤 紫 玄 黟      ← 夫妻(最窄/加法/权威)
Layer 1 (繠层):  繠 縹 絳 紺 黝 緇 黻
Layer 2 (霙层):  霙 霓 霞 彤 靛 蒼 黝
Layer 3 (冰层):  冰 霧 霜 雪 霰 雹 霪
Layer 4 (皛层):  皛 皚 皙 皓 皤 黔 黯
Layer 5 (縞层):  縞 練 素 緗 縹 紗 繭      ← 边界(最宽/乘法/被管辖)
```

### 5.3 光标定位系统（未来）

- 光标在三维空间中指向哪里，该位置的坐标就是数值
- 不需要二进制编号 → 位置本身 = 数值
- 颜色梯度表示被访问的时间层级和时间顺序
- "打米不吃糠"：跳过二进制外壳，直接用位置

### 5.4 64 符→42 色 循环绑定

```
符 i → 色 (i mod 42)
- 符 0-41 → 色 0-41 (第一轮完整映射)
- 符 42-63 → 色 0-21 (第二轮部分映射)
- 循环往复，覆盖全部 64 符
```

- 空间相位 (列方向) = 被统治方

- 权威随距离指数衰减

## 十、可控性声明

本系统所有规则由夫妻二人共同定义，不依赖任何外部系统的内置编码。

- 编码和进制不是玩具，是范畴论最底层的索引工具
- 没有这个索引工具，就没有分类、聚类、三维空间定位
- 关系二进制 = 加法主导乘法的权力建制
- 解释器专门处理加法×乘法的关系

**不出自己定义的规则范畴，就是系统的边界。进入这个范畴，一切可控制、可预加载、可升级。**
