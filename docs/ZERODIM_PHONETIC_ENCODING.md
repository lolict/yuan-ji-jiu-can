# 零维码 · 容器编码表（P1-1 修订版）

> **容器结构：** 容器一·阿大（声母）、容器二·阿猫（韵母）、容器三·阿狗（声调）、容器四·叠音
> **a, o, e, i, u, v(ü) 是声调，不是韵母**——只在容器三·阿狗中，不在容器二·阿猫中
> 内部符号按顺序排列，不需要命名

---

## 设计原则

1. **一符一码**：每个符号唯一对应一个声母/韵母/声调位置
2. **大小写配对**：每个码位都有大写和小写两种形式（满足100+进制）
3. **用户定义优先**：用户已在附件中定义的符号映射不做任何修改
4. **空缺待补**：用户未定义的码位用 `—` 标记，不擅自填写
5. **预组合唯一**：所有符号必须是单码点预组合（猴子本体），拒绝组合字符

## 八、跨容器重复符号对照表

> 零维码四个容器独立运作，但允许符号跨容器复用。
> 同一符号在不同容器中代表不同音节，由容器+顺序（位权）决定具体含义。

### 重复符号一览

| 符号 | 容器二·阿猫（韵母） | 容器四（叠音） | 复用说明 |
|------|---------------------|---------------|----------|
| Ȣ / ȣ | ou | xiong(叠音) | 同一符号表示"欧"和"熊" |
| Ǫ / ǫ | ong | qiong(叠音) | 同表示"翁"和"穷" |
| Ꜻ / ꜻ | uai | uai(叠音) | uai双重定义 |
| ꬰ / ꬱ | ai | uai(叠音) | ai/uai交叉复用 |
| Ѻ / ѻ | iong | jiong(叠音) | iong/jiong复用 |
| Ѹ / ѹ | — | oi(叠音) | oi变体复用 |
| Ꙕ / ꙕ | ou异体 | oi(叠音) | ou/oi交叉 |
| Ǟ / ǟ | ua | ua(叠音) | ua同符号复用 |
