# 零维码 · 声母/韵母/声调编码表（P1-1 修订版）

> **本版本严格遵守用户已在三份附件中定义的符号映射，绝不覆盖。**
> 数据来源：附件1（粤语+变体）、附件2（DeepSeek 对话整理）、附件3（最终定稿表+编码串）
> 符号优先级：附件3 定稿表 > 附件2 > 附件1

---

## 设计原则

1. **一符一码**：每个符号唯一对应一个声母/韵母/声调位置
2. **大小写配对**：每个码位都有大写和小写两种形式（满足100+进制）
3. **用户定义优先**：用户已在附件中定义的符号映射不做任何修改
4. **空缺待补**：用户未定义的码位用 `—` 标记，不擅自填写
5. **预组合唯一**：所有符号必须是单码点预组合（猴子本体），拒绝组合字符

### 跨容器重复符号对照表

> 零维码四个容器（声母/韵母/声调/叠音）独立运作，但允许符号跨容器复用。
> 同一符号在不同容器中代表不同音节，由容器+位置（位权）决定具体含义。

| 符号 | 容器一：韵母码位 | 容器四：叠音码位 | 复用说明 |
|------|------------------|------------------|----------|
| Ȣ / ȣ | F11(ou) | xiong(叠音) | 同一符号表示"欧"和"熊" |
| Ǫ / ǫ | F33(ong) | qiong(叠音) | 同表示"翁"和"穷" |
| Ꜻ / ꜻ | F20(uai) | uai(叠音) | uai双重定义 |
| ꬰ / ꬱ | F07(ai) | uai(叠音) | ai/uai交叉复用 |
| Ѻ / ѻ | F37(iong) | jiong(叠音) | iong/jiong复用 |
| Ѹ / ѹ | — | oi(叠音) | oi变体复用 |
| Ꙕ / ꙕ | F11(ou异体) | oi(叠音) | ou/oi交叉 |
| Ǟ / ǟ | F18(ua) | ua(叠音) | ua同符号复用 |
| Ȫ / ȫ | F19(uo) | uo(叠音) | uo同符号复用 |
| Ꙍ / ꙍ | F19(uo异体) | uo(叠音) | uo变体交叉 |
| ʉ / Ʉ | F18(ua异体) | ua(叠音) | ua异体交叉 |

> **层级说明**：跨容器复用是"活编码"的体现——符号本身不固定含义，
> 由它所在的容器和在该容器中的位置共同决定。这就像同一个"副本"在不同"层级"中执行不同功能。
