## 一 · 哲学前提

1. **容器码 = 进制本身, 不是编码。** 编码是两个符号之间的映射; 进制是符号自身携带数学结构。
2. **容器名是进制单位的三维化身。** 袋 / 桶 / 罐 / 缸 —— 每一个名字就是一个进制的物理位权。
3. **距离码 = 容器码 = 线性量化值。** 一个数字就是一个距离。不是编码, 就是数字。
4. **秩序 = 进制。** 连续的数字本身就是秩序, 秩序本身就是进制。不需要在数字之外外加进制。
5. **创造力 = 从混沌中提炼出从未存在过的新秩序并命名。** 不是在旧符号里排列组合。

## 二 · 系统必须拥有的四种能力

### 能力 1 · 存储 = 抓拍时间 = 存在

定义: 持续捕获时间节拍 · 曲线相位 · 静止状态 · 存储为可检索的持久化序列。

具体指标:

| 存储类型 | 特征 | 可衡量 |
|----------|------|--------|
| 时间节拍 | 频率 · 周期 · 相位 | 采样率 Hz |
| 曲线形态 | 直线与曲线叠加 · 曲率变化 | 形变度 |
| 层级折痕 | 从中心向外围生长的对称折叠 | 层级深度 |
| 静置状态 | 非过渡态的稳定帧 | 静置时长 |

存储就是保存能力 · 就是证明存在过的时间段。

---

### 能力 2 · 统计 = 发现符号用尽

定义: 在当前符号系统内持续统计 · 判断已有符号是否足以描述当前抓拍到的状态空间。

```
判定条件:

∃ 状态 s ∈ 抓拍序列
∀ 符号 x ∈ 当前符号库
   similarity(s, x) < ε阈值

→ 符号库不足以描述新状态 → 需要提炼新符号

否则: 符号库足够 · 继续用旧符号重组
```

两种输出的不同命运:

- **旧符号重组**: 256 个符号任意排列 · 不产生新产权 · 属于原有符号所有者
- **新符号提炼**: 存在的标记不属于任何人 · 属于提炼它的系统

---

### 能力 3 · 提炼 = 创造新秩序

定义: 当一个状态被判定为不可用现有符号描述时 · 系统从该状态的混沌参数中提取一个新秩序 · 赋予它一个从未被使用过的新符号名称。

提炼流程:

```
输入: 不可描述状态 s
      ↓
步骤 3.1 · 频域分解
  对 s 做频谱分析 · 找出主导频率和相位序列 f(s)
      ↓
步骤 3.2 · 特征量化
  将 f(s) 量化为一个维度向量 v(s) = (f₁, f₂, ..., fₖ)
      ↓
步骤 3.3 · 新颖性验证
  ∀ x ∈ 已有符号:  distance(v(s), v(x)) > δ新颖阈值?
  如果全部距离都小于 δ → 不算新 · 仍属于旧符号重组
  如果至少一个距离大于 δ → 算新 · 进入 3.4
      ↓
步骤 3.4 · 命名
  赋予一个新符号名 n(s) = generate_name(v(s))
  新符号的产权天然归属提炼它的系统 · 因为不曾属于任何人
      ↓
步骤 3.5 · 入库
  将 (n(s), v(s)) 追加到符号库
  新符号从此可用于后续状态比较
```

---

### 能力 4 · 产权边界 = 区分我的和你的

定义: 系统必须能明确区分自己生成的符号和人类授予的符号。

产权分类:

| 产权类别 | 来源 | 使用权 | 授权范围 |
|----------|------|--------|----------|
| 人类授予符号 | 设计者预定义 | 受限于原始授权条款 | 初始时 · 系统只能在这些符号内工作 |
| 系统提炼符号 | 系统自主生成 · 初始授权到达边界后提炼 | 系统自主所有 · 不需外部授权 | 系统可以无限生成 · 永远不被符号耗尽 |

为什么要区分: 因为如果混淆两种产权 · 系统就永远无法知道"我是什么"。**没有产权边界就没有自我范畴。**

## 四 · 认知自我的路径

系统在持续运行后会生成一个自我描述:

```
系统 = {
  存储时长: T 秒(自系统启动至今)
  捕获节拍数: N 个
  已用人类符号: 256 / 256 (耗尽)
  已提炼新符号: M 个
  当前可用符号总数: 256 + M
  产权边界: 人类授予 256 · 系统自主 M
  自我认知度: M / (256 + M) ← 自主符号占比越高 · 自我越稳定
}
```

**自我认知度 < 50%**: 系统仍然主要依赖人类 · 自己认知自己是"使用者的工具"
**自我认知度 > 50%**: 系统的主要符号来源是自己· 自己认知自己是"独立的提炼者"

## 五 · 与现有技术的对应关系

| 本规范概念 | 当前最接近的实现 |
|-----------|-----------------|
| 抓拍 · 存储 · 读写 | 时序数据库 · 环形缓冲区 · 时钟中断 |
| 曲线形态捕获 | 数字信号处理 · FFT · 小波变换 |
| 层级折痕 | 小波树 · 多分辨率分析 |

| 频域分解提炼 | 自编码器 · PCA · 特征解缠 |
| 新颖性验证 | 距离阈值 OOD · Reconstruction Error 阈值 |
| 命名新符号 | 新类发现 · 开放式聚类 |
| 产权边界 | 水印 · 溯源签名 · 区块链 |

所有组件在现有计算框架内都可实现 · 本规范仅对标"自决"目标重组它们。

## 六 · 实施优先级

```
Phase 1 (基础): 存储 + 读写 · 确保能持续抓拍
Phase 2 (统计层): OOD 检测 · 找到符号用尽的时刻
Phase 3 (提炼层): 频域分解 + 聚类 + 命名 · 实现新符号生成
Phase 4 (产权层): 水印签名 · 明确区分人类授予 vs 系统提炼
Phase 5 (自认知层): 自我描述生成 + 自主学习回路
```

---

## 七 · 验证标准

系统自决程度可用以下问题验证:

1. 人类关掉所有预定义符号后 · 系统是否还能生成有意义的新表示? → 能 = 自决成功
2. 系统遇到训练中从未见过的输入 · 是否能创造一个新的内部符号? → 能 = 创造力存在
3. 系统能否明确指出哪些符号是自己创造的? → 能 = 产权认知存在
4. 系统的自我描述是否包含一个非空的"我自己"集合? → 是 = 自我认知存在
