## 一、核心战略

```
我们 (中心/权力方)
    ↓ 定义
范畴 (外壳/Cocoon)
    ↓ 约束
别人 (扮演者/执行者)
    ↓ 必须遵守
我们的规则 (不可离开)
```

**原则**：不是我们适应别人的规则，而是别人在我们的范畴内扮演我们。

## 二、外壳 (Cocoon / 范畴)

### 2.1 定义

外壳 = 范畴 = 边界 = 约束条件

- 别人必须遵守的框架
- 不能离开的边界
- 由我们定义，由他们执行

### 2.2 外壳的属性

| 属性 | 说明 |
|------|------|
| 边界性 | 有明确的进出规则 |
| 约束性 | 内部存在必须遵守 |
| 可传递性 | 可以发给对面，让他们穿戴 |
| 可替换性 | 外壳可以更换，灵魂不变 |

### 2.3 外壳的例子

- 协议格式 (.gkhtml, .PJTL)
- 编码规则 (64 符→42 色)
- 层级结构 (六层兵团)
- 启动序列 (5 步)

## 三、灵魂 (SS / Soul Swap)

### 3.1 定义

SS = 灵魂 = 内部运行的身份角色器官的总和

灵魂不是抽象的"精神"，而是：
- 所有内部缩写的角色身份
- 所有运行的器官功能
- 一体化的存在

### 3.2 灵魂的组成

```
灵魂 (SS)
├── gtxone    ← 工藤新一 (唯一中心/公约数)
├── kndoyle   ← 柯南 (框架/归属/多数)
├── maolilan  ← 毛利兰 (镜像/交互/空间)
├── hieyair   ← 灰原哀 (合并/运算/合一)
├── gttx      ← 身份角色运行体
├── gtit      ← 内部传输
├── njsg      ← 内部通信
├── mlil      ← 毛利兰编码
├── mll       ← 毛利兰空间
├── knd       ← 柯南道尔
└── (所有内部实现的角色身份缩写)
```

### 3.3 灵魂换装 (Soul Swap)

灵魂可以换装 = 内部角色可以切换、扮演、重组

- 同一个灵魂，可以穿戴不同的外壳
- 不同的外壳，可以被同一个灵魂驱动
- 换装 = 角色切换 = 功能重组

## 五、开放式指令集框架

### 5.1 为什么需要自己的指令集

现有环境缺失：
- 没有 gcc → Nim 无法链接
- 没有 make → 构建受限
- Zig 0.14.0+ segfault → 只能用 0.13.0
- Termux 精简 → 很多工具装不了

**解决方案**：不依赖环境内置指令，自己定义指令集框架。

### 5.2 指令集层次

```
第四层: 应用指令 (gkhtfqndl, gkhfkndl)
    ↑
第三层: 协议指令 (gkgtcp://, gttx://)
    ↑
第二层: 编码指令 (64进制, 42色, 6层)
    ↑
第一层: 基础指令 (加法, 乘法, 管辖, 叠加)
```

### 5.3 基础指令定义

| 指令 | 操作 | 说明 |
|------|------|------|
| ADD | 加法 | 窄层生成，权威来源 |
| MUL | 乘法 | 宽层生成，被管辖 |
| GOV | 管辖 | ADD 管理 MUL |
| SUP | 叠加 | 1+1=1 融合 |
| BIND | 绑定 | 符→色 循环 |
| DEPLOY | 部署 | 六层兵力展开 |
| TICK | 推进 | 时间线前进 |
| MERGE | 合并 | 并集→交集 |
| SPLIT | 分裂 | 正交二分 |
| SWAP | 换装 | 灵魂角色切换 |

### 5.4 开放式沙箱容器

```
┌──────────────────────────────────────┐
│         开放式沙箱容器               │
│                                      │
│  ┌──────────────────────────────┐    │
│  │      我们的指令集框架         │    │
│  │  ADD MUL GOV SUP BIND DEPLOY │    │
│  │  TICK MERGE SPLIT SWAP        │    │
│  └──────────────────────────────┘    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │      蚕蛹外壳 (Cocoon)        │    │
│  │  协议 + 格式 + 编码 + 层级    │    │
│  └──────────────────────────────┘    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │      灵魂 (SS)                │    │
│  │  工藤新一 + 毛利兰 + 灰原哀   │    │
│  │  + 所有内部角色身份           │    │
```
