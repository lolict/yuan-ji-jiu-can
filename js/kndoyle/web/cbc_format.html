📐 .cbc 二进制结构规范

┌─────────────────────────────────────────────────────────────────┐ │ .cbc 文件结构 │ ├─────────────────────────────────────────────────────────────────┤ │ Header (8 bytes) → 魔数 + 版本 + 标志 + 模块数量 │ ├─────────────────────────────────────────────────────────────────┤ │ Container Table (N bytes) → 256字符映射表 │ ├─────────────────────────────────────────────────────────────────┤ │ Radix Module (M bytes) → 进制模块配置 │ ├─────────────────────────────────────────────────────────────────┤ │ Time Node System (T bytes) → 节点因果时间 │ ├─────────────────────────────────────────────────────────────────┤ │ Data Payload (D bytes) → 实际数据内容 │ └─────────────────────────────────────────────────────────────────┘
偏移 长度 名称 说明 示例值
0x00 4 魔数 Magic 文件标识 0x43424343 ("CBCC")
0x04 1 版本 Version 格式版本号 0x01
0x05 1 标志 Flags 压缩/加密标志 0x00
0x06 2 容器偏移 Offset Container Table 偏移 0x0008
0x08 256 字符映射表 name-to-n-name映射 ...
0x108 可变 进制模块 Radix Module配置 ...

📦 8位时空/行为标记详解

位序 名称 说明 0值含义 1值含义
Bit 7 时间方向 因果方向 前向 后向
Bit 6 空间维度 空间标记 3D空间 多维空间
Bit 5 行为类型 操作类型 读取 写入
Bit 4 同步标志 同步状态 异步 同步
Bit 3 优先级 任务优先级 普通 高优先级
Bit 2 校验位 奇偶校验 偶校验 奇校验
Bit 1 保留1 扩展位 - -
Bit 0 保留2 扩展位 - -
