# UniCore ISA v2.0 - 全新指令集架构规范

## 版本历史
- v1.0: 初始版本（传统改进架构）
- v2.0: 革命性重构（不进位、节点时间、集装箱架构）**[当前版本]**

---

## 第一部分：核心设计理念

### 1.1 传统架构的问题
```
传统ISA缺陷：
1. 二进制进位导致溢出、精度损失
2. 时钟驱动执行，功耗高、延迟固定
3. 线性地址空间，碎片化
4. 指令集固定，扩展困难
5. 冯诺依曼瓶颈
```

### 1.2 UniCore v2.0的突破
```
全新架构特性：
1. 不进位计数 → 零溢出、无限精度
2. 节点因果时间 → 事件驱动、低功耗
3. 集装箱内存 → 自然分区、无碎片
4. 插件即指令 → 无限扩展、动态加载
5. 空间向量操作 → 多维计算，原生支持
```

## 第二部分：基础数据类型

### 2.1 集装箱（Container）
```
最小存储单元：1字节 = 8位

结构：
┌────────────────────────────────────┐
│ Container ID: 0x00 - 0xFF (256个)  │
├────────────────────────────────────┤
│ Behavior Flags: 8位时空/行为标记    │
│  Bit 7: 时间方向 (0=前向, 1=后向)   │
│  Bit 6: 空间维度 (0=3D, 1=多维)    │
│  Bit 5: 操作类型 (0=读, 1=写)       │
│  Bit 4: 同步标志 (0=异步, 1=同步)    │
│  Bit 3: 优先级 (0=普通, 1=高)       │
│  Bit 2: 校验位 (0=偶, 1=奇)         │
│  Bit 1: 扩展位1                     │
│  Bit 0: 扩展位2                     │
├────────────────────────────────────┤
│ Payload: 0-255 字符映射            │
└────────────────────────────────────┘
```

### 2.2 节点（Node）
```
时间记录单元

结构：
┌────────────────────────────────────┐
│ Node ID: 32位无符号整数            │
├────────────────────────────────────┤
│ Event Type: 枚举类型               │
│  - 0: 普通事件                     │
│  - 1: 动作行为                     │
│  - 2: 状态变更                     │
│  - 3: 因果触发                     │
├────────────────────────────────────┤
│ Cause Pointer: 因果节点ID (可空)    │
├────────────────────────────────────┤
│ Time Offset: 时间偏移 (浮点数)      │
├────────────────────────────────────┤
│ Time Unit: 时间单位名称 (字符串)    │
└────────────────────────────────────┘
```

### 2.3 空间向量（Spatial Vector）
```
多维位置表示

结构：
┌────────────────────────────────────┐
│ X: -100 ~ +100 (整数)             │
│ Y: -100 ~ +100 (整数)             │
│ Z: -100 ~ +100 (整数)             │
│ W: -100 ~ +100 (整数, 扩展维度)    │
└────────────────────────────────────┘
```

## 第三部分：指令格式

### 3.1 指令编码（32位固定长度）

```
┌────────────────────────────────────────────────────────────────────┐
│  31-24 (8位)    │  23-16 (8位)   │  15-8 (8位)    │  7-0 (8位)    │
├────────────────────────────────────────────────────────────────────┤
│  Op_Code        │  Container_ID  │  Vector/Args │  Flags         │
└────────────────────────────────────────────────────────────────────┘

Op_Code: 操作码 (0x00-0xFF)
Container_ID: 集装箱ID (0x00-0xFF)
Vector/Args: 空间向量或参数
Flags: 行为标记
```

### 3.2 操作码定义

```
基础指令 (0x00-0x1F):
0x00  NOP       空操作
0x01  HALT      停止执行
0x02  LOAD      加载集装箱
0x03  STORE     存储集装箱
0x04  MOVE      移动集装箱
0x05  COPY      复制集装箱

不进位计数指令 (0x10-0x1F):
0x10  INC       不进位加1
0x11  DEC       不进位减1
0x12  ADD       不进位加法
0x13  SUB       不进位减法
0x14  ZERO      归零
0x15  MAX       设为最大值
0x16  FLIP      位翻转

节点时间指令 (0x20-0x2F):
0x20  CREATE_NODE    创建节点
0x21  LINK_NODE      链接节点
0x22  TRIGGER        触发节点
0x23  WAIT_NODE      等待节点
0x24  SYNC_TIME      同步时间
0x25  GET_OFFSET     获取时间偏移

空间操作指令 (0x30-0x3F):
0x30  SET_POS        设置位置
0x31  GET_POS        获取位置
0x32  MOVE_TO        移动到位置
0x33  DISTANCE       计算距离
0x34  ROTATE         旋转
0x35  PROJECT        投影

插件指令 (0x40-0xFF 可扩展):
0x40  LOAD_PLUGIN    加载插件
0x41  UNLOAD_PLUGIN  卸载插件
0x42  CALL_PLUGIN    调用插件
0x43  LIST_PLUGIN    列出插件
```

### 3.3 指令详解

#### 3.3.1 NOP - 空操作
```
编码: 0x00000000
功能: 不执行任何操作
周期: 1
```

#### 3.3.2 LOAD - 加载集装箱
```
编码: 0x02XX0000 (XX=集装箱ID)
功能: 将集装箱内容加载到活动寄存器
周期: 1
示例: LOAD 0x10 → 加载ID=0x10的集装箱
```

#### 3.3.3 INC - 不进位加1
```
编码: 0x10000000
功能: 活动集装箱值+1，255后变为0
周期: 1
特点: 无进位溢出，循环范围[0,255]
```

#### 3.3.4 CREATE_NODE - 创建节点
```
编码: 0x20XXXXYY (XXXX=事件类型, YY=参数)
功能: 创建新的因果节点
参数:
  XXXX = 事件类型
  YY = 因果节点ID (0xFF表示无因果)
周期: 2
```

#### 3.3.5 SET_POS - 设置位置
```
编码: 0x30XXYYZZ (XX=X, YY=Y, ZZ=Z)
功能: 设置集装箱的空间位置
周期: 1
```

## 第四部分：执行模型

### 4.1 节点驱动执行（传统时钟的替代）

```
传统模型:
┌─────────────────────────────────────┐
│ 时钟 → 取指 → 译码 → 执行 → 访存 → 写回 │
│ (固定周期，高功耗)                      │
└─────────────────────────────────────┘

节点驱动模型:
┌─────────────────────────────────────┐
│ 节点触发 → 因果传播 → 指令执行 → 等待   │
│ (事件驱动，低功耗）                     │
└─────────────────────────────────────┘
```

### 4.2 执行流程

```
1. 系统启动
   ↓
2. 初始化集装箱池 (256个)
   ↓
3. 创建根节点 (时间基准)
   ↓
4. 等待节点触发
   ↓
5. 因果链条传播
   ↓
6. 执行相关指令
   ↓
7. 产生新节点
   ↓
8. 循环4-7
```

### 4.3 时间同步机制

```
借用外部硬件时钟作为参考基准：

┌─────────────┐     1秒      ┌─────────────┐
│ 硬件时钟    │ ──────────▶ │  UniTick    │
│ (不可控)    │   映射倍率   │  (自定义)   │
└─────────────┘   可调       └─────────────┘

时间转换公式:
  uni_time = hardware_time × scale_factor

scale_factor 可自定义，默认 1.0
```

## 第五部分：内存管理

### 5.1 集装箱池

```
256个独立集装箱，无需寻址

┌────────────────────────────────────────┐
│ Container Pool                         │
├──────────┬──────────┬─────────┬───────┤
│ 0x00     │ 0x01     │ ...     │ 0xFF  │
│ [数据]   │ [数据]   │ [数据]  │ [数据]│
│ [标记]   │ [标记]   │ [标记]  │ [标记]│
│ [位置]   │ [位置]   │ [位置]  │ [位置]│
└──────────┴──────────┴─────────┴───────┘
```

### 5.2 不进位计数实现

```python
def non_carry_add(a, b, max_val=255):
    """不进位加法"""
    result = a + b
    if result > max_val:
        result = result % (max_val + 1)  # 循环回到0
    return result

def non_carry_sub(a, b, max_val=255):
    """不进位减法"""
    result = a - b
    if result < 0:
        result = max_val + 1 + result  # 循环到最大值
    return result
```

## 第七部分：示例程序

### 7.1 Hello World

```
; 显示 "Hello" 在集装箱0x00-0x04
LOAD_PLUGIN 0xA0           ; 加载字符映射插件
SET_CHAR 0x00, 'H'         ; 集装箱0x00 = 'H'
SET_CHAR 0x01, 'e'         ; 集装箱0x01 = 'e'
SET_CHAR 0x02, 'l'         ; 集装箱0x02 = 'l'
SET_CHAR 0x03, 'l'         ; 集装箱0x03 = 'l'
SET_CHAR 0x04, 'o'         ; 集装箱0x04 = 'o'
OUTPUT 0x00, 0x05          ; 输出5个字符
HALT
```

### 7.2 不进位计数演示

```
; 演示不进位加法
LOAD 0x10                   ; 加载集装箱0x10
INC                          ; +1 (0xFF → 0x00)
INC                          ; +1 (0x00 → 0x01)
ADD 0x10, 0xFF              ; +255 (0x01 → 0x00)
HALT
```

### 7.3 节点因果时间

```
; 创建事件链

CREATE_NODE 0x03, 0x02     ; 创建事件类型3，因果于节点2
```

## 第八部分：技术规格

### 8.1 性能指标

```
指令周期: 1-5 (取决于指令类型)
并发节点: 无限制 (受内存限制)
集装箱数量: 256 (固定)
插件数量: 208 (0x40-0xFF)
最大向量范围: ±100 (每维)
时间精度: 浮点数64位
```

### 8.2 兼容性

```
UniISA v1.0 程序: 不兼容 (需重写)
UniISA v2.0 程序: 完全兼容
外部数据格式: 支持.cbc导入导出
```
