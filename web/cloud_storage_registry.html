💡 平台说明

这个平台收集各种云盘服务的配置信息，帮助大家找到最适合自己的存储方案。

核心思路：
• 我无法亲自测试所有云盘服务
• 但我可以让大家一起测试
• 你不需要亲自试错，让别人帮你测试
• 测试成功或失败都可以提交，大家共享结果

💰 成本说明：如果你没有花费，就无法登录网页。坚果云需要付费才能使用 WebDAV。其他云盘服务可能提供免费 API 或试用额度，大家可以一起测试哪些服务更实用。

🥜 坚果云 ✅ 已验证
国内知名的同步云盘，支持 WebDAV，适合个人和小团队使用。
📋 WebDAV 配置
服务器：dav.jianguoyun.com/dav/
端口：443
用户名：你的注册邮箱
密码：应用密码（非登录密码）
⚠️ 注意：需要付费会员才能使用 WebDAV 功能

☁️ OwnCloud ✅ 已验证
开源私有云盘解决方案，可以自己部署服务器，完全自主控制。
📋 WebDAV 配置
服务器：你的域名/remote.php/dav/files/用户名/
端口：443 (HTTPS)
用户名：你的 OwnCloud 账号
密码：你的 OwnCloud 密码
💡 优点：完全免费，可自行部署，数据完全私有
📦 NextCloud ✅ 已验证
OwnCloud 创始人创建的开源项目，功能更丰富，社区活跃。
📋 WebDAV 配置
服务器：你的域名/remote.php/webdav/
端口：443 (HTTPS)
用户名：你的 NextCloud 账号
密码：你的 NextCloud 密码
💡 优点：完全免费，可自行部署，支持大量插件
