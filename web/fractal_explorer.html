🎓 什么是分形？

分形是具有自相似性的复杂几何图形，它们在任意缩放级别下都保持相似的结构。Mandelbrot和Julia集合是最著名的分形例子，它们展示了简单的数学公式如何产生无限复杂的美丽图案。

Mandelbrot集合公式： zₙ₊₁ = zₙ² + c
Julia集合公式： zₙ₊₁ = zₙ² + c (固定的c值)
