容器编码 · 32位分配 Container Code Bit Allocation

家族
[3 bits] family
0=容器 1=边界 2=夫妻 3=网状 4=中性
极性
[1 bit] polarity
0=阴/囡 1=阳/囝
结构
[3 bits] structure
字形结构分类 (独体/上下/左右/包围...)
声母
[6 bits] shengmu
FQ-SM48 声母进制 (2⁶=64 ≥ 48)
韵母
[6 bits] yunmu
FQ-YM66 韵母进制 (2⁶=64 ≥ 66 近满)
声调
[3 bits] tone
0=阴平 1=阳平 2=上声 3=去声 4=轻声
总计: 3+1+3+6+6+3 = 22 bits → 容器编码 32 bits (留 10 bits 扩展)
渲染帧: 16字符 = 1 bit · 254字符 = 2 bytes 通过渲染帧传递

衍射八维 Eight-Dimensional Diffraction

审美 aesthetic
全局感知能力,不是局部抓芝麻。衍射——把一束光分成八束,每个维度看到不同颜色
例: 整体和谐 vs 局部堆积
类型 type
类型跃迁判定: a-á 距离 ≈ 0.18 > 阈值 0.15 = 跨类型。不是渐进是跳跃
例: 容器→边界 = 类型跳变
面相 appearance
镜像观察: 字的"长相"——字形结构、笔画数、部首归属
例: 囡(方形容器) vs 囝(竖长界线)
骨骼 structure
工藤新一 映射: 骨/头/体等结构属性。字形的骨架构成
例: 独体/上下/左右/半包围/全包围
思考 thinking
概念流产物: 范畴 + 聚类 + 解释后的认知结晶
例: 字的语义网络与联想路径
协同 cooperativity
你压我一头我压一头——编织均衡,分布式平衡
例: 两个笔画互相支撑不倾倒
目标 goal
靶点身份决定主权级别: Active/Passive/Sleeping/System
例: 路由到 Wife/Husband = 完全权限
归属 ownership
极性 + 家族 + 层级关系。这个字属于哪个袋子,袋子在哪个更大的袋子里
例: 囡 → 容器家族 → 刘楚恬侧 → 阴极性
