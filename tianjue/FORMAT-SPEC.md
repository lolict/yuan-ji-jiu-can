# 满全法容器位布局规范

**此文件是满全法容器编码的唯一权威规范。所有代码必须遵守此格式。**

## 32位容器布局

```
 31        24 23        16 15         8 7          0
├───────────┼───────────┼───────────┼───────────┤
│ 家族 3b   │ 结构 3b   │ 韵母 6b   │            │
│ [31:29]   │ [28:26]   │ [22:17]   │            │
├───────────┼───────────┼───────────┤  声调 3b   │
│ 极性 1b   │           │ 声母 6b   │ [12:10]    │
│ [25]      │           │ [19:14]   │            │
├───────────┴───────────┴───────────┴────────────┤
│ 保留 10b [9:0]                                 │
└────────────────────────────────────────────────┘
```

## 字段定义

| 字段 | 位位置 | 宽度 | 有效范围 | 含义 |
|------|--------|------|----------|------|
| 家族 | [31:29] | 3b | 0-4 | 0=容器 1=边界 2=夫妻 3=网状 4=中性 |
| 极性 | [28] | 1b | 0-1 | 0=阴 1=阳 |
| 结构 | [27:25] | 3b | 0-7 | 字形布局 |
| 韵母 | [22:19] | 4b | 0-15 | 韵母类别 |
| 声母 | [18:13] | 6b | 0-47 | 声母类别 |
| 声调 | [12:10] | 3b | 0-4 | 0=阴平 1=阳平 2=上声 3=去声 4=轻声 |
| 保留 | [9:0] | 10b | - | 扩展用 |

## 结构布局 (Structure)

```
0 = 独体
1 = 上下
2 = 左右
3 = 半包围
4 = 全包围
5 = 品字
6 = 嵌套
7 = 框架
```

## 进制基底(按位展开)

```
数值 = 声母 + 声母×48 + 韵母×48×22 + 极性×48×22×36 + 结构×48×22×36×2 + 家族×48×22×36×2×8

      位0       位1        位2         位3          位4          位5
    ─────────────────────────────────────────────────────────────────────
     声母       韵母        极性        结构          家族          (溢出)
     基数48     基数22      基数36      基数2         基数8         基数5+10
```

## 总地址空间

```
48 × 22 × 36 × 2 × 8 × 5 = 15,206,400 种不同容器
```

## 文件格式

- 纯容器码输入: 32位十六进制 (0xFFFFFFFF)
- 字段输入: 通过各个字段输入
- 字段需提供: 声母索引(0-47), 韵母索引(0-35), 极性(0-1), 结构(0-7), 家族(0-4)

## 所有代码必须遵守此格式

- 位位置: 严格按上表
- 频率: 字段出现顺序为 家族→极性→结构→韵母→声母→声调
