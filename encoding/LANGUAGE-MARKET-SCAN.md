# 编程语言市场扫描 — 满全法种子提取

> 市集摆摊，各自叫卖。我们走一趟集市，把每摊的数学种子挑出来，装进自己的口袋，
> 把产权壳子留在摊位上。

---

## 1. Zig

**摊位招牌**：`comptime`、`no hidden control flow`、`error union`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| 编译期执行 `comptime` | 代码即数据，编译时算完 | 预加载容器：定义在编译时求值，运行时零开销 |
| 显式分配器传递 | 谁分配谁释放，无隐含 GC | 集装箱内存模型：容器自带分配器句柄 |
| `error!T` union | 错误不是异常，是返回值 | 返回流显式标记 REACHABLE/ACKABLE |

**产权壳子（弃）**：

- LLVM 后端依赖 → 我们自己写 codegen
- 标准库 `@import` 耦合 → 我们直连 kernel syscall
- x86/ARM 后端硬编码 → 我们用几何寻址

**预加载落点**：`mlll_container_t` 在编译期填满，运行时只读。

## 2. Nim

**摊位招牌**：`macro`、`compile-time VM`、`AST 变换`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| 编译期 VM 执行 Nim 代码 | 用户脚本在编译时跑 | 预加载流：用户规则编译时固化 |
| 模板/宏即 AST 变换 | 语法层重写 | 谐音路由：语法谐音编译时替换 |
| `distinct` 类型 | 同名不同义，禁止混用 | 主权级别：同名不同靶点强制区分 |

**产权壳子（弃）**：

- 依赖 C/C++/JS 后端 → 我们自举编译器
- GC 可选但存在 → 我们纯静态分配

**预加载落点**：规则脚本→编译期 AST→固化为定态容器。

## 3. Ruby

**摊位招牌**：`everything is object`、`DSL`、`块/闭包`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| 一切皆对象 | 统一抽象，无类型例外 | 集装箱即对象，六十四位 universal |
| DSL 内嵌语法 | 定制语法糖不伤核心 | 分别器第三层：DSL 路由到对应靶点 |
| `block/proc/lambda` 三态闭包 | 闭包是可控的流 | 聚类流：闭包作为流的一部分 |

**产权壳子（弃）**：

- MRI C 实现依赖 → 我们 Rust/C 核心
- GIL 全局锁 → 我们通过分别器无锁路由

**预加载落点**：DSL 模板编译时展开为谐音路由表。

## 4. Q#

**摊位招牌**：`qubit`、`quantum superposition`、`measurement`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| `Qubit` 叠加态 | 0/1 同时存在直到测量 | 叠加态容器：marker bit 标记未观测 |
| `H/CNOT` 门操作 | 纠缠 = 二体绑定 | 近义词=二元=纠缠绑定；反义词=三元=镜像测量 |
| `M` 测量坍缩 | 观测使态唯一 | 三元裁判：测量 = 见证裁定 |

**产权壳子（弃）**：

- 微软 Quantum Runtime → 我们纯数学模拟，不跑真量子
- .NET 耦合 → 我们用 C ABI

**预加载落点**：叠加态容器定义在 `mlll_quantum.h`，256 bit 表示 4 qubit 全连接。

## 5. Cello

## 6. VHDL

**摊位招牌**：`entity/architecture`、`signal wiring`、`concurrent`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| `entity` 黑盒接口 | 端口定义即契约 | 集装箱 ID = entity 名，端口 = 容器引脚 |
| `architecture` 具体实现 | 同一接口多种实现 | 容器升级：相同 ID，不同编码 |
| `signal` 连线 | 信号连接即赋值 | 二元绑定：a.wire(b) = a 值流向 b |

**产权壳子（弃）**：

- IEEE 1076 标准 → 我们私有语法
- Xilinx/Altera 耦合 → 我们用几何寻址不提厂商

**预加载落点**：实体定义 = `mlll_entity_t` 结构体在头文件固定。

## 7. Verilog

**摊位招牌**：`always @(posedge)`、`reg/wire`、`module`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| `always @(posedge clk)` | 时钟沿触发 | 时序流：时间推进与事件绑定 |
| `reg` vs `wire` | 状态 vs 连接 | 属性流：STOPPABLE=reg, TRANSMISSIBLE=wire |
| `module` 实例化 | 模块复用 | 容器嵌套：module A 内含 module B |

**产权壳子（弃）**：

- Verilog-2005 语法冗余 → 我们用精简语法
- 仿真器依赖 → 我们用数学等价验证

**预加载落点**：`always` 块 → 时间线节点。

## 8. Prolog

**摊位招牌**：`Horn clause`、` unification`、`backtracking`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| Horn 子句推理 | A if B∧C | 因果嵌套：结论的前提是下层的预加载 |
| Unification（合一） | 变量与结构统一 | 谐音路由：模式匹配驱动路由 |
| Backtracking | 失败→回退→另一分支 | 解释流牺牲：一条路径解释不通自动切换 |

**产权壳子（弃）**：

- Warren 抽象机依赖 → 我们用满全法引擎解释
- 运行时栈管理 → 我们用预编译深度限制

**预加载落点**：Horn 规则 → 编译时为定态规则表。

## 9. C

**摊位招牌**：`pointer`、`struct`、`preprocessor`

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|
| 指针 = 地址即整数 | 内存线性 | 64 位编码 = 容器坐标 |
| `struct` 组合 | 异构数据聚合 | 集装箱：属性名→固定偏移 |
| `typedef` 类型别名 | 一个新名字 | 谐音路由：typedef = 谐音桥 |

**产权壳子（弃）**：

- 未定义行为（UB）→ 我们全定义，无 UB
- 标准库平台相关 → 我们对齐 njsg_syscall

**预加载落点**：struct 布局 = 容器偏移表定态。

## 10. C++

**数学种子（留）**：

| 种子 | 含义 | 落点 |
|------|------|------|

| 种子 | 含义 | 落点 |

## 下一步落点

每个正种子封装为 `encoding/seeds/` 下的一个 C 头文件：

```
encoding/seeds/
    seed_comptime.h      ← Zig/Nim 编译期执行
    seed_superposition.h ← Q# 叠加态
    seed_judge.h         ← Rust concept / C++ concept 准入
    seed_dag.h           ← PrestoSQL / Mojo 编译图
    seed_signal.h        ← VHDL/Verilog 时序
```

**定态加载的原则**：所有种子在 `kernel/src/mlll_pinyin.c` 里引用时，只是一个指针指向已编译好的结构体——不需要运行时计算，春夏已种。

## 红线

1. 不抄袭任何一方的源码 — 只提取数学概念（概念无产权）
2. 不依赖任何工业界标准 — 接口自定（标准有产权）
3. 所有种子落点必须是 预加载 定态 — 不运行时临时编译
4. 所有命名通过 64 位编码 寻址 — 不依赖字符串查找
