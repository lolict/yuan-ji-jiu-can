# 脱壳编译器 (HUSK-COMPILER)

## 谷壳隐喻

```
        旧编程语言符号 (带壳谷子)
    ┌─────────────────────────────┐
    │  壳 = 旧进制 · 私有命名 ·    │  ← 不能进粮仓
    │      类型系统 · 产权编码     │
    │  ┌───────────────────────┐  │
    │  │  米 = 数学种子        │  │  ← 这个留下
    │  │  (算法/逻辑/DAG/     │  │
    │  │   信号流/编译期)      │  │
    │  └───────────────────────┘  │
    └─────────────────────────────┘
              ↓
         脱壳编译器
              ↓
    ┌─────────────────────────────┐
    │  满全法容器 (新进制 · 新命名)│
    │  family|polarity|struct|    │
    │  shengmu|yunmu|tone|...    │
    └─────────────────────────────┘
```

## 三大原则

1. **不能带壳进仓** — 任何外部符号必须脱壳后才能进入我们的空间
2. **不能延迟脱壳** — 延迟 = 给壳发芽的时间 = 未来在我们内部生根
3. **不混用进制** — 只用我们自己的进制重新编排, 不保留他们的骨骼

## 进制对照

| 层 | 旧体系 (壳, 弃) | 新体系 (仓, 留) |
|----|-----------------|-----------------|
| 字符 | ASCII/Unicode | 容器编码 (32位) |
| 命名 | 私有标识符 | 感知家族 + 谐音靶点 |
| 结构 | 语法树 AST | 流水线时序 + 层级叠加 |
| 类型 | 静态类型系统 | 三元裁判 + 动力充足 |
| 作用域 | 命名空间 | 主权路由 + 容器归属 |
| 求值 | 惰性/即时 | 预加载时序 + Winter取用 |

## 脱壳流程

```
旧源代码
  ↓ 词法分析 (拆旧符号)
旧 token 流
  ↓ 脱壳层: 每个 token 剥离旧进制
命名种子 + 数学种子
  ↓ 满全法编码层: 用新进制重新编排
容器化 token 流
  ↓ 筷子夹持层: 二元公倍数夹持目标
编排序列
  ↓ 流水线: 单向时序排水
满全法产物 (Document/执行代码)
```

## 容器内的壳检测

`husk_detect(symbol)` — 如果一个符号还带着旧进制 (他们的骨骼/进制/私有命名), 触发:

- 状态: `HUSK_DETECTED`
- 处理: **立即隔离** · 不能进入下游
- 报警: "谷子还带着谷壳 · 不可入仓"

只有 `husk_free(symbol) == true` 的符号才能进入后续流程。
