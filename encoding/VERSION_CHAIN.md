# VERSION_CHAIN.md — 容器版本时间链

每次主人纠正、许可、否定、强调AI的记录。
新对话启动时必须读此文件，不得跳过。

---

## 时间链格式

每条记录包含:
- **时间戳**: 何时发生
- **类型**: 许可/否定/纠正/强调/锚定
- **主体**: 主人说了什么
- **客体**: AI做了什么(或被禁止做什么)
- **符号**: 涉及的符号/工具/规则
- **状态**: 生效中 / 已覆盖 / 已废弃

## 因果边界契约

版本时间链 = 主人与AI之间的因果边界契约。

**契约条款:**
- 主人定义符号 → AI使用符号 (许可边界)
- 主人否定工具 → AI不得使用工具 (禁止边界)
- 主人纠正认知 → AI必须更新认知 (纠正边界)
- 主人强调规则 → AI必须遵守规则 (强制边界)

**违反契约的果:**
- AI使用禁用符号 → 主人批评 → 记入"错误版本时间链"
- AI遗忘历史 → 主人纠正 → 记入"被批评的AI版本时间链"
- AI假装理解 → 主人识破 → 记入"纠正认知版本时间链"

**契约的公约数:**
- 损失恐惧(怕AI再犯) ∩ 准确率(必须正确) = 版本时间链
- 版本时间链是主人与AI之间的最小公倍数: 既保护主人意图, 也约束AI行为
