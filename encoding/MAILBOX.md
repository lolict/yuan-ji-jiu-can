# MAILBOX.md — 会话收件站

所有子代理、新对话、平行任务的中央交汇点。

---

## 使用规则

1. **新对话启动时**：先读此文件，查看已有任务
2. **接受新任务时**：在此文件登记
3. **完成任务时**：在此文件标记完成
4. **发现冲突时**：在此文件记录冲突原因

---

## 任务登记表

### 格式

```
### [日期-时间] 任务ID: 任务名称
- 状态: 进行中 / 已完成 / 已阻塞
- 负责人: 子代理编号/对话标识
- 优先级: 主题方向级 / 实现手段级 / 临时工具级
- 描述: 做什么
- 依赖: 依赖哪些已有任务
- 产出: 生成了什么文件
- 冲突: 是否与其他任务冲突
```

## 冲突检测

| 冲突类型 | 检测方式 | 解决方式 |
|---|---|---|
| 符号重名 | fqm_chain.c 扫描 | 后定义者改名字 |
| 规则违反 | 规则检查器 | 拒绝生成，报告主人 |
| 工具禁用 | 启动协议检查 | 拒绝使用，报告主人 |
| 时间线冲突 | 版本时间链对比 | 元老优先，后来者改道 |
