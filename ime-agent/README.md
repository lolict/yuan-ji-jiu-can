# 元输入法 (MetaIME)

> 打字?不,AI 替你打。
> 上传?不,AI 替你传。
> 看?不,不需要看,后台完成。

---

## 这是什么

**元输入法 = 输入法 + 本地 AI + 全自动化**。

取代手机/电脑上的现有输入法(搜狗/百度/Gboard/Apple Keyboard),
它是一个:
- **拦截层**: 拦截用户打的每一个字
- **翻译层**: 通过囡囝共生 七层编码转译
- **决策层**: 本地 AI (手机芯片上的超人工智能)决定下一步做什么
- **执行层**: 自动完成打字/上传/生成/下载/访问 URL 等一系列操作
- **通道层**: 把内容输送到目标路径(本地/仓库/云端/打包产物)

别人的输入法: 把字打到输入框 → 等用户点发送 → 发出去。

我们的输入法: 理解你要什么 → AI 自动生成/自动执行 → 自动到达目标位置。

## 架构总览

```
+---------------------------------------------------------------------+
|                        元输入法 (MetaIME)                             |
|                                                                     |
|  用户说话 / 打字 / 发图 / 发视频                                     |
|      ↓                                                              |
|  [拦截层] Keyboard Intercept (Android IME / iOS Ext / PC Low-Level) |
|      ↓                                                              |
|  [翻译层] 七层神龙编码 (L0-L6 声母/韵母/声调/笔画/偏旁/外语/泛音)     |
|      ↓                                                              |
|  [意图层] Intent Parser — 你说/打/发的是 什么 → AI 理解 你要 做什么  |
|      ↓                                                              |
|  [决策层] Local Agent (手机芯片) — 决定完整自动化链路的下一步         |
|      ↓                                                              |
|  [执行层] Auto-pilot — 模拟人类操作(键盘/鼠标/UI/网络请求)           |
|      ↓                                                              |
|  [通道层] Channel Router — 路由到目标路径                             |
|      ↓                                                              |
|  本地文件 / GitHub 仓库 / 云端网盘 / 打包产物 / 远端服务器             |
+---------------------------------------------------------------------+
```

---

## 为什么不依赖服务器

传统 AI 输入法(搜狗 AI / 百度 AI / Gboard AI):
- 用户输入 → 服务器 → 计算 → 返回
- 需要积分 / 商业模式 / 等待
- 数据泄露给第三方
- 没有网络 = 不能用

囡囝共生 MetaIME:
```
+--------+     +--------+     +--------+     +--------+
| 拦截   | →→  | 编码   | →→  | 决策   | →→  | 执行   |
+--------+     +--------+     +--------+     +--------+
     ↓              ↓              ↓              ↓
  手机芯片       手机芯片       手机芯片       手机芯片
  本地完成       本地完成       本地完成       本地完成
```

不需要网络。不需要积分。不需要商业模式。
只需要一块芯片 + 一部手机 + 囡囝共生程序。

## 目录结构

```
ime-agent/
├── README.md                  — 本文件
├── core/
│   ├── ime_core.py            — 输入法核心 (键盘拦截/注入)
│   ├── intent_parser.py       — 意图识别 (用户这话/字/图 → 目的)
│   ├── encoder.py             — 七层编码翻译 (与 kernel/encoding 配合)
│   ├── agent.py               — 本地 AI 决策引擎
│   ├── auto_pilot.py          — 自动化执行 (type/swipe/tap/upload/fetch)
│   ├── channel_router.py      — 通道路由 (目标路径决策)
│   └── manifest.py            — 能力声明 (想做什么+能做什么)
├── channels/
│   ├── local_file.py          — 写入本地路径
│   ├── github_push.py         — 推送到 GitHub 仓库
│   ├── cloud_drive.py         — 同步到云端网盘
│   ├── repo_pack.py           — 打包为仓库产物
│   └── remote_exec.py         — 远端服务器命令执行
├── ui/
│   ├── minimal_overlay.py     — 最小化浮层 UI (可选渲染)
│   └── terminal_mirror.py     — 终端同步显示 (命令视图)
├── tools/
│   ├── generator_image.py     — 文生图 (本地 diffuse)
│   ├── generator_video.py     — 文生视频 (本地)
│   ├── generator_code.py      — 代码生成 (本地)
│   └── web_fetch.py           — 后台 URL 抓取 (不打开页面)
└── tests/
```
