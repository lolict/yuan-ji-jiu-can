# 64容器 · 语文组织表

> 语文分类优先·数学仅作后附描述
> 容器自身定义进制·数学只是描述工具·不可反客为主
> 8类×8格 = 64容器，是每个容器名称/形状/用途自带的层级规则

---

## 分类总则

本表按**语文逻辑**（名称相近·形状相近·用途相近·功能角色递进）将满全法已定义的历史符号家族组织为8大类、每类8个容器。数学表示（4³=8²=2⁶）仅在附录中出现，不参与分类决策。

**分类依据：**
1. 以容器符34字为核心存在单位
2. 其余三族（操作符26字、极性符20字、层级符19字、审判符19字、产权符20字）按功能角色分别归入各类的"操作位""极性位""层级位""审判位""产权位"
3. 每类8格 = 根基位 + 容器位(1-3) + 操作位 + 极性位 + 层级位 + 审判/产权位

**分类依据：** 所有容器的源头——"袋"是满全法第一个被定义的容器单位，象征"袋级操作"（不数米的颗粒，整袋整袋地装）。本类收纳最小的、最基础的容器单位和定义根基的符号。

| 1 | **盂** | 袋装盂（盂是袋的缩小版·浅口碗状） | 小范围收纳·临时容器 | 北·藏 |

## 层级嵌套总规则

### 一、容量层级（哪个装哪个）

```
袋 ⊃ 盂 ⊃ 盏 / 盅
袋 ⊃ 桶 ⊃ 盆 ⊃ 钵 / 盒
桶 ⊃ 罐 ⊃ 瓮 / 坛
缸 ⊃ 罂 ⊃ 甑 ⊃ 甗
壶 ⊃ 匣 ⊃ 奁 ⊃ 箱 ⊃ 柜
盒 ⊃ 杯 ⊃ 盌 / 盉 / 瓯
箕 ⊃ 笼 ⊃ 篓 ⊃ 筐
坛 ⊃ 甏 ⊃ 箩 ⊃ 筲
```

### 二、同级互装规则

同级容器原则上**不可互装**（容量相等·边界相抵）。但有3个例外：
- **盏与盅同级**：可互换·功能重叠（盅可装盏·反之亦然）
- **匣与盒同级**：匣可装盒·盒可装匣（互为镜像·夫妻一体）
- **柜与箱同级**：柜可装箱·箱可装柜（层级并列·各有门户）

### 三、跨类互装规则

跨类互装需满足**"大器可装小器·同级类不互装"**原则：
- 根基类 → 可装：自身小容器
- 扩容器族 → 可装：根基类+扩容器族内部
- 重器族 → 可装：根基类+扩容器族+罐级自身
- 权柄族 → 可装：根基至重器全部+壶级自身
- 界藩族 → 可装：根基至权柄全部+匣级自身（宝藏容器·可装一切）
- 分配族 → 可装：仅分配族内部（公平分配·不兼容器）
- 承载族 → 可装：自身内部+大件搬运（不装液体/半流）
- 归藏族 → 可装：一切（终极密封·归藏万方）

### 四、极性分配规则

根据满全法定义（偶数=阳=界线=我·奇数=阴=容器=刘楚恬·8=九元=平衡）：

```
类0（根基）：奇数阴·容器族
类1（扩容）：偶数阳·界线族
类2（重器）：奇数阴·容器族
类3（权柄）：偶数阳·界线族
类4（界藩）：奇数阴·容器族
类5（分配）：偶数阳·界线族
类6（承载）：奇数阴·容器族
类7（归藏）：8=平衡·混沌族
```

### 五、层级定位规则

每类对应满全法九元层级之一·加上一个"超越"态：

| 类别 | 对应元级 | 偏移率 | 容器数量 | 极性态 |

## 附录B：编码值极性映射

> **警告：** 数学表示仅作附录参考·不参与主要分类逻辑·

### bit6 / bit7 极性标记在容器族中的表达

根据根基锚点定义（我=1=高位·刘楚恬=0=低位）：

| bit | 值 | 满全法含义 | 容器族表达 |
|-----|-----|------------|------------|
| bit6 | 64 | 妻子观测态=刘楚恬=0 | 奇数类（根基/重器/界藩/承载·阴·容器）= 妻子极性态占优 |
| bit7 | 128 | 丈夫观测态=我=1 | 偶数类（扩容/权柄/分配·阳·界线）= 丈夫极性态占优 |
| bit6+bit7 | 192 | 夫妻统一体=平衡 | 归藏族（第7类·njsgr）= 混沌平衡态 |

### 观测坍缩规则

当读取某类容器中的物品时·触发夫妻观测：
- 从奇数类取出物品 → 妻子先观测（bit6=1·容器侧优先）
- 从偶数类取出物品 → 丈夫先观测（bit7=1·界线侧优先）
- 从第7类（归藏族）取出物品 → 双观测同时触发（192=混沌坍缩·双方同时得见）

### 数学附会（仅描述·非定义）

64格的容器族可附会表示为：
- **8类** = 2³（3位编码·每位的0/1代表极性翻转）
- **每类8格** = 2³（3位编码·代表该类内部8种细分）
- **合计64格** = 2⁶（6位编码·高位3=类·低位3=格）

**此数学表达由语文分类结果自然形成·不可反转为主·64格是因为语文上"8类各8个"成立·数学碰巧能附会2⁶=64。**
