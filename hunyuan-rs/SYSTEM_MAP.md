## 三、数据流 (字符从输入到判决)

```

    │
    ▼
[1] 编码桥接 (encoding_bridge.rs)
    │  unicode → family分类
    │  á → Family::Couple
    │
    ▼
[2] 衍射分析 (grand_court.rs → crime_transcript.rs)
    │  8维特征投影 (审美/类型/外观/结构/思维/合作/目标/归属)
    │  等效距离计算 (公倍数对齐检查)
    │
    ▼

    │  a vs á 距离≈0.18 > 阈值0.15 → 类型跳跃
    │  记录犯罪: TypeMismatch
    │
    ▼

    │  节点间拉力平衡
    │  均匀分布式判断
    │
    ▼
[5] 全局水质 (crime_transcript.rs → GlobalWaterQuality)
    │  样本累计
    │  全局污染检测 (>50%样本不合格)

    │
    ▼
```

## 四、比特分配 (编码效率)

### 容器码 (perception_field.h)

```
32 bit = 4 字节/字
┌────────┬───────┬────────┬────────┬────────┬───────┬──────────┐
│family  │polarity│structure│shengmu │yunmu  │tone   │reserved  │
│3 bit   │1 bit   │3 bit   │6 bit   │6 bit  │3 bit  │10 bit    │
└────────┴───────┴────────┴────────┴────────┴───────┴──────────┘
```

### 字框 (container_codec.h)

```
1 字框 = 16 字 = 1 bit (渲染定态)
254 字 ÷ 16 = 15.875 → 16 框 = 16 bit = 2 字节

理论极限:
  4064 字 (254框 × 16字/框) = 254 bit = 32 字节
  而 4064 字 × 4字节(容器码) = 16256 字节
  → 压缩比: 512:1
```

### 相位立体坐标 (cylinder3d.h)

```
cylinder_coord_t: { x: u8, y: u8, z: u8 } = 3 字节/坐标
  容量: 256 × 256 × 16 = 1,048,576 个位置
```

### RGB 像素 (glyph_pixel_algebra.rs)

```
GlyphPixel: { r: u8, g: u8, b: u8, phase: u8, alpha: u8 } = 5 字节/像素
  但 16 字共享 1 个渲染框 = 1 bit
```
