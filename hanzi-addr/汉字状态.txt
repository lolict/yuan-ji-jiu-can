## 约定法语言 2026-10-16

约定 是 声明式编程 + 呼唤式编程：源 约定.chain，宿主 Nim，解释器 约定.nim
语法（一行一约，可 # 注释）：主导者 <名> / 跟随者 <名> 属于 <主导者> / 功能类型 <名> / 约定 <名> 是 <功能类型> / 号令 <名> 取 <约定> / 范畴符 <名> 取 <号令> / 大约定 <名> { 小约定 <名> 是 <约定> }
语义：门禁是主导者，门禁内部是跟随者；以功能类型的主导声明的为约定，以约定为号令；用约定的号令作私有门禁内部范畴符，用范畴符本质的功能去干活
大约定驾驭小约定；小约定只在自己范畴内生效，互不影响状态（范畴 进制域 声环 可见；范畴 声环 顶层 不可见）
门禁可计算：呼唤 声母.b → 地址 U+E00A（地址取自 码位表.toml，对上用户「门禁入口没有地址值所以不可计算」之问）
命令：约定 / 约定 语法 / 约定 检查 / 约定 呼唤 <名> / 约定 呼唤 <门禁>.<符> / 约定 计算 <门禁>.<符> / 约定 范畴 <作用域> <名> / 约定 原话
