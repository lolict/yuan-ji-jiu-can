# 阴阳三进制解释器 · Yinyang Tri-base Interpreter

> 囡囝共生 v2.0 的语言层 — 把二进制做成三维,
> 让外部代码在我们的规则里被扮演。

---

## 核心思想(代码层)

传统二进制是一维序列: `0 1 1 0 1 ...` — 一条线。

**阴阳三进制是三维坐标空间**: 每条指令是 3D 网格里的一个节点,
节点之间的连接是 **阴(包裹)** 或 **阳(流动)** 的拓扑关系。

### 三个语义轴

```
         经度(jing = 时间因果 = 执行序)
              ↑
              |
              |
              +-------→ 纬度(wei = 空间并行 = 并行流)
             /
            /
           ↓
        深度(zhong = 嵌套 = 集装箱层级)
```

- 经度(jing): 因果先后,一个接一个 — **为什么**
- 纬度(wei): 空间并行,同时共存 — **哪里**
- 深度(zhong): 嵌套封闭,一层套一层 — **装什么**

### 节点类型

| 类型 | 含义 | 角色 |
|------|------|------|
| 0    | 容器(阴) | 包含者,中心,定义边界 |
| 1    | 被含物(阳) | 被包含者,被装的单元 |
| +    | 连接(阳的流动) | 从一个节点流到下一个 |
| =    | 闭合(阴的闭环) | 时间闭环,从终点回到起点 |

### 语法(极简文本形式)

```
(0        进入一个新的3D格子 — 阴的容器开启
  (a 1)   格子 a 放置被含物 1 — 阳的填充
  (b 1)   格子 b 放置被含物 1
  (评 a b) 对 a,b 施加裁定 — 共生赔伴引擎
  (判)    输出 verdict
)         退出当前格子 — 阴的容器闭合
```

三进制数位: 每位由三个 trit 组成 **(in, out, flow)**:
- in: 0=空容器 1=有内容
- out: 0=闭锁 1=开放(可连接)
- flow: 0=静止 1=流出 2=回流(循环)
